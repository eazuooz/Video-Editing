# 자료화면 큐 v4 — 첫 플레이 장면의 게임 디자인

2026-09-14 설명란 전용 출처 요청 반영. Archive64 / NintendoBlackCrisis의 녹화본으로 교체.
[허용 근거](../sources/archive64-rights.md), [입력 컷 계획](../sources/archive64-cuts.json).
원본은 업로더 표기 CEMU·영어판이며 Switch 실기 성능 자료가 아니다.

각 씬은 야숨 관찰 → 디자인 해설 → 가상 2.5D 설계 비교를 정확히 1:1:1로 배치한다.
19.5초는 최초 가안이다. 최종 길이는 `timeline.generated.json`의 실측 `segmentFrames`를 읽는다.
최종 인/아웃·클립 길이·디코드 결과는 `motion-canvas/src/projects/let-them-play/assets/broll-archive64/media-report.json`이 기준이다.

| 08 | 대지 절벽에서 패러세일로 내려가 숲에 착지 | 첫 행동 이후의 연결 |

## 검토와 제외

- 03의 최초 475초 후보는 코로그 대화가 중심이어서 제외했다. 708초부터 지형을 살피는 별도 구간을 사용한다.
- 08의 최초 2752초 후보는 시간의 신전 주변 활공이라 제외했다. 3504초부터 실제 대지 절벽을 내려가는 구간으로 바꿨다.
- 01과 04는 같은 원본의 별도 시간대다. 동일 컷을 반복하지 않는다.
- 02는 대본에서 오프닝으로 되돌아간다고 설명한다. 06은 최초 화면 직후가 아닌 이후 학습이라고 대사로 구분한다.
- 게임의 HUD·대화창은 보존한다. 우리 편집에서 추가한 작은 출처·장 번호·상태 글씨와 마지막 크레딧만 없앤다.
- 모든 영상·음악 출처는 `publishing/youtube.ko.md`, `youtube.en.md`에 표기한다.
- 기존 `assets/broll`, `selected-footage.json`과 과거 검토 MP4는 보존하되 새 본편에는 연결하지 않는다.

## 제작 원칙

원본 속도 유지, 루프·정지로 시간 채우기 금지. 짧은 구간은 관련된 실제 동작 컷을 연결한다.
게임 디자인 해석과 가상 비교는 닌텐도의 공식 개발 의도나 사용자 실험 결과로 표현하지 않는다.
게임 원음은 작게, 우리 대사는 세 구간 내내 이어지며 승인한 Discovery는 처음부터 끝까지 연속 재생한다.
시간 변경 시 KO/EN SRT·본편 믹스·영상도 같은 실측 타임라인으로 재생성한다.
