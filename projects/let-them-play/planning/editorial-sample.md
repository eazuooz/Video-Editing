# 설명 화면 리디자인 — 에디토리얼 2.5D 시안

2026-09-14 사용자 요청: 음성 음량 ×1.1, 더 세련된 설명 화면의 예시 샘플.
**후속 승인: 사용자 “좋아 해줘” — 이 시안을 본편8장면에 확장하고 렌더 완료했다.**
샘플 자체는 비교 이력으로 보존하며 본편 확장은 [editorial-v5.md](editorial-v5.md)에 기록한다.

## 디자인

흰색 연구 발표 스타일을 유지하되, 상자 대신 하나의 작은 게임 공간을 보여준다.

- 왼쪽 큰 제목·짧은 원리, 오른쪽 여백 있는 디오라마의 비대칭 편집 디자인.
- 제목62px, 원리36px, 보조27~31px. 검정/청색/회색, 결과의 노랑.
- 직접 만든 오리지널 모험가: 청색 의상, 노란 스카프, 가방과 부츠. 얌얌코딩의 기존 확정 캐릭터나 링크가 아니다.
- 캐릭터·지형은 코드로 그린 2.5D 벡터. 닌텐도 모델·텍스처·로고·HUD를 가져오지 않았다.
- 저채도 지형, 층이 보이는 바닥, 작은 그림자. 네온·대시보드·광택 카드 없음.
- 천천히 확대하고, 설명 시점에 주변 대비를 낮춰 첫 관심 대상을 남긴다.
- A/B는 같은 좌표·지형·카메라·대상 수를 사용한다. 강조의 대비만 비교한다.
- 한글·제목·라벨은 Motion Canvas `Txt`로 편집 가능. 출처/상태 꼬리말과 엔딩 크레딧 없음.

## 구성

39.7초, 1920×1080, 60fps / 2382프레임.

| 구간 | 화면 |
|---|---|
| 0~9초 | 큰 제목 + 모험가/지형, 여러 요소에 대비가 분산된 상태 |
| 9~19.1초 | 크기·대비·여백 키워드 강조, 주변 대비를 낮춰 첫 관심 대상 표시 |
| 19.1~29.5초 | 같은 장면 두 개를 나란히 보여주고 오른쪽만 강조 조정 |
| 29.5~39.7초 | A/B 유지 + “강조하지 않을 곳도, 디자인합니다.” |

기존03장면 내레이션을 사용한다. 발화 첫 음절이 잘리지 않도록 원본140.40초에서 추출
(첫 단어 실측140.60초). 새 대사·TTS 생성·속도 변경은 없다.
끝180.10초, 마지막 문장 종료179.36초 이후 짧은 여유를 둔다.
샘플 오디오에만 시작0.06초/끝0.6초 페이드. 마지막 발화 후에 페이드가 시작되며 본편 믹스에는 적용하지 않는다.
음성 ×1.1 + 승인된 Discovery를 포함한다. 실제 야숨 게임 화면이 없는 디자인 샘플이다.

## 음성 1.1배 — 본편 적용

정규화된 내레이션에 ×1.1 (+0.8278537dB).
기존 게임 원음+BGM 배경 스템, 덕킹 기준, 내레이션 속도와 타이밍은 유지한다.
리미터 후 전체 믹스는 정확히1.1배가 아니며, 배율은 내레이션의 합산 전 게인이다.

- 영상 패킷 해시 동일, 28908프레임 / 481.8초 유지. 한영 SRT 해시 동일.
- 최종 AAC -15.83LUFS / -2.06dBTP, 전체 디코드 통과.
- 본편 MP4와 편집기WAV에 적용. 이전 파일은 `shared/output/let-them-play/voice-gain-1p1/before-voice-gain.*`에 보존.
- 반복 명령: `node scripts/boost-let-them-play-voice.cjs`.
- 전체 재믹서도 `project.json.audio.narrationGain=1.1`을 읽는다. 이미 믹스된 파일에 재차1.1배를 곱하지 않는다.

Discovery 크레딧은 기존 한/영 게시 설명란에 유지한다.

샘플 웹페이지에도 출처를 적되 영상 프레임에 표시하지 않는다.
