# v4에서는 구현 시뮬레이션을 본편에서 제외

현재 영상은 게임 디자인 해설이다. ‘우리 게임에 기능을 구현한다’는 촬영안을 따르지 않는다.
기존2D 시뮬레이션 소스/2.5D 비교 렌더는 표현 참고물이며, v4 대본 반영 영상이 아니다.

세번째⅓은 같은 가상 시작 장면을 다르게 구성하는 **설계 비교**다.

- 1: 정보를 제시하는 순서 — 설정·조작 안내가 먼저 쌓인 시작 / 주인공과 가보고 싶은 곳이 먼저 보이는 시작
- 2: 주인공과 첫 목표의 화면상 관계 — 주인공·대상·출구의 관계가 흐린 구도 / 주인공에서 대상과 출구로 이어지는 구도
- 3: 강조의 우선순위 — 여러 대상이 비슷한 크기와 대비로 경쟁 / 첫 관심 대상 하나가 배경과 구분
- 4: 처음 요구하는 행동의 수와 순서 — 살펴볼 대상과 기능 안내가 한꺼번에 등장 / 작은 상호작용 하나를 먼저 경험
- 5: 결과가 보이는 위치 — 조작 결과가 현재 시야 밖에서 발생 / 조작과 결과를 한 구도 안에서 확인
- 6: 위험 원인의 가시성 — 위험의 원인이 드러나지 않는 화면 / 같은 위험에 원인을 읽을 단서가 있는 화면
- 7: 같은 정보를 전달하는 시점 — 앞으로 쓸 정보를 시작 시점에 모두 제시 / 행동의 맥락에 맞춰 필요한 정보 제시
- 8: 첫 행동 이후의 연결 — 첫 목표를 끝낸 뒤 방향이 끊기는 구성 / 첫 목표의 결과가 다음 관심사로 이어지는 구성

장면을 만드는 기술보다 플레이어가 무엇을 보고 이해하는지를 설명한다. 가짜 시선추적/유저 반응 수치를 만들지 않는다.
최신 기준은 review.ko.md 및 planning/scenes.json의 designComparison이다.
