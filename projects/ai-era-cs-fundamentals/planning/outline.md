# 기획 개요

- 질문: AI가 코드를 만들어 주는 시대에 컴공생은 무엇을 직접 연습해야 할까?
- 한 문장: AI가 있으면 더 빠르게, 없어도 멈추지 않게. 도구의 요금·사용 환경이 바뀌어도 직접 이해·구현·검증할 선택권을 남긴다.
- 대상: 컴공 학부생·개발 취준생·프로그래밍 입문자.
- 길이: v4 약 11~12분 예상, 12개 독립 씬. 전체 TTS 생성 전 확정 아님.
- 톤: 차분한 균형형·대화체. 약 10% 유머는 톤 기준이며, 취준생의 하루·속마음·짧은 질문으로 공감대를 만든다. 농담 뒤 바로 훈계하기보다 현실적 제약을 인정한다.
- 도입: 코테·포트폴리오 공부를 시작했는데 자극적인 AI 소식 때문에 진로부터 다시 고민하는 가상의 하루.
- 본론: 가상 회의실의 기대와 취준생의 현실, 학습 목표, 디버깅, CS 기초, 설계 설명, 힌트 학습, 테트리스, 테스트, 측정·AI 비용, 리뷰, AI 없이 빈 파일에서 로컬 구현.
- 결론: 작은 기능을 시작하고 끝내 본 경험은 남는다. 합불이나 한 번의 지연으로 실력 전체를 평가하지 않는다. ‘도구는 구독해도 실력까지 구독형으로 만들지는 말자’.
- 강화 사례: 06번 시험·면접에서 손코딩·직접 구현의 첫 줄이 막힘 → 입력·출력·순서 연습. 10번 신입의 반복되는 ‘거의 완료’ → 완료 기준·남은 일·도움 요청. 11번 ‘선배님은 이미 취업하셨잖아요’라는 반론을 먼저 수용.
- 핵심 편집 결정: 원저자의 개인 경험·단정적인 미래 예측은 우리 채널의 사실 주장으로 옮기지 않음.
- 상세 씬 구성: [제작 계획](production-plan.md).
- v4 사실 확인: Astra·Fable 5.1 기본 API 요금은 2026-09-06 공식 문서 확인. 가격 인상은 확정 예측이 아닌 조건 변화 시나리오.
