# 새 배경음악 후보

상태: **후보 1번 Blue Dream — Cheel 선택 확정 (2026-09-06)**. 음악 파일 다운로드·믹스는 아직 하지 않았고, 보관함의 해당 곡 라이선스를 확인 중입니다. 이 선택은 목소리 샘플 승인과 별개입니다.
현재 Computer Use에 연결된 브라우저가 없어 곡 행을 직접 확인하지 못했습니다. [다운로드·라이선스 확인 상태](bgm-selection.md)를 따릅니다.
아래는 작곡가 본인의 공개 미리듣기 링크이며, 설명에서 YouTube Audio Library를 안내합니다.

| 후보 | 미리듣기 | 편집 방향 제안 |
| --- | --- | --- |
| 1. Blue Dream — Cheel **선택됨** | [작곡가 영상](https://www.youtube.com/watch?v=dOfp_DUdwF4) | 편안한 대화형 학습 영상 방향 |
| 2. Lazy Walk — Cheel | [작곡가 영상](https://www.youtube.com/watch?v=lJHlHuyKo_8) | 서두르지 않는 차분한 학습 분위기 방향 |
| 3. Sunset Dream — Cheel | [작곡가 영상](https://www.youtube.com/watch?v=ysAwdX7ntjU) | 결론을 조금 더 밝게 마무리하는 방향 |

분위기 칸은 편집 제안이며 실제 음성 아래에서의 적합성은 곡 선택 후 짧은 믹스로 확인합니다.

## 사용 조건과 출처

- 공식 작곡가 영상의 설명에서 YouTube Audio Library 다운로드 안내를 재확인했습니다. 사용자가 이 프로젝트에 사용할 곡으로 선택했습니다.
- 선택 후 YouTube Studio Audio Library의 해당 곡 행에서 적용 라이선스·출처 표시 필요 여부를 확인하고 기록합니다.
- 모든 곡을 ‘저작권 없음’으로 부르거나 Content ID 결과를 보장하지 않습니다.
- 출처 초안: `Music: Blue Dream — Cheel (YouTube Audio Library)`. 보관함에서 별도 문구를 요구하면 그 문구를 사용합니다.
- [YouTube의 Audio Library 사용 안내](https://support.google.com/youtube/answer/3376882)

## 믹스 방식

선택한 한 곡을 처음부터 끝까지 연속 사용합니다. 원음은 같이 재생하며 겹칠 때 BGM만 3dB 낮춥니다.
나레이션 -16 LUFS, 원음 -23 LUFS, BGM -28 LUFS, 가벼운 음성 덕킹, 곡 반복 1초 크로스페이드.
