- 길이: 33.52초. 24,000 Hz / mono.
- 자동 받아쓰기와 대본을 공백·문장부호 제거 후 비교: 전체 일치.
- 자동 받아쓰기는 자연스러움·문장 끝 호흡·음색의 청취 승인을 대신하지 않는다.
- 생성 스크립트는 WAV 저장 뒤 Windows 콘솔 문자 인코딩 오류로 종료했으나, 생성 파일의 디코딩과 받아쓰기는 정상 확인했다.
- 첫 씬 속도로 추정한 전체 길이: 약 8분 40초. 전체 음성 생성 전의 추정값이다.
- 편집기는 이 샘플만 연결되어 있다. 나머지 11씬에는 아직 내레이션이 없다.
- 전체 TTS·한국어/영어 SRT·최종 믹스는 승인 후 생성한다.

- `npm run build`: 통과.
