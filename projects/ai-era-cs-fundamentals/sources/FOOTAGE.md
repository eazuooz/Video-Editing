## 재현

```powershell
node scripts/prepare-ai-cs-media.cjs acquire
node scripts/prepare-ai-cs-media.cjs trim
node scripts/build-ai-cs-preview-audio.cjs
node motion-canvas/scripts/check-ai-cs-visuals.cjs
node scripts/check-ai-cs-media.cjs
```

현재 구간/컷별 소스는 `selected-footage.json`의 `segments`가 기준입니다.
원본 캐시: `shared/output/ai-cs-media-cache/`. 이전 편집 클립: `archive-v1/` 및 교체한 스톡 6컷은 `archive-v2/`에 보존. 선정 기록은 `sources/archive/selected-footage.v2.json`.
테트리스 소스는 고유 파일명 `07-tetris-lt1Lal2gh_E.mp4`를 사용하므로 예전 스네이크 원본 캐시와 혼동하지 않습니다.
검수 파일: `media-check.json`, `visual-qa/report.json`(60개 프레임 캡처). 최종 TTS·BGM·SRT는 미완성이며 현재 믹스는 구성 검토용입니다.
