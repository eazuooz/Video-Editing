## Title

If AI Can Write Code, What Should CS Students Learn?

## Description

Running code and understanding code are not the same thing.
This video explores practical ways to learn programming fundamentals while using AI as a learning assistant.

Topics include debugging, data structures, design decisions, a small Tetris project,
boundary tests, performance measurement, and code review.
This is a proposed learning approach, not a guarantee of career outcomes or a claim that one tool is always best.
