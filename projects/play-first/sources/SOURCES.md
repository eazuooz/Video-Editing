# 출처·권리 기록 — play-first

기획일: 2026-09-25. 사실 확인과 영상 사용 허가는 별개로 기록한다.

## 1. 논지 참고 (화면·음성 미사용)

- 사쿠라이 마사히로, 「그냥 놀게 놔두세요! [기획 및 게임 디자인]」: https://www.youtube.com/watch?v=PlbwQ_rntCM
- 사용자가 붙여 준 일본어 전사문의 요지만 참고. 번역 인용이 아닌 채널 재구성 대사로 작성.
- 대사 속 “앞부분을 건너뛰는 버릇” 등은 원본 발언의 요약이며 따옴표 직접 인용으로 표시하지 않는다.
- 원본 영상 화면·음성·썸네일·그래픽은 사용하지 않는다. 설명란에 참고 링크를 넣는다.

  제작자 페이지 https://www.nintblkc.com/archive-64 도 같은 조건을 명시.
- 업로더 설명상 Nintendo Switch 녹화, 최대 1440p60. 성능·화질 비교 증거로 쓰지 않는다.
- Super Mario Odyssey © Nintendo. 녹화본 허용과 게임 저작권은 별개. Nintendo 지침: https://www.nintendo.co.jp/networkservice_guideline/en/index.html
- 검토용 360p 프록시: `shared/output/play-first/media-cache/` (최종 사용 파일 아님). 후보 컷·관찰 사실: [odyssey-cuts.json](odyssey-cuts.json).
- 게임 원음은 효과음 위주로 작게 사용. 오프닝 BGM이 큰 03 구간은 원음을 더 낮추거나 효과음 구간을 우선한다.
- 다른 원본 후보(Ninbanyan, Spiral Power 등 9개 롱플레이)는 설명란에 사용 허용이 없어 제외.
