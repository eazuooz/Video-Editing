# 스타트를 눌렀으면 놀게 해 주세요 | 마리오 오디세이로 보는 첫 3분 게임 디자인 — 구성안 v2

2026-09-25 기획. 사용자 요청: 기존 `let-them-play`가 제작 중 다른 주제(첫 화면 정보 설계)로 넓어졌으므로,
원래 논지인 **“그냥 놀게 놔두세요”** 에 맞춰 3~4분짜리 새 영상을 별도로 만든다.
같은 날 “이번에는 마리오 오디세이로 가자” 요청으로 사례를 **슈퍼 마리오 오디세이** 하나로 통일(v2).
기존 `let-them-play` 프로젝트와 출력물은 수정하지 않는다.

## 핵심 질문

게임은 왜, 그리고 어떻게 처음 몇 분 안에 플레이어를 직접 놀게 해야 할까?

## 시청자가 얻어갈 한 문장

첫 3분은 ‘보여 주는 시간’이 아니라 ‘해 보게 하는 시간’이다. 이야기가 필요하면 지우지 말고 조작을 앞으로 당긴다.

## 논지 출처와 우리 재구성

- 원본 논지: 사쿠라이 마사히로, 「그냥 놀게 놔두세요! [기획 및 게임 디자인]」 (https://www.youtube.com/watch?v=PlbwQ_rntCM)
- 사용자 제공 일본어 전사문의 요지만 참고한다. 문장 번역·원본 영상 화면·음성은 사용하지 않는다.
- 오디세이 사례, 유머, A/B 도식, 마지막 체크 질문은 채널의 독자 구성이다. 원본이 오디세이를 분석했다고 주장하지 않는다.

|---|---|---|

## 길이와 구성

- 5장면, 각 장면 = 실제 게임 예시(기본 19.5초, `project.json.editing.exampleSeconds`) → 자체 설명 화면.
- 내레이션은 예시·설명 구간 모두 연속(2026-09-12 기준). 예시 앞 무음 슬롯 없음.
- 본편 예상 약 3분 39초(문자 수 추정) + 마지막 멤버십 감사 10초([규칙](../../../docs/MEMBERSHIP_OUTRO.md)). 길이를 맞추려고 속도를 바꾸지 않는다.
- 후보 컷·관찰 사실: [odyssey-cuts.json](../sources/odyssey-cuts.json). 장면별 대사·화면 계획: [review.ko.md](../script/review.ko.md).

## 디자인

- `docs/VIDEO_VISUAL_STYLE.md` 흰 연구 발표형, `motion-canvas/src/styles/research-paper.ts` 사용.
- 설명 도식에는 마리오·캐피 등 게임 캐릭터를 그리거나 본뜨지 않는다. 채널 자체 도형 인물·아이콘만 사용.

- 외부 영상은 변색·테마 오버레이 없이 원본 비율 유지. 출처는 설명란에만 기록.
