# 버튼을 눌렀는데 왜 무반응일까? | 실제 게임으로 보는 입력 피드백 디자인

버튼을 눌렀는데 화면이 그대로라면, 입력을 못 받은 걸까요? 아니면 선택만 바뀌었거나 작업할 자원이 부족한 걸까요? 산소 미포함의 개발 중 데모에서 포인터 정보, 선택된 카드, 자원 부족 안내, 캐릭터 추가, 작업 계획과 진행, 도구별 표시를 살펴봅니다. 기존 2.5D 설명과 잠긴 문·건설·메뉴·컷신·모의 저장·사용하지 않는 입력 비교를 모두 유지하고, 각 장 사이에 실제 게임 행동과 새로운 해설을 더했습니다.

입력의 수신, 거절 이유, 확정 전 선택, 진행과 완료를 구분해 봅니다. 실제 화면에 나타난 상태와 동작을 바탕으로 우리 게임의 응답을 설계합니다. 2016년 개발 중 데모는 현재 버전의 기능이나 키보드 지원을 증명하는 자료가 아닙니다. 실제로 이해했는지는 플레이테스트로 확인합니다.
