# 입력에 응답하기

시청자 질문: 눌렀지만 실행할 수 없는 상태에서 입력 수신·거절·확인 대기를 어떻게 알아보게 할까?

1. 실제 게임의 조작/대상 표시 → 잠긴 문 응답 비교
2. 건설 거절: 점유와 재료 부족은 다른 이유
3. 메뉴의 확인 의도와 조작 약속
4. 컷신 짧은 입력/길게 확인/중간 취소
5. 모의 저장 요청/진행 중/완료를 분리
6. 현재 맥락에 의미 있는 응답만

칭찬·프레임/입력 지연·튜토리얼을 반복하지 않는다. 새 게임의 관찰 가능한 표시만 설명한다. 자체 테스트는 실제 키 이벤트와 조건별 상태를 기록하고 인간의 재미/사용성 검증을 추정하지 않는다.
