# A03 — 실제 자세와 분석 가이드 구별

선택된 A03만 수정한다. 기존 `relations-v4` 완성본은 보존하며 다른 17편, YouTube, Drive는 변경하지 않는다.

## 화면 변경

- 동일한 화면을 두 번 보여 주던 시연을 큰 단일 화면으로 바꿨다. 기존 기본 속도 세 번 관찰 후 느린 분석 순서를 유지한다.
- 같은 실제 UE 캡처의 대기(0), 준비(23), 타격(35), 후속 동작(48) 프레임을 한 화면에 배치한다. 준비에서 팔을 들어 올리는 자세, 검이 표적에 닿는 순간, 몸을 굽혀 힘을 정리하는 자세를 분리한다.
- 느린 분석의 가이드는 해당 캡처의 실제 골격 트랙과 같은 카메라에서 투영한다. 현재 팔, 대기/타격의 기준 골격, 손의 경로와 디딤발 위치를 보여 준다. 물리 엔진의 접지 측정이나 상용 게임의 내부 측정으로 표현하지 않는다.
- 실제 조작 복귀 시점이 다른 36/48프레임 비교만 좌우 화면을 유지한다. 공격 동작의 자세, 판정 활성 구간, 조건부 히트 스톱과 조작 복귀를 구분한다.
- `1×`는 기존에 시간 배치한 시연의 재생 속도다. 제공된 애니메이션 원본의 미편집 재생시간이라는 뜻이 아니다.

## 재현

`prepare.py`는 기존 편집표와 이동된 관찰 구간에서 정확한 교체 프레임을 구한다. `visual.py`가 원본 UE PNG와 골격 기록으로 합성한다. `render.py`는 CPU 4스레드로 교체 장면과 전체 영상을 만들고 기존 AAC 스트림과 자막을 복사한다. `verify.py`는 기술 검사와 실제 인코딩 표본을 만들며, 직접 표본을 확인한 `visual-review.json`이 있어야 `deliver.py`가 로컬 납품과 통합 A03 항목을 갱신한다.

오디오, 내레이션, 두 언어 SRT의 내용과 타이밍, 앞의 관계도 및 독립 게임 예시는 그대로 유지한다. 기술적 전체 디코딩과 표본 시각 검수는 전체 인간 시청·청취 또는 사용자 승인과 구분한다.
