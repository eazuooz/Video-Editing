현재: 대본 초안/새 촬영 계획. 실제 음성·녹화·씬·최종 컷은 아직 없습니다. 시간은 확정 타임코드가 아닌 제작 계획입니다.

## 이 영상의 질문과 차별점

강의를 따라 만든 뒤, 정답 없이 다시 구현하는 연습을 구체적으로 어떻게 할까? 핵심은 **배우기 → 닫기 → 나누기 → 직접 구현 → 실행/디버깅 → 조건을 바꿔 다시 구현**입니다. 기존 공부법 편의 개괄적 조언을 새 C++ Linked List와 낙하 블록 실습의 실제 결정/검증 과정으로 깊게 확장합니다. [중복 기록](../../../production/preflight/blank-project-coding.json)에 부분 중복과 실제 Studio 근거를 남겼습니다.

## 승인된 화면 방식

고양이 인트로 2초, 본편 1260초, 원본 회원 이미지 엔딩 10초를 최초 계획으로 잡습니다. 본편 실제 작업 756초(60%), 흰 연구 발표형 2.5D 설명 504초(40%)이며 코칭 안내도 설명 시간에 포함합니다. 60fps 계획은 실제 45,360프레임/설명 30,240프레임입니다. TTS와 컷 실측 후 최대 1프레임 반올림 기준으로 재계산합니다.

실제 편집기/디버거/플레이 화면은 전체 화면으로 보여주고 boxed-white-forest-v1 자막을 올립니다. 흰 액자 안 작은 게임, 정적 코드/콘솔 장면과 도식 중심 녹화는 실제 작업 비중을 대신하지 않습니다. 모든 설명은 두께·원근·투영 그림자와 의미 있는 비교/화살표/강조를 사용합니다. 영어 비유는 설명 화면으로 만들고 일반 사무실/회화 스톡을 넣지 않습니다.

좋은 설명을 자르지 않고 동작 관찰과 적용 결과를 연결합니다. 부족하면 관련 작업을 새로 촬영하고 KO/EN 해설을 더해 전체를 늘립니다. 빈 화면·루프·슬로다운으로 비중을 채우지 않습니다.
