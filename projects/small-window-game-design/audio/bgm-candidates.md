# BGM 확정 — Discovery / Scott Buckley

사용자 선택: “디스커버릭로 해줘~”. 이번 프로젝트의 BGM으로 Discovery를 승인받았다.
음악 선택만 확정했으며 대본·음성 샘플 승인과 실제 믹싱은 별도다. 현재 무음 콘셉트에는 아직 적용하지 않았다.
설명란에 아래 Discovery 크레딧을 넣고, 본편에서는 연속 BGM으로 사용한다.
