# 고양이 로고 인트로 v2

사용자 제공 고양이 로고를 그대로 삽입. 픽셀 닭 버전은 채택하지 않는다.

- 2초 / 1920×1080 / 60fps / 120프레임.
- 프레임이 오른쪽으로 펼쳐지고 “얌얌코딩 / 게임 기획·디자인” 등장.
- 고양이 원본 전체를 비율 유지해 표시. 별도 생성/누끼/그림 수정 없음. 글자는 편집 가능한 Motion Canvas Txt.
- Discovery 4–6초 발췌와 낮은 음량 유지. 내레이션 없음.
- 기존 본편 영상, TTS, KO/EN SRT 변경 없음. 디자인 샘플이므로 멤버십 엔딩 없음.
- 재생: `output/intro-sample/index.html` / `yamyam-intro-v2.mp4`.
- 재현: `node motion-canvas/scripts/render-yamyam-intro.cjs`.
