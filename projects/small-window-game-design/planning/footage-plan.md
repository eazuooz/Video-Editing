## 초기 계획 기록 (현재 편집표 아님)

본편 약 4~5분 목표, 실측 전. 독립 6씬. 사용자 요청으로 실제 게임 화면을 본편의 약 68%로 늘린다.
비교 기준은 오디세이(play-first) 최신 타임라인: 실제 게임 135초 / 본편 198.233초 = 약 68.1%.
씬당 27초는 계획 기준이며, 실제 발화 길이와 문장에 맞춰 고유한 추가 컷을 배치한다. 최종 비율은 편집 후 측정한다.
본편에 실제 게임 약 2/3 + 2.5D 설명 약 1/3, 게임은 전체화면, 두 화면 모두 한국어 대사 유지.
10초 멤버십 엔딩은 본편 비율 계산에서 제외한다. 출처는 설명란에 모으며 별도 화면 라벨은 넣지 않는다.
아래는 후보/선정 기준이며 다운로드·프레임 확인·인아웃 확정이 끝난 편집표가 아니다.

| 씬 | 실제 화면 후보 / 필요한 행동 | 새로 만드는 2.5D 설명 |
|---|---|---|
| 01 | Forza Horizon 5, 전방 코너가 나타나는 주행 | 눈–모니터–세계 관계 |
| 02 | 같은 트랙·차량의 운전석/추적 시점 우선 | 동일 도로에 운전석을 올렸다 내리며 가림 비교 |
| 03 | 카메라 FOV를 바꾸는 실제 엔진 화면 또는 설정 확인된 플레이 | 같은 위치·동일 표적·같은 화면 폭, 수평 60°/100° |
| 04 | 슈팅: 먼 적과 가까운 적의 실루엣이 보이는 전투 | 표적의 크기/대비 변화. 판정 크기가 바뀐다고 표현하지 않음 |

Forza 두 업로더 설명에서 해설·편집을 더한 재사용 허용 안내를 확인했다.
게임 IP/라디오/삽입 음악 전체의 권리 보장은 아니다. 필요한 카메라 시점과 동작이 있는지는 아직 프레임 미검수.
VR와 FPS는 내용/권리 검증 전 최종본에 넣지 않는다. 확보 불가 시 자체 재현 대체를 사용자에게 제안한다.
엔진·바퀴·총성은 내레이션보다 작게 유지. 제3자 음악 분리가 안 되면 다른 구간 선택.
출처는 설명란. 워터마크 제거 금지, 얼굴 없는 화면 우선, 원본 반복·슬로모션으로 분량 채우기 금지.
