# 작은 창으로 게임을 읽는 법

질문: 그래픽이 정교해져도 왜 조작할 때 답답할까?
결론: 화면을 장식으로 채우기보다 지금 판단하고 행동할 단서를 충분히 잘 보이게 한다.

약 4~5분 본편 + 10초 멤버십 엔딩 목표. 실제 TTS 길이 측정 전 예상이다.
흰 연구 발표형 색상, 2.5D 원근 도식, 비교는 같은 조건, 긴 글 대신 동작/크기/시선 중심.
원작자 소개가 아니라 게임 디자인 자체를 이야기하며, 참고 원문은 내부 출처 문서에 남긴다.

1. 작은 화면: 그래픽 정교함과 정보 가시성은 다르다.
2. 운전석 vs 외부 시점: 몰입·공간 정보·가림의 절충.
3. FOV: 주변 범위와 중앙 표적 크기의 절충.
4. 표적: 원거리 조준과 동작 읽기, 크기·거리·대비.
5. VR: 이동 방향/관찰 방향을 나눌 수 있지만 별도 가독성 확인이 필요.
6. 결론: 필요한 대상·가림·실제 시청 환경 체크.

각 장면은 실제 예시와 자체 설명을 페어로 배치하되, 예시에서도 내레이션은 계속된다.
사용자의 오디세이 비율 요청에 따라 실제 게임 목표는 본편 68%, 설명은 32%다. 예시 27초를 출발점으로 실측 음성에 맞춰 조절한다.
자료 후보/미확보 항목은 `footage-plan.md`, 보완 논거는 `fact-check.md` 참고.
현재 디자인 프리뷰는 장면당 6초, 36초 무음. 본편 분량과 혼동하지 않는다.

승인: 대본 v1 제작 진행 요청으로 승인 / 기존 균형형 1.7B 첫 장면 샘플 생성·청취 대기 / Discovery 선택 승인 / 최종 청취 미진행.
회원 원본 사진·이름·배지가 미확보이므로 텍스트 전용 구형 엔딩은 붙이지 않는다.
최종 납품은 `output/small-window-game-design/`에 자막판/무자막판/한영 SRT 네 파일.
