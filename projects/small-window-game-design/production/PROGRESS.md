# 제작 상태 — 게임 화면 비중 확대

## 이번 요청 반영

- 오디세이 `play-first` 최신 storyboard를 읽어 실제 게임 135초 / 본편 198.233초 = 68.1% 확인.
- 이번 프로젝트 본편 목표 68%, 전체화면 사용. 총길이의 10초 회원 엔딩은 비율에서 제외.
- 사용자의 제작 진행 요청을 대본 v1 승인으로 기록. 별도 목소리 샘플 승인은 아직 대기.
- Discovery 선택 승인, 저장된 원본 SHA-256 재확인. 다른 곡으로 대체하지 않음.

## 첫 장면 검토본

- 30.24초 사용자 음성 기반 Qwen3 1.7B 합성 완료.
- Whisper 받아쓰기로 6문장 누락·반복 없는지 확인. 사람 청취 승인과 별도.
- 새 Forza 영상 원본 30–75초 확보. 검토본에는 30–50.917초 사용.
- 30.75초 검토본 중 실제 게임 20.9167초(68.02%), 자체 설명 9.8333초.
- TTS / 낮춘 원음 / Discovery 믹스, 편집기에도 동일 WAV 연결. 본편 원음 사용 권리는 추가 검토 필요.
- `preview/narrated-v1/`에 별도 보존. 자막·회원 엔딩 없는 승인용 샘플로, 최종 `output/`에는 수집하지 않음.

## 다음 제작 조건

1. 샘플 목소리 승인 후 전체 6씬 합성·ASR·한영 SRT 타이밍 생성.
2. 운전석/추적, FOV, FPS, VR의 실제 동작과 허용 조건을 확인해 새 컷 확보. 후보 링크만으로 삽입 완료 처리하지 않음.
3. 실측 발화와 컷을 연결해 전체 게임 화면 비율 측정. 원본 반복·정지·슬로다운으로 분량 늘리지 않음.
4. 회원 프로필/표시 이름/배지 원본 캡처 파일 필요. 공유 `members.json`의 `sourceImage`가 null이며 잘린 핸들도 미확인. 텍스트 전용 구형 엔딩으로 대체하지 않음.
5. 최종 믹스·한영 자막·자막판/무자막판 검수 후 `output/small-window-game-design/` 수집.

기존 오디세이 파일은 참조만 했으며 변경하지 않았다. 전체 영상 제작 완료를 의미하지 않는다.
