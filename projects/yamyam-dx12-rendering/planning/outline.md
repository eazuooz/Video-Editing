# 화면 하나 제대로 띄우기까지 | 얌얌엔진 DX12 개발기 — 구성안

## 핵심 질문

게임 엔진에서 화면 한 장을 안정적으로 그려 에디터에 보여주려면 어떤 약속이 필요할까?

## 시청자가 얻어갈 것

GPU가 자원을 쓰는 시간, 재질을 그리는 규칙, 완성된 이미지를 보여주는 방식을 분리해 이해한다.

## 확정 전 제안 흐름

1. 실제 엔진으로 도입: 화면 하나 제대로 띄우기까지.
2. CPU/GPU 완료 시점과 Fence.
3. Scene/Game 카메라와 오프스크린 출력.
4. 패널 리사이즈·자원 수명·입력 분리.
5. 공유 Shader와 재질별 PSO.
6. Opaque/CutOut/Transparent 차이와 현재 제약.
7. 표시용 SRV로 알파 중복 합성 방지.
8. 자동 테스트와 수동 확인, 개발기 결론.

목표 5~7분, 8개 독립 본편 씬 + 10초 멤버십 엔딩. 실제 길이는 TTS 이후 확정.
