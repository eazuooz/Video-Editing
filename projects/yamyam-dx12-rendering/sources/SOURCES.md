## 메모

- 원본 제목과 업로더 이름을 함께 남깁니다.
- 허용 조건을 확인한 페이지나 라이선스 링크를 기록합니다.
- 편집·비평 목적이라도 필요한 분량만 사용하고 출처를 표시합니다.
- 게임 영상은 화면뿐 아니라 원음 사용 여부와 권리 위험도 따로 기록합니다.
- BGM은 사용자 승인 전에는 최종 영상에 넣지 않습니다.
- CC BY 음악은 설명란에 붙일 정확한 출처 문구까지 기록합니다.
