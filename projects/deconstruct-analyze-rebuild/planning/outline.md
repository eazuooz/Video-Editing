# 게임을 베끼지 않고 배우는 법 | 재미를 분석하는 3단계 — 구성안

## 핵심 질문

좋아하는 게임에서 기능을 옮겨 왔는데도 재미가 따라오지 않는 이유는 무엇일까?

## 시청자가 얻어갈 것

겉모습보다 플레이어가 한 판단을 관찰하고, 조건 하나씩 바꿔 새 규칙으로 실험하자.

## 구성

도입은 같은 이동 기능에 서로 다른 판단이 있다는 약속을 보여준다. 본문은 행동 관찰 → 느낌을 조건으로 설명 → 하나를 제거하거나 변경한 테스트 → 판단을 다른 상황에 조립하기 순서다. 참고 영상의 레이싱·드리프트·에어라이드 구성이나 원문 문장을 옮기지 않는다. 슈퍼 미트 보이, 할로우 나이트, 포털의 서로 다른 행동과 직접 만든 도형 기반 점프·통과·이동 테스트를 새 비교로 사용한다.

각 대본 장면마다 실제 사례/플레이테스트 후 독립 2.5D 설명을 붙인다. 예시의 사용 구간과 권리는 확보 후 기록하고 타이밍은 TTS 실측 이후 확정한다. 한 게임의 짧은 컷을 반복해 분량을 채우지 않는다. 결론은 한 번의 플레이를 `무엇을 봤나 → 무엇을 선택했나 → 결과를 어떻게 알았나`로 기록하는 실천을 제시한다.

본편은 실제 게임·개발 영상 60% / 자체 설명 40%를 기본으로 합니다. 흐름상 필요하면
62% / 38%까지 조정하며 채널 인트로·멤버십 엔딩은 계산에서 제외합니다.
각 씬의 비율은 달라도 됩니다. 설명은 2.5D 비교·화살표·강조 애니메이션 중심으로 설계합니다.
