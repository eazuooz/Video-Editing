# 울퉁불퉁한 벽이 사실 평면이라고? — 노멀 매핑 쇼츠

한 가지 사건: 튀어나와 보이는 벽을 옆에서 보면 판 한 장이다. 실제 메시를 바꾸지 않고 조명 계산용 방향을 바꾸는 노멀 매핑으로 답한다.

## 전체 내레이션

튀어나와 보이는 이 벽, 사실은 평면입니다.

먼저 우리 평면 그림은, 빛 계산에 같은 표면 방향을 씁니다.

표면에서 수직으로 나가는 방향, 이게 법선입니다.

빛 계산에 쓸 방향을 픽셀마다 다르게 주면 어떨까요?

방향들을 빨강, 초록, 파랑 값에 저장한 그림이 노멀 맵입니다.

기본 보라색은 재질의 색이 아니라, 표면에 수직인 방향 데이터예요.

빛을 마주 보면 밝게, 옆을 향하면 어둡게 계산합니다.

그래서 같은 그림에서도, 움직이는 빛에 따라 굴곡이 살아나죠.

데드셀의 캐릭터도 3D 모델에서 색 그림과 노멀 맵을 뽑아, 이런 2D 조명에 활용했습니다.

3D 벽에도 같은 원리를 쓰면, 면을 잘게 쪼개지 않고 작은 요철을 표현할 수 있어요.

하지만 꺼도 켜도, 우리 벽은 삼각형 두 개 그대로입니다.

옆에서 보면 윤곽도 평평하죠. 모양 대신, 조명 계산에 쓰는 표면 방향을 바꾼 겁니다.

## 같은 대상에서 이어지는 화면

1. 같은 벽의 노멀 매핑 결과와 짧은 옆면 공개로 질문을 연다. 이후 같은 평면·같은 색·같은 광원을 기준으로 설명한다.
2. 처음 평면에서 법선이 같음을 흰 화살표로 보여 준다. 표면에 수직인 법선의 뜻을 같은 표면에서 정의한다.
3. 픽셀별 계산 방향을 초록 화살표로 바꾸고, 실제 노멀 맵 RGB 데이터와 기본 보라색의 뜻을 보여 준다. 방향과 재질 색을 구분한다.
4. 같은 표면의 선택 지점과 노란 광원 방향을 연결한다. 실행값과 명암 변화는 실제 셰이더·GPU 읽기 값에만 연결한다.
5. 검증된 Dead Cells 캐릭터 제작 사례의 역할은 유지하되, 허락 없는 게임/참고 영상은 쓰지 않는다. CC0 Knight의 실제 3D 원본 → 색 그림·법선 그림 → 재조명되는 평면 캐릭터로 한 프레임을 재현하고, 재현임을 표시한다. 배경 노멀 맵까지 3D에서 만들었다거나 모든 플랫폼이 같다고 말하지 않는다.
6. 같은 3D 벽으로 돌아와 노멀 맵만 켜고 끈다. 실제 메시의 삼각형 두 개와 같은 윤곽선을 확인하고 처음 질문의 답으로 끝낸다.

내레이션·시연은 같은 시간축에서 겹쳐 진행한다. 고정 헤드라인, 같은 공간, 한 절 자막과 의미 있는 표시를 사용하며 검정 화면/음악 리셋을 넣지 않는다. 고양이는 반전·원리·마무리의 필요한 순간에만 오른쪽 아래 크게 둔다. 출처는 전체 한영 설명의 맨 아래에 모은다.

원본 전체의 학습 순서·교정 근거는 sources/reference-analysis.json, 구현·권리는 sources/sources.json, 실제 큐·카메라·표식은 production-plan.json에 연결한다. 완료 경계는 4파일과 전체 자막영상의 로컬 최종 검수다.
