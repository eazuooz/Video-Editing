# 게임 기획서 정리: 계층형 아웃라인으로 생각을 묶는 법

기능, 세부 규칙, 미확인 질문을 어떻게 묶어야 읽는 사람이 필요한 내용을 찾을 수 있을까? 실제 Two Point Museum 공식 시연의 배치·선로 편집·입구 관찰·장식 이동을 먼저 검토하고, 그 행동에 관한 우리의 설명용 기획 메모를 계층형 아웃라인으로 만든다. 개발사의 실제 기획서나 사용 도구를 복원했다는 주장은 하지 않는다.

전체 기존 프로젝트와 실제 Studio 내용 비교는 배치 preflight/hierarchical-game-outlines.json 및 proof-hierarchical-game-outlines/content-review.json에 있다. 프로젝트 생성 전과 독립 한영 대본 작성 후 현재 입력 --check를 통과했다. 원본 강의는 개념 연구용이며 대본 복사·번역이나 강의 영상 복제로 사용하지 않는다.

독립12장·한영 각60문단, 실제 장36문단과 흰2.5D 설명24문단을 교차한다. 본편 실제60%/설명40%, 고양이 인트로2초·회원 엔딩10초 제외, 최대1프레임 반올림. 원본2:24는 상한이 아니다. 실측 부족분은 관련 새 실제 행동을 확보하며 설명 삭제나 반복·정지·저속·무관한 대기로 맞추지 않는다.

공식 두 원본 전체 디코딩/해시와 Museum1018·Against98 연구화면을 검토했다. 최초34컷 native102화면에서 잘못된 시작·물체 명칭·알림 겹침을 발견해 제외했고 새2181–2193 경계3화면을 직접 확인했다. 현재32컷392초 후보이며 최종 비율 수치가 아니다.

공개 Update12 시연/DLC 미리보기 표시를 유지한다. 서로 다른 발췌를 하나의 성공한 연속 플레이로 연결하지 않는다. 설치 미리보기를 완료 놀이기구로, 확인 표시를 전체 검증으로, 꽃 장식을 만족도 개선으로, 입구 관찰을 길 건설로 설명하지 않는다. 원본 진행자·음성·음악은 최종 제외, 얼굴 없는 전체 화면 크롭을 사용한다. Against 첫 건설 시간 압축은 실제60% 제외이며 짧은 배치 예시는 보류한다. 자체 게임/시뮬레이터는 없다.

기존 승인 Qwen3-TTS1.7B reference15–35초·연속 Nimbus를 재사용한다. 여섯 설명의 주장·승인 후 PCM/길이를 보존한다. 새 음성의 현재 해시 전체 ASR·접합/끝소리와 사람 전체 청취는 별도 검수다. 모든 자막은 아래 가운데(960,970). clean은 로컬용이며 비공개 업로드는 검수한 captioned MP4만 사용한다. KO/EN 수동 자막·영어 메타데이터·코칭 카드/엔딩/댓글과 원래 회원 이미지/이름/배지/제목/로고를 유지한다.

최종 공개 권리·원래 Nimbus·잘린 회원 핸들·외부 백업·사람 청취는 pending. 현재 최종 음성·컷·비율·믹스·전체 렌더·수집·비공개/Git 전달을 완료로 기록하지 않는다.
