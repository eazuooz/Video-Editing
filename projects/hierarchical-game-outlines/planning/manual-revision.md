# 계층형 아웃라인 — 원본 구성 보존 수정안

현재 기준: `sakurai-original-flow-modern-equivalent-v1`. 상태와 실제 근거는 [production-plan.json](production-plan.json), [review-ledger.json](../production/review-ledger.json)에 기록한다. 이전 4게임 확장안은 보존된 미사용 이력이며 현재 제작 입력이 아니다.

사용자 최신 지시: **마사히로 원본의 짜임새를 유지하고 그 위치에 세부 설명 PPT를 추가한다. 오래된 게임만 설명이 동등한 최신 버전으로 찾아 바꾼다.** 최소4게임과 추가1게임 기본값을 모두 제거했다.

## 원본과 게임

참고: [Staying Organized with Hierarchical Outlines](https://www.youtube.com/watch?v=ZzCfzwe23kw). 전체 일본어 자동 자막을 연구 자료로 읽었고, 공식 원본 00:35에서 **Smash Bros. Ultimate Main Menu**와 계층 아웃라인의 대응 화면을 직접 확인했다. 자동 자막의 인식 오류를 원문 확정 표현으로 사용하지 않는다.

원본의 게임 사례는 **Super Smash Bros. Ultimate**다. 해당 메뉴·파이터·필살기 명세의 예시 역할을 유지한다. 현재 이용 가능한 후속/최신 버전 중 같은 기능과 설명을 보여 주는 자료가 있는지 확인한 뒤 버전을 확정한다. 새 작품이 있다는 이유만으로 다른 메커니즘을 대신 넣지 않는다. 동등한 최신 사례가 없으면 원본 게임을 유지한다. 아직 최신판 판정이나 새 게임 영상 확보를 완료한 상태는 아니다.

추가 게임은 없다. Two Point Museum, Manor Lords, Against the Storm, Timberborn의 기존 파일·PCM·검수 근거는 보존하되 이 수정본의 사례로 자동 투입하지 않는다.

**참고와 제작 소스 구분:** Sakurai 강의 `ZzCfzwe23kw`, 공식 발표 `fccgHnBQ0YM`, 행사 실연 `4PRS0UHXJt4`는 모두 연구 전용이다. 사용자가 2026-10-13 명확히 정정한 대로 이 영상의 게임 컷·화면·음성을 완성본에 가져다 쓰지 않는다. 확보한 발표/실연 파일과 테스트는 미채택 이력으로 보존하고 제작 컷 목록에서 제외한다. Smash Ultimate의 별도 실제 플레이·메뉴 조작 녹화를 검색하여 출처·사용 조건·실제 동작을 확인하고, 그 영상에 우리 내레이션과 상세 PPT를 붙인다. 기존 초안의 메뉴별 대사는 새 원본에서 확인된 행동에 맞춰 확정한다.

원본의 개론·주장·사례·결론을 우리 방식의 별도 강의로 재배열하지 않는다. 위 PPT는 해당 설명을 더 자세히 이해시키는 삽입이며 원본의 다음 대목으로 돌아온다. 제목·문구·수치·게임 내부 구조를 지어내지 않는다.

대본은 원본의 내용과 순서를 유지한다. 사용자 제공 원문이면 해당 텍스트를 바탕으로 설명을 추가한다. 제공되지 않은 전체 대본을 그대로 복제·번역하지 않고 독립 문장으로 설명한다. KO/EN 최종 본문은 실제 게임 소스와 현재 도구 UI를 확인한 뒤 확정하며, 이전 4게임 결합 대본은 사용하지 않는다.

## 보존할 제작 설정

- 기존 원본 파일, 납품본, 예약 영상 `jBRt3xatdPk`, 회원 신원과 2초/10초 브랜딩을 보존한다. 이 수정안으로 예약을 변경하지 않았다.
- 기존 흰색 설명 팔레트와 실제60:설명40 계약을 유지한다. 추상적 문서 트리는 개념 자체가 대상이므로 투영·가림·단계별 움직임으로 명확하게 표현한다.
- 실제 화면은 필요한 대상/UI를 추적하며, 자막은 960,970 고정·48px·최대2줄. 상세 설명을 위해 원본 UI를 가리거나 자막을 옮기지 않는다.
- 저음량 로파이와 유용한 게임 효과음/환경음, 내레이션 우선 정책을 적용하는 안이다. 새 원본의 음악·해설이 섞인 경우 그대로 살렸다고 주장하지 않고 실제 분리/사용 가능 범위를 먼저 확인한다.
- 기존 [로파이 비교 샘플](../production/manual-preflight-v1/lofi-comparison-final.mp4)은 46.683초의 이전 화면을 사용한 음량 비교다. 새 스매시 사례 영상이나 새 PPT의 완성 샘플이 아니다. 사람 청취/곡 선택은 아직 미완료다.

2. 위 원본 순서에 맞춰 전체 KO/EN 설명과 세부 PPT, 실제 자막/UI 여백·고유 소스 분량을 한 설계로 확정한다.
3. 가장 까다로운 새 PPT/실제 화면 구간만 대표 샘플로 만들고 전체 설계와 함께 보여 준다. 기존 완료 TTS·렌더·검사를 반복하지 않는다.

현재는 원본 대응 수정안까지 준비한 상태다. 새로운 전체 TTS·본 렌더·업로드는 아직 시작하지 않았다. 제작 전 패키지는 내부 확인하고, 사용자 최신 지시에 따라 이 한 편을 중간 승인 없이 제작·검수·비공개 업로드까지 완료한다. 완성 후 사용자 검수를 받으며 다음 영상은 자동 착수하지 않는다.
