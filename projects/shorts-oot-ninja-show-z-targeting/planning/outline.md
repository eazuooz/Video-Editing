# 닌자쇼에서 찾은 젤다 락온의 비밀

Nintendo 개발진 인터뷰3절의 학습 순서를 따른다. [현재 KO/EN 대본](narration-draft-v2.json)과 [원문→대사→장면 대응](source-order-map-v2.json)이 제작 입력이다. 새 대본은 음성 생성 전 초안이다.

| 순서 | 설명 | 화면과 연결 |
|---|---|---|
| 도입 | 특정 상대를 계속 겨누는 락온의 쉬운 뜻과 이번에 볼 두 관계 | 독립 게임 녹화에서 상대를 향한 링크와 주목 표식부터 보여 준다. |
| 1 | 링크를 보이는3인칭 화면의 카메라·전투 문제, 마리오64의 표지판 방향 문제 | 게임 현상에서 카메라/캐릭터 방향을 구별하는 자체 그림으로 이어간다. |
| 2 | 공연에서 처음 주목한 사슬과 원운동 | 우리 설명 모형으로만 표현한다. 첨부 영화 스틸·원본 인터뷰 영상은 제작 컷에 넣지 않는다. |
| 3 | 이미 진행 중이던 주목 고민과, 활극에서 발견한 여러 적의 공격 차례 | 같은 자체 무대에서 한 명의 공격 참여와 나머지 대기를 보여 준다. 닌텐도 내부 코드나 실측으로 표시하지 않는다. |
| 4 | 인터뷰의 숲의 신전 두 스탈포스 사례 | Archive64 독립 원본에서 확인한 두 상대·주목 표식·전투 흐름을 연결한다. |
| 5 | 보이지 않는 연결, 접근·옆 이동·틈과 점프 공격 | 같은 배우의 상대 중심 기준을 자체 도식으로 설명하고 실제 게임 동작으로 확인한다. |
| 정리 | 상대 중심 이동과 여러 공격자의 참여 조절 | 처음 질문에 답하며 두 관계를 말과 화면으로 짧게 되짚는다. |

실제 확보 원본은 **시간의 오카리나3D / Citra 녹화**다. N64 원작 기기 영상으로 표시하지 않는다. 원작 Z 버튼과3DS판 L 버튼의 차이를 유지한다. 파일은1920×1080·60fps 무음이고 녹화자가 편집·수익화 이용을 허용했다. 현재 검수는 전체 원본의 희소 표본과 전투 후보 구간의5초 간격 프레임 확인이다. 연속 재생·최종 컷·자막·음성·완성 영상 검수는 아직이다.

Unity 촬영·TTS·합성은 기존 전체 자원 검사를 통과한 뒤 한 번에 하나씩 실행한다. 원문이 설명하지 않는 보편적인 적 AI나 수치를 만들어 내지 않는다. 최종 clean/captioned/KO/EN, 실제1080p·375px, 음량·발화·접합 검수가 끝난 버전만 로컬 최종 검수로 전달한다.
