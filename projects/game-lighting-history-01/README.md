# 게임 렌더링 역사 · 1편

선택된 한 편만 비공개 업로드까지 제작한다. 현재 상태와 실제 작업 식별자는 [체크포인트](production/checkpoint.json), 검수 근거는 [리뷰 원장](production/review-ledger.json)을 따른다. 자동 채팅과 다음 편 자동 착수는 꺼져 있다.

둠의 구역 밝기 → 퀘이크 라이트맵 → 텍스처 필터링·밉맵 → 타일 기반 GPU → 둠3의 법선·섀도 볼륨 → 하프라이프2의 방향별 라이트맵·공간 표본 → 섀도 맵·CSM → 포워드·디퍼드 → SSAO 순서다. 사용자 제공 설명을 바탕으로 필요한 전제·작은 계산·독립 게임/엔진 시연을 해당 설명 옆에 보강했다.

최신 편집은 `production/local/final-edit-v1/repair-v2/plan.json`이다. 1080p60, 131,010프레임, 2,183.5초(36분23.5초). 본편 실제 화면78,174프레임과 검정2.5D 설명52,116프레임은 정확60:40이며, 원래 고양이2초와 회원10초는 별도다. 고정 길이·최소/최대 시간·20분 자동 분할 규칙은 없다.

원래108문단 음성과 추가36안내를 보존했다. 현재 한글380개·영어388개 자막은144문단/안내 구간에 대응한다. 검정 배경·흰 본문·노란 제목의 투영2.5D 설명과 고정 하단 자막을 사용한다. 현재 전체 믹스13장과 모호한 끝부분2문맥의 실제 ASR 비교를 완료했다. 사람 전체 청취·발음은 별도 대기다.

현재 두 출력의 전체 디코드, 모든 프레임 PTS, 동일 AAC를 확인했고 수정 구간60이미지10판과 세 구간의 정상 속도 재생을 검수했다. 유지 구간은 동일한128,971개의 H264 패킷과 설정을 대조해 기존 검수 근거를 재사용한다. 현재 판정은 [최종 검수](production/local/final-edit-v1/repair-v2/combined-review.json)를 따른다. 원래 실패가 포함된 검수 기록도 역사로 보존한다.

`node scripts/collect-video-output.cjs game-lighting-history-01`로 무자막·한글 자막 MP4와 KO/EN SRT를 수집하고 네 SHA를 확인했다. 공유 인덱스 쓰기 잠금으로 명령이 마지막 단계에서 exit1을 반환한 사실과 인덱스만 마무리한 범위는 [수집 기록](production/collection-completion-v2.json)에 남겼다. 완료된 원본·음성·설명 자산·출력을 재생성하지 않는다.

게시 제목·14챕터·한영 설명·썸네일과 링크는 [게시 패키지](publishing/upload-package-v1.json)에 기록한다. [비공개 완성본](https://youtu.be/ZUrPmDV-bSQ)은 단일 captioned 업로드이며 SD/HD 처리와 1080p60 재생을 확인했다. 수동 KO/EN·영어 정보·썸네일·00초 카드·마지막10초 재생목록/자기구독/과외 링크는 저장 후 재열람했다. 저작권·광고 자동 검사와 첫 재생에서 사용 불가였던 선택형 CC 전파는 pending이며 통과로 간주하지 않는다. 실제 상태는 [게시 영수증](publishing/youtube-receipt.json)을 따른다. 다음 편은 자동 시작하지 않는다.

원본·내레이션·BGM·영상·QA 이미지는 로컬에 보존하며 Git에 추가하지 않는다. 최종 사람 청취·공개 권리·원래 Nimbus 파일·잘린 회원 핸들·외부 미디어 백업은 실제 확인 전까지 pending이다. 다른 영상·기존 예약·연구 GPU·외부 스테이징은 보존한다.
