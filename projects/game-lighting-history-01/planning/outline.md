# 1편 — 게임의 빛은 어떻게 시작됐을까?

현재 질문은 **저장된 밝기와 실행 중 계산하는 빛·그림자는 어떻게 다르며, 조명이 많아지면 계산 순서를 왜 바꾸는가?**이다. 사용자의 남은 영상 제작 요청에 따라 이 편부터 이어간다. 자동 채팅이나 자동 다음 편 제작은 재활성화하지 않는다.

현재 상태는 [제작 계획](production-plan.json)과 [단일 체크포인트](../production/checkpoint.json)가 기준이다. 13장108문단의 KO/EN과 이미 생성한 v4 PCM 1260.87025초를 보존한다. 최종 MP4·수집·업로드는 미완료다. 과거의 714초 실제/476초 설명/1202초 전체 계획과 ‘PCM 미제작’, 흰 배경 시안은 현재 제작 기준이 아니다.

## 확정한 내용과 보존할 자산

원래 고양이2초 → 23.84초 안내 내레이션 → 실제 게임/엔진 동작과 검정2.5D 설명 → 결론 → 원래 회원10초다. 안내는 둠의 구역 밝기, 퀘이크 라이트맵, 실시간 그림자, 포워드/디퍼드 순서를 예고한다. 시청자는 저장 데이터·갱신 조건·입력에 없는 정보를 구별한다. 유리·안개·최신DLSS는 후속 편으로 연결한다.

설명 팔레트는 사용자가 지정한 `research-black-v1`이다. 검정 배경, 흰 본문, 노란 제목, 의미별 색과 표지를 유지하며 투영된 면·가림·움직임을 대사에 맞춘다. 기하 개념은 기하로 설명하고 사람을 단순 상자로 대체하지 않는다. 기존 검정 시안12개 모델의 검수는 시안 범위에서만 재사용한다.

현재 [스토리보드v4](../production/animation-storyboard-v4.json)는108 KO/EN문단과 일치한다. 최종 씬 runtime이 이 버전을 읽도록 수정했다. 기존 v3 대비07-p7의 확정된 한국어 발음 보정 문장을 동기화했으며 EN·기하 동작은 유지했다. 과거 v2에서 달라진09b-p2/p3의 G-buffer 설명도 포함한다. 최종 타이밍/비중 가드는 해제하지 않는다.

기존 승인 Qwen 목소리와 PCM을 보존한다. 이 시작된 프로젝트의 manifest에 기록된 Nimbus 계약을 임의로 다른 곡으로 바꾸지 않는다. 원래 음원 파일 확인과 사람 전체 청취/발음은 pending이다. 시각·자막 수정으로 전체 TTS를 반복하지 않는다.

게임 후보 이름이 여러 개라는 사실만으로 네 게임 해설 완료를 인정하지 않는다. 각 게임의 필요한 규칙/UI, 전 상태→행동→결과, 공통 원리와 의미 있는 차이가 실제 컷과 독립 해설에 연결되어야 한다. 엔진 데모는 허용하지만 게임 수에 합산하지 않는다.

## 현재 자막과 분량

[current-caption-boundary-review-v5.json](../production/current-caption-boundary-review-v5.json)에서108문단 전체를 인식 결과와 대조하고7개 경계를 수정했다. PCM은 변경하지 않았다. [251개 KO 큐 제안](../production/current-caption-layout-proposal-v6.json)은 기존 ASR의 실제 단어 경계를 사용하며 글자 수로 시간을 균등 배분하지 않았다. 48px·1570px 텍스트 폭·최대2줄 기준의 측정과251개 문구 직접 읽기는 완료했다. 실제 브라우저/최종 영상 픽셀, 세부 발화 경계, 최종 EN 대응은 아직 승인하지 않았다.

자막은 `(960,970)` / MC`(0,430)`의 `boxed-white-forest-v1`이다. 박스·테두리·그림자까지 확보하고 게임/UI/도식을 재배치한다. 현재 큐 시간은 **내레이션 기준**이며 고양이·추가 안내·최종 삽입을 반영한 납품 SRT가 아니다.

사용자 지시로 총 영상 시간 제한과 약20분 자동 분할을 제거했다. 필요한 설명과 관련 시연 길이로 이1편을 완성하며, 기존60:40 비중은 별도 유지한다. 현재 후보742.2초는 장별 최종 채택 분량이 아니다. 전체 문단 단위의 설명 배치안894.333초를 유지하면 실제1341.5초·본편2235.833초가 필요하다는 설계 추정이며, 정확한 문장/동작 배치에 따라 달라진다. 음성 전체 길이에 단순히60%를 곱했던 과거14.322초 부족 추정은 폐기했다. 시간이나 비율을 채우기 위한 정적 대기·반복·저속·무관한 시연은 추가하지 않는다.

추가 UE2017 탐색에서3132초의 회색 표면과3140/3141.06/3147.17초의 주황 줄무늬·초록 표면 변화를 보았다. 정확한 변경 조작과 조명 계산 완료는 확인하지 못했으므로 새 채택 분량은0초로 유지한다. 앞뒤 화면 차이만으로 라이트 베이크나 단일 광원 효과를 주장하지 않는다.

## 최종 제작으로 넘어가기 전

다음 한 작업은 **장별 실제 시연 배치와 해당 대사 연결을 완성하는 것**이다. 관련 변경 입력에 한정한 현재 중복 검사, 충분한 고유 소스, 정확 인아웃/크롭, 현재 자막과 대사별 동작 시작을 하나의 제작 패키지로 묶는다. 기존 승인과 해시 일치 자료는 재사용한다.

그 뒤 단일 프레임 타임라인에 믹스·씬·KOEN·챕터·회원 엔딩을 맞추고, 최종 믹스 대조와 clean/captioned 합성, 모든 큐/컷/동작 및 두 출력 기술검사,4파일 수집을 진행한다. 현재 시안·자막 제안을 완료본으로 업로드하지 않는다. 사용자가 모바일에서 검수하도록 최종 captioned 영상의 비공개 업로드까지 이미 승인했다. 같은 업로드 허가를 다시 묻지 않고 저장·재열람 후 링크를 전달한다. 이미 완료한④-1/④-3,③기존 비공개본과 연구 작업은 보존한다.
