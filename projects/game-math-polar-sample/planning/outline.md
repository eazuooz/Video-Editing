# 극좌표계 첫 챕터 — 3분 강의 샘플

2026-10-04 사용자 요청에 따라 본편은 **실제 사례 40% / 설명 60%**. 일반 영상의 60:40을 이 샘플에 적용하지 않는다. 인트로2초·회원 엔딩10초를 제외하고, 모든 Manim 도식과 3D 장면은 설명으로 분류한다.

핵심 질문: 같은 점을 왜 x,y 대신 중심으로부터의 거리와 각도로 표현할까?
시청 후 할 수 있는 일: 오른쪽 +x, 양의 반시계 방향 규약으로 (r,θ)의 점을 찾고 x=r cosθ, y=r sinθ로 바꾸기. 중심이 움직일 때는 상대 변위에 중심의 좌표를 더하기.

Part1 방식: 익숙한 실제 움직임 → 시청자의 질문 → 숫자로 점 찍기 → 움직여 비교하기 → 마지막에 공식. 처음부터 삼각함수를 암기시키지 않는다. ‘네 칸 오른쪽, 세 칸 위’와 ‘다섯 떨어져 약37도’가 같은 점이라는 비교를 보여 준다.

전체 내용 안내(독립01, KO/EN): 회전·퍼짐에서 위치 표현이 필요한 이유 / 거리와 각도의 의미와 변환을 이해한다 / 실제 움직임 관찰, 점 찍기, 가로·세로 좌표 변환 순서. 대본과 실제07까지 대조했고 TTS 전에 약속한 내용을 검토했다. 이 장면은 설명 시간에 포함한다.

최종 본편168초: 실제67.2초(4032프레임) / 설명100.8초(6048프레임). **실제 TTS와 단어 정렬을 기준으로 설명 슬롯을 조정했으며 총180초**이다. 자연스러운 발화가 슬롯을 넘으면 해당 설명을 자르거나 말 속도를 바꾸지 않고 총 길이와 사례 컷을 함께 늘린다. 최종 수치는 production/timeline.json을 따른다. 루프·슬로다운·정지·메뉴를 실제 시간으로 채우지 않는다.

원본 자료를 먼저 전체20초 간격 및 보스2초 간격으로 보았고, 각 선택 구간을2초 간격으로 다시 확인했다. 로딩이 들어간192–203초를 제외하고205초부터 선택했다. sources/gameplay-cuts.json의 발사 지점·방향·보이는 행동과 대사를 대조했다. 서로 다른 원본 구간을 설명 사이에 삽입하며 게임 구현 자체를 아는 것으로 주장하지 않는다. 표의 원운동은 일반 원리이며 실제 Gungeon 탄막이 고정 반지름 원운동이라고 주장하지 않는다.

이 샘플은 Notion7.1의 점 표현·변환을 중심으로7.3 원통좌표를 짧게 예고한다. 중복 표현/음수 반지름/atan2 역변환/구면좌표 전체를3분 안에 압축한 완강 영상이 아니다. 기존 Part1이나 완성 영상은 변경하지 않는다.

기존 Qwen 목소리와 승인 Nimbus를 사용한다. 모든 발화는(960,970) 고정 흰 박스/초록 그림자 자막, KO/EN 동일 타이밍. 전체 최종 음성 ASR·디코딩·음량·모든 큐의 픽셀을 검수하고4종파일을 수집한다. 실제 사람 청취와 게임IP/Nimbus 원본 확인은 별도 미완료 상태를 유지한다. 이번 요청은 로컬 샘플이며 YouTube 업로드 완료로 기록하지 않는다.
