# 뱀파이어 서바이버와 D2 서바이버

제공한 9개 챕터 순서를 유지한다. 실제 게임 장면 확보·관찰 뒤 대본을 확정한다.

- 00:00 — 오프닝: 재미있는데, 이거 괜찮은 건가?
- 01:10 — 뱀파이어 서바이버는 원조였을까?
- 02:25 — 뱀파이어 서바이버가 성공한 이유
- 03:35 — D2 서바이버는 무엇이 다른가?
- 04:45 — 그런데 재미있는 것과 완성도가 높은 것은 다르다
- 05:45 — 무료 팬게임이면 저작권 문제가 없을까?
- 07:10 — 유저들의 인식은 왜 달라질까?
- 08:35 — 팬게임은 게임산업에 도움이 될까?
- 09:45 — 결론: 재미와 저작권을 함께 이야기해야 한다

현재 공식 고지의 로컬 파일 읽기와 호스팅 전환 안내를 구분하고, 재미·완성도·권리관계를 별개로 설명한다.
