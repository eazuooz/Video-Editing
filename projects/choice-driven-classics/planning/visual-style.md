# 크림색 종이와 펜화 — 프로젝트 전용

사용자가 제공한 죄와 벌 UI와 펜화에서 도출했다. 원본 이미지는 수정하지 않는다.

- 종이 `#F3EFE5`, 잉크 `#25231F`, 보조 글자 `#746E63`, 구분선 `#C8C0B2`.
- 한국어 제목 Batang(바탕) 명조, 자막 Malgun Gothic(맑은 고딕). 폰트 파일 재배포 없음.
- 제목 52–66px, 핵심어 38–44px, 자막 36px, 기획/계획 표기 24px.
- 좌우 96px 안전 여백, 하단 126px 자막 전용. 그림/본문 위에 큰 자막을 얹지 않는다.
- 종횡비 유지. 1.00→1.025의 느린 확대. 0.65–0.8초 종이색 페이드.
- UI 강조는 가는 잉크색 테두리와 작은 커서. 실제 실행처럼 보이는 새 창/알림 금지.
- 신규 한글·숫자는 Motion Canvas Txt 노드. 작은 원본 도식은 새 편집 가능한 텍스트 흐름도로 표현한다.
- 1080p에서 제목/원본 크레딧/자막의 잘림·겹침을 검수한다.

기존 글로벌 디자인 기본값 및 과거 프로젝트는 바꾸지 않는다.
