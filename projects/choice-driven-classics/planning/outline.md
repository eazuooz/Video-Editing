# 60초 구성

| 씬 | 구간 | 역할 |
|---|---|---|
| 01 | 0–8 | 원본 손 펜화 느린 확대, 주인공의 선택 질문 |
| 02 | 8–20 | 죄와 벌 원본 UI, 본문 → 선택지 순차 강조 |
| 03 | 20–33 | 선택지 커서, 심증4→5. 이후 화면 원본/대체 승인 대기 |
| 04 | 33–43 | 원본 새 펜화, 각색 설계 → AI 초고 → 작가 전량 검수 |
| 05 | 43–52 | 무료 데모 → 작품별 완결판 → 다음 작품; 목표 가격 |
| 06 | 52–60 | 대표 완성 펜화와 제목; 첫30분 데모 개발 계획 |

사용자 제공 문장을 유지. 60초 시간표가 일반 예시 슬롯 기본값보다 우선한다.
