# M21 · 재질 구와 빛의 경로

2026-11-05 사용자 검수 반영. 새 음성, 다른 회차, 업로드는 이 수정에 포함하지 않는다. v4의 게임 컷 7개, 79문단 타임라인, 내레이션과 믹스를 보존한다. `local/render-v5`에서 제작하며, 이전 검수 파일은 덮어쓰지 않는다.

- 재질 미리보기는 [Epic의 PBR 재질 설명](https://dev.epicgames.com/documentation/en-us/unreal-engine/physically-based-materials-in-unreal-engine)처럼 같은 구의 기본색·조명을 고정하고 금속성만 바꾼다. GGX·Smith·Schlick을 사용한 자체 구현이다. 언리얼 엔진 캡처로 표시하지 않는다. 본문에서 가르치는 퐁·블린–퐁 계산은 이 PBR 예시와 구분한다.
- 빛은 해에서 표면점 P로 들어온다. L은 그 반대인 P→광원, N은 P에서의 법선, R은 거울 반사 방향, V는 P→카메라 렌즈다. 옆에서 실험을 보여주는 관찰 시점과 화면 속 카메라를 구분한다. 벡터 끝, 화살촉, 기호가 내레이션 구절에 맞춰 나타난다. 렌즈가 R과 겹치는 순간에만 이상적인 거울 경로가 렌즈로 이어진다. H와 0벡터 예외는 별도로 설명한다.
- 3D 계산·실제 베이크는 기존 M21 Unity 6000.6.0f1 / URP 17.6.0 실험을 재사용한다. 가상의 받침에서 표면의 값을 읽는 대신 재질 구의 표면을 기준으로 삼는다. 표시용 해는 발광 메시나 실제 태양의 거리 측정값이 아니다.
- 한국어 음성 원본, 기존 문장 순서와 모든 SRT 구간 시각을 유지한다. 이 수정의 한국어 표시 자막만 수학 기호로 치환한 후 박스 폭과 번인 자막을 다시 계산한다. 영어 SRT는 그대로 복사한다.
- 재현 순서: `native.py` → `baked.py` → `fit.py` → `delivery.py --all` → `review.py`. 스크립트는 동일 경로에 있는 v4 큐·편집 소스와 검수 master가 필요하다. 한 번에 한 M21 전용 에디터만 사용한다. 실제 베이크 증거와 브라우저/프레임 검수 결과를 완료된 파일에 연결한다.

전체 디코딩 및 광선 표시 검사는 `review.py`, 격리된 브라우저의 실제 구간 이동·재생 검사는 `playerqa.py`가 수행한다. 두 검사가 끝난 뒤 `record.py`가 M21의 검사 근거와 장면 목록을 기록한다.

이미 편집된 컷을 바꿨다면 `M21_REFRESH_SCENES`에 수정한 세 자리 장면 번호를 쉼표로 지정한다. 재합성 후 두 최종 파일을 다시 검사한다. `scene-catalog.json`에는 시작 프레임, 기존 게임 영상의 원본 구간, Unity 장면 위치가 있으며, `review-evidence.json`에는 이번 수정본의 파일 해시와 검사 결과가 있다.
