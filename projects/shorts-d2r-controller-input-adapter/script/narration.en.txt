Diablo II was built around click movement. How did the developers connect a gamepad?

A click specifies a destination. The game finds a path to it. A stick specifies the direction to move right now.

An input translator connects the two. It connects sticks and buttons to actions the existing game understands.

But is translating the command enough? With the controller, automatic pathfinding is turned off. The player directly controls the direction. Push toward a wall and the character can run into it.

In our diagram, the intended destination is the same. Click movement finds a route around the obstacle. Stick movement needs you to change direction. The meaning of the control has changed.

An input adaptation layer connects the old game to the new device. Adapting movement makes it feel natural on a controller.
