It is StarCraft, turned into a defense game against enemies following a lane. To preserve this freedom in custom maps, Blizzard even built an emulator.

Maps contain triggers that execute actions when conditions are met. Creators used the unit death-count reading function to access other game data.

This uses EUD: Extended Unit Death triggers. But the same opening could be exploited for attacks, so that use was blocked.

Custom maps that depended on it could no longer work. What if a translator sat between an old map’s request and the new game?

That is the EUD emulator’s role. If an old map asks to read the player name, it retrieves that value from the new game.

Patch 1.21.0 brought back some older EUD maps. It did not restore every feature, but kept user-created play alive while preserving security.
