# 전체 음성 받아쓰기 검토

원본 결과는 `asr-review.json`, 별도 구간 재인식은 `asr-recheck/results.json`에 보존한다.
점수가 높다는 이유로 사람의 청취까지 합격한 것으로 표시하지 않는다.

## 점검 결과

- 88페이지 전부 받아쓰기 수행. 초기 자동 플래그는 6·66쪽이었다.
- 추가로 일치율 0.97 미만 페이지를 모두 읽어 숫자 표기·고유명사·말미의 차이를 검토했다.
- 3·5·6·8·22·29·32·54·61·63·65·66·77·78·83·87쪽 등의 차이는 영어/한글 음차와 숫자 표기를 많이 포함한다. 예: How are you / 하우 아 유, 512 / 오백십이, DPT / 디피티.
- **14쪽**: 최초 받아쓰기 마지막의 “다음 영상에서 만나요”는 끝부분 9초를 별도 재인식했을 때 없었다. 최초 단어 타임스탬프도 말미 30.14초에 붙어 있다. 원음을 자르거나 대본·자막에 이 문장을 추가하지 않았다.
- **22쪽**: 두 번의 인식에서 “지금”이 빠진 “까지는”으로 시작했다. 같은 승인 대본으로 전체 페이지를 재합성한 v2 take를 별도 보존했다. v2에서는 의미가 같은 완전한 “여기까지는 헤드 하나의 계산을 봤습니다”로 인식된다. 설치 검증 통과 후 해당 자막도 발화에 맞춘다. 다른 페이지의 시작/종료 프레임은 유지한다.
- **19쪽**: “제곱근을 씌운 값”이 “제곱근을 50값”으로 인식된다. 발음과 숫자 토큰 혼동 가능성이 있어 ASR만으로 잘못된 수식 발화라고 단정하지 않았다. 영상의 수식 및 자막은 정확한 제곱근 스케일링을 유지한다. 짧은 청취 대상: `asr-recheck/page19-window.wav`.
- **66쪽**: “쉰네 쌍”이 “50냇상”으로 인식된다. 문맥은 9×6=54, 54×2=108, 128-108=20이다. 원본 발화를 숫자 오독이라고 단정하지 않았다. 짧은 청취 대상: `asr-recheck/page66-window.wav`.
- `인베딩/임베딩`, `랜더포머/렌더포머`, `보관/보간` 등의 ASR 철자 차이를 자막의 기술 용어로 옮기지 않았다.

## 남는 승인

사람이 실제 음성을 들어 숫자·고유명사·종결 어미를 확인해야 한다. 특히 6·19·66쪽과 교체한 22쪽을 먼저 확인한다.
전체 음성 청취 승인 전에는 `publishReady: false`를 유지한다. ASR 검토는 청취 승인을 대신하지 않는다.
