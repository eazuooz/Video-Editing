# 프리뷰 검수 기록

- 56.766667초, 3,406프레임, 1920×1080/60fps, H.264/AAC. 전체 디코딩 오류 없음.
- Motion Canvas의 독립 씬 3개와 실측 타이밍 일치. PCM 음성이 연결되고 muted=false, volume>0에서 재생 시간이 증가하는 것을 브라우저로 확인.
- 총 11개 cue를 캡처, 줄바꿈·박스 크기를 측정했다. 최대 두 줄, 자막 상단 860px 이하 영역에 침범하지 않고 하단 그림자 포함 1060px 이내. 원본 슬라이드는 y=20~848px.
- 표지, Q/K/V의 긴 문장, 보충 도식을 원본 크기로 보고 전체 cue contact sheet도 확인했다. 글자와 도식의 겹침 없음.
- 48쪽은 빈 페이지 영역에 장면/카메라 두 입력 분기를 추가했다. 공식 논문 원본 그림인 것처럼 새 그림을 제시하지 않는다.
- 최종 AAC 실측: -16.04 LUFS, -2.35 dBTP. BGM 없음은 사용자 요청이다. 원본 합성 WAV는 보존했다.
- Whisper 읽기 비교는 숫자 표기(3/삼), 영문자(Q/K/V)와 한국어 음가 차이를 정규화했을 때 세 발췌 모두 일치했다. 실제 억양·속도·음색의 사람 청취 승인은 아직 없다.
- `npm exec tsc -- --project tsconfig.renderformer.json` 통과. 전체 저장소 검사에는 별도 작업 중인 `play-first/scenes/paper-scene.tsx:9`의 인수 누락 오류가 있었으며 이번 프로젝트 범위 밖이라 수정하지 않았다.
- 다른 작업의 `play-first` 등록/파일을 보존했다. 이번 변경은 RenderFormer 프리뷰 및 제작 계획이다.
- 이 기록은 88페이지 전체 검수가 아니다. 전체 렌더 전 56개 페이지의 보완표 점검, 전체 TTS·동기화·음성/화면 검수가 남아 있다.
