# 전체 구성과 제작 계획

88페이지 전체 대본은 승인되었다. 현재 1·14·48쪽의 대본을 발췌한 음성·애니메이션 프리뷰를 제작했으며 목소리 확인을 기다린다. 원본 페이지를 줄이거나 순서를 바꾸지 않는다. 아래 구간은 영상의 탐색용 챕터이며 페이지를 묶어서 하나의 Motion Canvas 씬으로 만들라는 뜻이 아니다. 각 페이지의 선택적 움직임은 `animation-plan.md`를 따른다.

| 원본 페이지 | 챕터 | 설명의 중심 |
|---|---|---|
| 1~2 | 영상 안내 | 삼각형에서 이미지로, 전체 학습 경로 |
| 3~11 | 트랜스포머와 입력 표현 | 인코더·디코더, 토큰, 임베딩, 위치 |
| 12~25 | 셀프 어텐션과 멀티헤드 | Q/K/V, 내적, 스케일, 가중합, 헤드 |
| 26~31 | 잔차 연결·정규화·FFN | 학습을 돕는 경로와 토큰별 특징 변환 |
| 32~44 | 디코더·마스킹·크로스 어텐션 | 정답 이동, 인과 제약, 인코더 정보 참조 |
| 45~49 | RenderFormer의 전체 구조 | 문장에서 장면으로, 두 단계 처리 |
| 50~61 | 삼각형 토큰과 공개 코드 | 위치·재질·법선, 공유 오프셋, register |

| 72~76 | 시점 독립 트랜스포머 | 장면 정보 교환, RMSNorm·SwiGLU |

## 설명 방식

각 페이지는 ‘이 연산이 필요한 이유 → 그림의 입력과 출력 → 다음 페이지와의 연결’로 읽는다. 작은 행렬의 모든 숫자를 낭독하지 않고 행과 열이 뜻하는 대상을 설명한다. 같은 그림이 이어지면 첫 장은 구조, 다음 장은 크기·작동·해석으로 초점을 나눈다.

대본의 `화면:`은 제작 지시, `내레이션:` 아래 문장만 TTS 입력이다. 읽을 때는 Q/K/V를 큐/케이/브이로 표기하고 숫자·약어는 한국어 음가를 우선했다. TTS에서 실제 발음을 확인하고 수정한다. 자막은 `RMSNorm`, `768`, `Q/K/V`처럼 보이는 화면 용어와 연결되는 표기를 사용하되 발화 의미를 바꾸지 않는다.

자료의 표현을 무조건 정답으로 읽지 않는다. 원 논문·공개 코드·설명용 비유를 구분하고, 검증되지 않은 ‘항상’, ‘완벽하게’, ‘각 뉴런의 고정 의미’는 제거했다. 코드 세부는 고정 커밋에 대한 설명이며 후속 버전까지 같은 구조라고 단정하지 않는다.

## 화면

- 1920×1080, 60fps. 원본 16:9 페이지와 도표 비율을 유지한다.
- 각 페이지 전체를 먼저 보여 주고, 필요한 수식·도표만 천천히 확대/포인터로 짚은 뒤 전체로 돌아온다.
- 페이지 1개에 독립 씬 1개, 총 88개다. 본문을 줄이거나 PPT 내용을 별도 카드로 대체하지 않는다.
- 원본의 흰색 바탕과 남색 제목, 그림을 유지한다. 야간 대시보드나 네온 그래픽을 추가하지 않는다.
- [보완표](corrections.ko.md)의 정정은 별도 사본에 적용한다. 원본 PDF의 파일 내용은 보존한다.
- 원래 존재하는 출처·저자 표기를 보존하고 게시 설명란에도 논문 출처를 정리한다. 불필요한 제작 상태 표시/새 푸터는 넣지 않는다.
- PDF에는 영상이 없는 48쪽을 실제 동영상으로 오인하지 않는다. 기존 빈 영역에 편집 가능한 흐름 도식을 보충한다.

## 자막과 슬라이드 공존

기존 `boxed-white-forest-v1`을 사용한다. 검정 텍스트/얇은 테두리, 흰색 각진 박스, 짙은 녹색 하드 그림자다. 이전 요청처럼 중심을 Motion Canvas 좌표 y=400에 두어 바닥 여백을 남기는 방향으로 시작한다.

원본 PDF의 하단 텍스트 위로 자막을 덮지 않는다. 상단의 페이지 영역과 하단 자막 여백을 분리하고 페이지는 비율 유지로 축소 배치한다. 확대할 때도 중요한 본문·축·수식이 자막 영역에 들어오지 않게 한다. 작은 글씨의 가독성을 먼저 확인하고 강조 확대를 조절한다. 무자막판과 자막판의 타이밍·장면·오디오는 동일하게 유지한다.

이 단계에서 박스 크기와 줄바꿈을 최종 확정하지 않는다. 실제 KO/EN cue 및 모든 페이지와의 겹침 검사를 통과한 뒤 확정한다. 영문 자막은 같은 타임코드에 번역한다.

## 시간과 오디오

- 현재 518문장, 문자 기반 추정 3,170~4,087초(약 53~68분). 실제 길이 아님.
- 페이지를 빨리 넘기기 위해 음성을 억지로 가속하지 않는다. 계산 흐름·결과 이미지에는 살펴볼 시간을 둔다.
- B-roll 19.5초 기본값은 이번 페이지 중심 영상에 적용하지 않는다.
- 기존 균형형을 출발점으로 숫자와 수식 설명 샘플을 먼저 확인한다. 문장 마무리와 호흡을 자연스럽게 유지한다.
- 원본에 소리가 없는 PDF 강의다. 2026-09-25 사용자가 ‘이번에는 BGM 없이 목소리에 집중’을 선택했다. 전체 영상에 음악을 넣지 않는다.
- 나레이션 표준은 `docs/NARRATION_AUDIO_STANDARD.md`다. 음악 없음은 이번 프로젝트의 명시적 예외다.
- TTS 실측 길이로 씬 시작점과 KO/EN SRT를 함께 산출한다. 현재 추정값은 렌더 시간/자막 cue로 사용하지 않는다.

## 검수 기준

대본 단계: 원본 페이지 1~88이 빠짐없이 정확히 한 번 등장, 내레이션/화면 지시 분리, 모든 보완에 출처 또는 수학적 설명 제공.

영상 단계: 원본 페이지와 대응 확인, 보완 문구 실제 화면 반영, 강조할 예시 계산 검산, 작은 한글·첨자 가독성, 자막 겹침, 실제 발화와 cue 일치, 음성 꼬리 보존, 페이지 전환시 잘림/무음 확인.

최종 공개 전 사람의 청취와 시각 검수가 필요하다. 전체 모델 추론이나 논문 성능 재현은 이번 대본 검토에서 수행하지 않았으며 영상에서도 그렇게 주장하지 않는다.
