## 독립 설명 근거

- [CDC Yellow Book: Motion Sickness](https://www.cdc.gov/yellow-book/hcp/travel-air-sea/motion-sickness.html), 2025-04-23. 감각 충돌은 설명 이론이며 개인별 반응은 다르다.02의 짧은 일반 원리만 사용. 진단·치료·약물·불편함 참기 권유 없음.
- [Xbox Accessibility Guideline117](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/117), 2026-03-04. 부가 카메라 움직임과 입력 조절 선택.04의 개발 원칙 근거.06/08/10 메뉴·전환·검수 화면은 채널의 설계 제안이며 실제 게임 UI/설정의 재현이 아니다.
- [PowerWash developer FAQ](https://steamcommunity.com/app/1290000/discussions/0/4353365966426924959/), 2025-09-18 수정. 에임/시점 분리 기능과 게임플레이 영상 수익화 허용을 확인. 효과 크기·개인 건강 결과·출시 버전의 모든 옵션을 주장하지 않는다.
