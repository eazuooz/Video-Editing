# 마리오64의 카메라맨은 누가 움직일까?

공식 매뉴얼의 **Camera Options, 인쇄19쪽**을 그림과 함께 읽고 그 순서를 제작 기준으로 삼았다. [원문→대사→장면 대응](source-order-map-v1.json)과 [KO/EN 초안](narration-draft-v1.json)을 사용한다. 매뉴얼로 확인되지 않는 개발 동기나 세계 최초 주장은 붙이지 않는다.

| 매뉴얼 순서 | 쉬운 설명 | 확보·확인할 장면 |
|---|---|---|
| 카메라맨과 C 버튼 | 마리오 이동과 찍는 자리의 이동은 다르다. | 원작 N64 녹화의 쥬게무 등장과 게임 안 카메라 안내 |
| 위·주변 탐색 | 캐릭터 위치와 보는 방향을 나누면 공간을 찾기 쉽다. | 실제 탐색의 전 상태→시점 변화→새로 보이는 대상 |
| C 위 | 가까운 시점에서 스틱으로 보고 다시 이동으로 돌아온다. | 가까운 보기와 복귀 동작; 대화 화면 확대와 혼동하지 않는다. |
| C 좌·우 | 마리오 중심으로 카메라가 돌아간다. | 같은 위치의 카메라 회전; 입력 로그가 없으므로 실제 버튼 누름을 실측처럼 표시하지 않는다. |
| C 아래 | 멀어지면 주변 공간이 더 들어온다. | 같은 장소의 가까운/먼 보기 전환; 원본에서 부족한 동작은 추가 독립 원본이나 명시한 자체 설명 모형으로 보충한다. |
| 정리 | 플레이어가 촬영자이기도 하다. | 가까이·회전·멀리 세 동작을 음성과 화면으로 되짚는다. |

Game Footage Archive에서 N64 실기(RGB 출력 수정→RetroTINK-5X→Elgato 캡처) 독립 원본을 확보했다. 녹화자의 프로젝트 이용 허용 정책을 확인했고, 실제 파일은1920×1080·60fps 무음이다. 원래4:3 게임 화면을 보존한다. 원본 소개 장면과 카메라 안내 표본은 확인했으나 모든 카메라 조작의 전후 동작·연속 재생은 아직 확인 중이다. 자료 확보를 영상 완성으로 표시하지 않는다.
