# 발라트로 60 · 테트리스 40 수정 방향

사용자 지시: 실제 게임 부분 안에서 발라트로 60%, 테트리스 40%. 본편 전체의 실제 게임 60%·설명 40%와 검정 2.5D 설명은 유지한다. 고양이 2초·회원 10초만 본편 비율에서 제외한다.

현재는 자료 검토 단계다. 이 문서는 배정 방향이며 완성 대본, 음성 실측 타이밍, 채택 구간 또는 최종 픽셀 승인이 아니다. 정확한 원본 프레임/PTS, 정상 속도 행동, 고정 자막 여백과 사용 조건을 먼저 봉인한다.

기존 317.533333초 본편의 실제 게임 10,999프레임 중 발라트로는 336프레임, 테트리스는 10,663프레임이었다. 같은 실제 게임 길이를 가정한 6,599/4,400프레임은 초기 계산일 뿐이다. 변경 해설의 실측 결과에 맞춰 두 비율을 함께 다시 계산한다.

테트리스의 역할은 진행량과 평가의 구분, 같은 줄 수의 다른 점수, 경기 중 상대 비교다. 02·03·06장의 유용한 본문과 관찰, 27줄/2,920점 차이 및 이후 141점 앞섬의 분리, 최종 승리로 오해하지 않는 문장을 보존한다. 불필요한 동일 테트리스 사례 반복을 줄이고 정확한 관찰 전후의 연속 동작을 남긴다.

발라트로는 04·05·07·08·09·10장에서 행동 이름, 손패 계산과 누적 결과, 칩·배수·목표의 다른 의미, 카드별 반응, 고정된 결과와 짧은 강조를 설명한다. 새 플레이의 실제 카드 선택·제출·기여·합산을 보고 각 주장과 연결한다. 서로 다른 손패나 몽타지 컷을 한 계산/승리로 이어 붙이지 않는다.

기존 30개 본문과 9개 관찰 안내는 보존 기준이다. 일반 설계 주장, 좋은 설명과 그 승인 PCM은 유지한다. 새 발라트로 장면과 충돌하는 ‘블록’, ‘줄’, ‘티 스핀’ 등의 화면 의존 문장과 연결 안내만 필요한 범위에서 독립 KO/EN으로 고친다. 바뀌지 않은 원문은 바이트 단위로 대조하고 승인 PCM을 재합성하지 않는다. 수정 문장의 음성만 사용자 승인 GPU 경계 인계로 만든다.

도입의 중심 질문과 성과를 읽는 세 질문을 유지하고, 실제 사례의 새 순서에 맞춰 전체 안내를 갱신한다. 20–30초는 계획이며 측정 전 길이를 승인하지 않는다. 결론의 이름·기준·변화 점검과 코칭 안내, 원래 회원 신원은 보존한다.

원래 검정 설명 7,333프레임/122.216667초를 보존한다. 화면 의존 사례가 바뀌는 도식만 의미에 맞게 수정하고 실제 움직이는 픽셀을 다시 검토한다. 새 설명은 의미 있는 비교가 있을 때만 추가하며 비율을 맞추려 무관한 카드나 대기를 늘리지 않는다.

재사용 후보 c1WD4x9Dyg0은 녹화자 Squeaky Whale Gameplay Archive의 명시적 재사용 허용과 CC BY 표시를 실제 확인했다. 설명에서 요청한 화면 크레딧/채널 링크와 기존 설명 출처 제외 지시의 예외는 사용자 응답 전 미해결이다. 취득·기술 검수는 읽기 준비이며 채택 승인이 아니다. 원본 게임 음성/음악은 사용하지 않고 승인 Nimbus를 연속으로 유지한다.

기존 비공개 oDYJlcv2Dqk 및 clean/captioned/KO/EN 원본은 보존한다. 현재 사용자는 기존 영상 삭제를 요청하지 않았다. 새 수정본 제작·전체 검수·4파일 수집·가능한 비공개 설정·선택 Git 전달이 끝나기 전 수정 완료로 표시하지 않는다.
