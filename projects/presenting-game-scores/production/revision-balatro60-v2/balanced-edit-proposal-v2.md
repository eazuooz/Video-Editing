# 게임 점수 디자인 — 발라트로 60 / 테트리스 40 수정 후보

사용자 요청: `게임 점수 디자인 원래 너무 테트리스 위주로 되었는데 발라트로 6테트리스 4정도로 맞춰서 비율을 수정해서 다시 만들어줘`.

비율의 분모는 실제 게임 구간이다. 그 안에서 Balatro 60%, Tetris 40%로 계산한다. 전체 본편은 실제 게임 60%, 검정 2.5D 설명 40%를 유지하며 원본 고양이 120프레임과 회원 600프레임만 제외한다. 음성 실측 이후 두 비율을 각각 최대 1프레임 오차로 검증한다. 기존 10999 게임 프레임을 기준으로 하면 Balatro 6599 / Tetris 4400프레임이 계획값이며 새 타이밍으로 확정된 값은 아니다.

기존 업로드 `oDYJlcv2Dqk`, 승인 PCM, 검정 설명과 원본 출력은 별도로 보존했다. 이번 요청은 기존 업로드의 삭제 승인이 아니다. 새 수정본 ID·합성·QA·비공개 저장·Git 전달은 아직 없다.

## 검토한 실제 행동과 배치 후보

11개의 서로 겹치지 않는 원본 행동 창 190초에서 실제 PTS 표본 201개 / 34판을 직접 읽었다. 1초 간격 및 마지막 프레임 표본이며 모든 중간 프레임 또는 전체 연속 동영상의 승인으로 확대하지 않는다. 원본 60fps / timebase 1/15360 / 프레임 PTS 간격 256의 연속성은 각 창의 모든 frame probe로 별도 검증했다. 표본 관찰과 세부 수치는 `native-actions-sample-direct-review-v3.json`을 따른다.

다음 표는 장별 연결을 평가하기 위한 후보이며 채택 목록·최종 편집 경계가 아니다. 긴 선택 대기, 튜토리얼 가림, 메뉴·상점·캐시아웃과 무관한 대기는 뺀다. 실제 선택·계산·합산의 순서를 보존하며 loop / slowdown / source audio는 0이다.

## 보존 및 새 해설 범위

- 원래 30문단과 9개 연결 안내 중 일반적인 점수의 이름·단위·수량/평가·비교 기준·정보 위계 주장을 유지한다.
- 변하지 않은 대사는 승인 PCM을 유지한다. Tetris 동작을 직접 설명하던 문장이나 첫 안내 순서는 새 실제 행동에 맞춰 독립 KO/EN으로 검토하고 필요한 부분만 새 장면 단위로 합성한다.
- 내레이션 실측 후 MC 길이·실제 컷·Nimbus 믹스·KO/EN 큐·챕터·회원 엔딩을 함께 갱신한다. 최종 혼합 ASR와 독립 완결 문맥을 직접 비교하고 두 decode / PTS / 동일 AAC / 모든 최종 cue·cut 픽셀을 검수한다.
- 아직 새 해설·TTS·MC 변경을 채택하거나 최종 타이밍을 확정하지 않았다. 준비 자료를 완료본으로 표시하지 않는다.

## 출처 조건과 사용자 확인 대기

새 장기 플레이의 녹화자는 Squeaky Whale Gameplay Archive다. 실제 원본 페이지는 화면 크레딧과 설명에 해당 채널·메인 채널·웹사이트 중 하나로 연결하는 링크를 요청한다. 원본 페이지의 YouTube Creative Commons 표기와 제작자 원문을 별도로 직접 읽었다. `shared/output/presenting-game-scores/revision-balatro60-v2/rights/c1WD4x9Dyg0-credit-condition.png`는 실제 설명의 화면 증거이며 local-only다.

기존 사용자의 공개 설명 출처 블록 제외 규칙에 이 영상만 예외를 둘지 비동기 질문으로 확인 중이다. 응답이 없는 것을 허용으로 간주하지 않는다. 이 결정이 나기 전에는 이 자료를 채택하거나 종속 해설/TTS/최종 업로드를 실행하지 않는다. 내부 표본과 배치 후보 검토는 계속할 수 있다.
