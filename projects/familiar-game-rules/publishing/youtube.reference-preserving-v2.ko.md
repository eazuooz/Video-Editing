# 처음 켠 게임인데, 왜 조작은 이미 알까?

처음 켠 게임인데도 이동하고 조준하는 손은 왜 익숙할까요? RAGE 2와 에이펙스 레전드의 FPS 공통 조작에서 출발해, 설명을 어디까지 줄이고 무엇을 다시 알려 줘야 하는지 살펴봅니다.

버튼 재설정(리매핑), 슈퍼 스매시브라더스 얼티밋의 아날로그 입력, 체르노브 / 아토믹 러너를 통해 버튼의 연결과 장치가 보내는 정보를 나눠 봅니다. 기본 배치·화면 안내·플레이어의 선택권을 함께 점검하고, 낯선 조작이 새로운 도전이 되는 경우까지 이어갑니다.

도식의 0~1 기울임 값은 설명용 예시이며 실제 게임의 속도나 판정 기준을 측정한 수치가 아닙니다. 입력 교환도 실제 아토믹 러너의 기본 배치와 구별한 가상 비교입니다.
