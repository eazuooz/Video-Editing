# Why Do You Already Know the Controls in a New Game?

Why do controls feel familiar in a game you have never played? Starting with shared FPS controls in RAGE 2 and Apex Legends, we examine which instructions can be shortened and what newcomers still need.

Button remapping, analog input in Super Smash Bros. Ultimate, and Chelnov / Atomic Runner help separate button assignments from the information a device supplies. We connect defaults, prompts and player choice, then consider when unfamiliar controls become an enjoyable challenge.

The 0-to-1 stick values are illustrative, not measured game speeds or thresholds. The swapped-input diagram is hypothetical, not Atomic Runner's actual default layout.
