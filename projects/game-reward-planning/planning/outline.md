### 자료 선정과 버전 확인

- 피규어·스티커는 과거 구현의 제작 비용 비교가 핵심이다. 최신작 스피릿만으로 대체하면 비교가 사라지므로 해당 구작의 독립 메뉴/플레이 녹화를 확보한다. 원강의의 화면을 추출하지 않는다.
- Ultimate 스피릿의 능력·장착·슬롯·획득 규칙은 [공식 설명](https://www.smashbros.com/en_US/howtoplay/spirits.html)에서 확인했다. 최종 용어 표기는 실제 한국어 메뉴와 추가 대조한다.
- Kirby Air Riders는 [공식 출시 안내](https://www.nintendo.com/us/whatsnew/kirbys-latest-vehicle-action-game-is-here-charge-boost-and-spin-to-attack-your-rivals/)로 출시를 확인했고, [공식 과제판 설명](https://www.nintendo.com/us/whatsnew/a-second-kirby-air-riders-direct-presentation-shares-more-new-features-modes-and-customizable-fun/)은 다섯 탭·조건 달성·인접 미해제 칸에서 목표로 이동하는 기능을 설명한다. 현대 대응 후보이며 아직 채택 확정이 아니다. 독립 플레이에서 같은 전후 관계와 구작 대비 차이를 보고 결정한다. Nintendo Direct는 연구 자료이며 편집에 넣지 않는다.
- 00:30의 장비 구매 화면은 기사가 무기 상점을 방문하는 삽화로 확인했다. 이 화면을 미확인 상용 게임으로 기록하지 않는다. 같은 교육 역할의 구매·강화 전후는 우리가 독립 제작한 도식/시연으로 설명하고 설명 분량에 넣는다. 다른 도입 화면과 커비 카피 능력 사례의 작품·버전은 추가 대조한다. 새 게임 수를 채우기 위한 추가는 하지 않는다. 기존 Wizard/Cult 소스는 보존하지만 같은 역할의 원래 사례를 밀어내는 자동 재사용은 하지 않는다.
- 각 신규 소스에 `research-reference-only`/`independent-gameplay`를 붙이고 URL·권리·인아웃·전/행동/결과를 기존 action-map에 기록한다. 확보·실시청 전 최종 내레이션과 60:40 타이밍을 확정하지 않는다.

### 설명·연출 구현

Motion Canvas는 보상 한 줄, 비용 비교, 과제판, 진행 화살표를 담당한다. 실제 게임 행동은 별도 확보한 게임 녹화가 우선이다. 독립 게임 규칙 시연이 필요해질 때만 Unity를 선택하고 씬별 `.unity`를 저장한다. 현재 저장한 신규 Unity 씬은 없다. 수식 애니메이션이 이해를 돕는 구간에 한해 Manim을 사용할 수 있으며 단순 사칙연산에 도구를 추가하지 않는다.

새 설명은 검정 바탕·흰 본문·따뜻한 노랑 강조와 기존 브랜드 토큰을 사용한다. 과거 흰 2.5D 고정 지시는 이번 수정에 적용하지 않는다. 실제 게임의 선택 항목·획득 결과·잠금 변화에는 움직임을 따라가는 윤곽/화살표를 계획하고, 게임 내부 측정값처럼 표시하지 않는다. 고정 자막 영역을 처음부터 비워 둔다.

처음 등장할 용어는 쉬운 상황→공식 한/영 표기→하나의 변화→관찰 결과→필요한 계산/제약 순서로 설명한다. 임시 용어 표: 파이터(Fighter), 피규어/트로피(Trophy; 실제 현지화 대조 필요), 스티커(Sticker), 스피릿(Spirit), 체크리스트/클리어 체커(Checklist/Challenges; 작품별 메뉴명 대조 필요). 서로 다른 작품의 메뉴명을 한 공식 명칭으로 강제 통일하지 않는다. 대본·자막·UI 표기와 TTS 읽기 별칭을 분리한다.

위 표 마지막 열을 장별 연결의 기준으로 삼아 앞 장 끝과 뒤 장 처음을 함께 쓴다. 같은 보상 행/획득 상태/작업 칸을 넘겨 주고 장 제목마다 음악과 화면을 초기화하지 않는다. 시작 인사는 한 발화로 자연스럽게 처리하고, 바뀌지 않은 승인 PCM은 복원 후 보존한다. 전체 설명 길이를 먼저 확보한 다음 관련 실제 화면을 맞추며 본편 실제60:설명40,1080p60,브랜딩2초·회원10초를 지킨다.

### 현재 복원 경계

현재 저장소에는 대본·계획·코드는 있지만 이 편의 승인 PCM, 두 완성 MP4, 계획에 적힌 게임 원본 9개가 없다. Drive의 `game-reward-planning` 검색에는 결과가 없었고, 알려진 6.07GB `media.tar`는 렌더링1 전용 인계 기록이다. 게임디자인/게임수학 미디어 백업 위치를 사용자에게 질문했다. 새 TTS/렌더는 아직 실행하지 않았고, 기존 비공개 업로드도 변경하지 않았다. 복원 위치 확인과 독립 소스 확보 뒤 이 한 편의 상세 장면·대본을 완성한다.

보상을 많이 넣기 전에 무엇을 정해야 성장 구조가 흔들리지 않을까? 보상 한 줄에 바뀌는 행동, 획득·사용 조건, 제한할 조합, 필요한 제작 작업을 함께 적는 것이 시청 후 적용할 점이다. 기존 visible-rewards의 현재 목표/HUD/욕구 설명을 반복하지 않는다. 전체 원본 강의는 개념 연구로만 쓰며 대본을 복사하거나 번역하지 않았다.

## 전체 내용을 안내하는 도입부

원본 고양이 로고 2초 직후 독립 씬01과 KO/EN 네 문장을 배치한다. 계획 기준은 약20–30초이며 실측 후 기록한다. 먼저 Wizard 탄약의 역할과 연구·제작 조건, 다음 강화·조합을 제한하는 질문, 이어 Cult 목장 역할과 배치 사례를 통한 제작 범위를 다룬다. 첫 상세 사례는 적을 얼리는 탄약과 빈틈에 길을 만드는 탄약이다. 시청자 질문·얻는 점·설명 순서·첫 사례 연결을 전체 대본/결론13과 직접 대조했다. 측정 전 시간을 맞추려고 말을 늘리거나 좋은 설명을 줄이지 않는다.

씬01은 흰2.5D 설명이므로 본편40%에 포함한다. 제외는 고양이 브랜딩2초와 회원 엔딩10초뿐이다. 13독립씬/46KO·EN문단 초안이며 최종 실측은 아직 없다.
