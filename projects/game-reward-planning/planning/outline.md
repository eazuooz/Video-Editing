## 일곱 설명의 독립 도식

- 01: 중심 질문 카드 → 기능/조건/작업 세 카드 → 첫 탄약 비교로 화살표를 연결한다.
- 03: 이름만 있는 목록을 행동별 세 열(강화/새 선택/표현·수집)로 나눈다.
- 05: 획득 시점 → 선행 연구 → 제작 재료 → 사용의 연결을 펼치고 미확인 칸을 질문으로 남긴다.
- 07: 성장 목표와 대등한 경쟁 목표를 비교하고 상한/동시 사용/교체의 세 검토 칸을 움직인다.
- 09: 외형과 기능을 두 축으로 구분하며 표현/기억/새 역할의 목적을 붙인다.
- 11: 플레이어 재료 비용과 개발 작업을 다른 면에 배치하고 아이콘/동작/효과/UI/검수 작업을 펼친다.
- 13: 한 보상 행의 기능·조건·제한·작업 빈칸을 채우고 실제 플레이와 제작 범위 양쪽에 연결한다.

모두 공유 research-paper 흰2.5D의 깊이·의미 있는 비교·화살표·움직임을 사용한다. 실제 게임은1920×1080 전체화면이다. 도식이 지배적인 화면은 설명으로 분류한다.

## 관찰 한계와 고정 자막

홍보 편집의 Completed/재료 부족 동시 표시는 정상 지불 과정의 증거가 아니다. Life Bullet의 대상 구분을 수치 비교로 확대하지 않는다. 협동 시연을 대전 게임으로 부르지 않는다. 목장 동물의 조건/동일 능력치/순수 꾸미기는 미확인이다. 개발 비용 표와 수집 후보는 우리의 설계 제안이다. 제작사 실제 문서/예산/코드라고 주장하지 않는다.

모든 내레이션 자막은 boxed-white-forest-v1 아래가운데(960,970)/MC(0,430)에 고정한다. 하단 연구 비용/경고가 겹치는 후보는 실제 편집에서 화면 구성·원본 구간·큐 분할을 고친다. 중요한 UI를 도식으로 재구성할 경우 해당 시간을 설명에 넣고 실제 행동을 추가 확보한다. 모든 최종 큐·컷 검수는 pending이며 자막을 위/옆으로 옮기지 않는다.
