## 실제 Studio에서 확인한 항목

한국어 세부정보의 **수동 자막 / 수동 / 게시됨**, 추가한 영어 세부정보의 **수동 자막 / 수동 / 게시됨**을 각각 확인했다. 두 파일은 `output/`의 납품 SRT이며 타이밍 포함 수동 파일 방식으로 등록했다. 플랫폼의 자동 한국어 자막도 존재하지만 수동 트랙을 대체하지 않았다.

영어를 별도로 언어 추가했다. 영어 제목은 `One-Button Game Design: 4 Ways to Make Simple Controls Fun | Kirby, Canabalt & Geometry Dash`이며, 영어 설명·출처·챕터·코칭·멤버십 URL을 작성하고 저장한 뒤 다시 열어 확인했다. 영어 표에서 자막 `1개 게시됨`, 제목 및 설명 `게시됨`을 확인했다.

새 한국어 영상 설명·챕터는 기존 채널 소개 위에 있으며 프로그래밍 코칭·Discord·멤버십 URL은 보존했다. 실제 저장된 설명 원문은 `upload-description.ko.txt`, 영어는 `.en.txt`이다. 미작성 수업 노트·GitHub 자리표시는 이 영상 설명에서 제외했고 채널 원문 기본값은 별도 보존했다.

썸네일 `thumbnail-v1.png`는 built-in ImageGen으로 제작한 1672×941, 1,476,324-byte PNG다. 사용자 제공 스타일 참조를 흰 바탕·노란 띠·큰 검정 글씨·빨간 강조·게임과 고양이 일러스트로 적용했다. 문구는 `버튼 하나로 왜 재밌을까?`, `원버튼 게임 디자인`, `4가지 핵심 원리`. 최종 프롬프트는 `thumbnail-prompt.txt`, 원본 참조는 `docs/references/youtube-thumbnail-20261001.png`에 보관했다. 업로드된 썸네일이 저장된 Studio 왼쪽 미리보기와 플레이어에 보임을 확인했다.

## 후속 변경 — 2026-10-01 공개 예약

사용자는 공개 설명 출처 삭제, 광고 자동 검토, 추천 간격·시간에 따른 공개 예약을 요청했고, 카드 표시 방식은 `그럼 초반에만넣어줘`로 결정했다. 위 비공개 업로드 기록은 최초 납품 당시 상태이며 현재 결과는 다음과 같다.
