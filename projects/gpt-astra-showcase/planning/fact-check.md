# 사실 확인과 해설 범위

검토 방식: X 원문 직접 웹 열기는 403. 공개 FxTwitter 메타데이터로 본문/작성자/미디어를 확인하고 X CDN 영상 파일을 내려받아 각 영상의 6개 시점 표본을 관찰했다. 게시물 응답은 media/research 캐시에 보존한다. 코드 실행·전체 개발 과정의 독립 검증은 하지 않았다.

‘GPT-6’, ‘Astra’, ‘GPT Images 2.5’ 등은 게시물 작성자의 명칭이다. 이 영상은 공식 모델 발표·사용법·가격·성능을 안내하지 않으며, 해당 명칭을 OpenAI 공식 확인 정보처럼 확장하지 않는다.
