# 구성 v3 — 중간 PPT 없이 작품 구경하기

약속: **무엇을 만들었는지** 짧고 쉽게 말하고, 시청자가 실제 화면을 구경할 시간을 준다. 제작 과정·토큰 수·복잡한 기술 설명은 빼되, 기존 캐릭터를 새로 만들었다는 오해는 막는다. 2026-09-18 사용자 승인 방향.

시청 대상: 게임개발 입문자와 AI 보조 제작에 관심 있는 개발자.

1. 도입 — 8개 사례, 11개 영상의 범위를 설명
2. 기사 캠프 — 장작 넣기·검술 연습·요리·잠자기
3. 기차 — 주행·정거장·차고를 연결한 경험
4. 가상 공간 — 가구 편집·공간 탐색·낚시
5. 작품 4종 — 운하 마을·고리 피하기·추격전·조립한 탈것
6. 캐릭터 다듬기 — 옷과 머리카락 색을 정리하고 앞뒤로 돌려보기
7. ZZZ풍 표현 — 캐릭터의 색과 그림자, 만화 같은 느낌
8. 엔드필드풍 표현 — 다른 색감으로 보여주는 캐릭터
9. 도시 — 운전·걷기·사격 장면 구경
10. 마무리 — 어떤 작품을 직접 해보고 싶은지 질문

실제 예시 221.5초 / 전체 238.5초(3:58.5), 약92.9%. 사용자 요청으로 8개 중간 PPT형 요약 화면(각3초, 총24초)을 모두 제거했다. 도입8초와 마무리9초는 유지하며 본문은 실제 사례 영상끼리 바로 연결한다. 이 프로젝트에서는 공통 실제 예시→자체 설명 페어 규칙의 예외로 기록한다. 각 사례는 최소19.5초이며 원본을 반복하거나 느리게 늘리지 않는다. 승인된 10개 음성은 재합성·배속 없이 그대로 새 시작 시각에 배치한다. 짧은 소개 뒤에는 연속 Discovery와 작은 원음을 들으며 감상할 여백을 둔다. 한글·영어 자막과 편집기 오디오도 같은 타임라인으로 변경한다. 이전 v2는 revisions/v2와 기존 review 파일에 보존한다.

톤: 사용자 본인 기준 음성의 균형형. 다른 제작자의 목소리를 복제하지 않는다. 31초 기차 장면 샘플의 목소리·속도와 Discovery를 2026-09-18 사용자가 승인했다. 전체 합성에서도 기차 장면의 승인된 음성을 그대로 재사용한다.
