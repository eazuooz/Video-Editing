# 게임은 왜 플레이어를 칭찬할까? | 성공 피드백 디자인

223.533초 최종 영상, 독립 설명 6개, 한영 자막 각각 48큐와 실제 예시 60.006%를 제작했습니다. 전체 디코딩, 현재 음성 해시의 전체 ASR, 61개 자막/컷 구간과 모바일 화면 검수를 통과했습니다. 전체 믹스는 -16.04 LUFS / -2.50 dBTP이며 두 MP4의 AAC가 동일합니다.

[비공개 YouTube 검토본](https://youtu.be/nq7NhHi9FSE) — 썸네일, 한영 수동 SRT, 영어 제목·설명, 0초 과외 링크 카드, 마지막 10초 관련 재생목록·구독 버튼을 저장하고 Studio에서 확인했습니다. 수익 창출 사용, 검토 중 알림 해소, 저작권 주장 없음이 확인됐습니다. 공개·예약은 사용자가 직접 합니다.

닌텐도 스위치 스포츠와 링 피트 어드벤처의 새 공식 구간, 직접 만든 방어 테스트 5개를 사용했습니다. 동일 입력·점수·체력을 유지하고 칭찬의 시점·문구·강도·정직함·위치만 비교합니다. 후보/권리 기록은 sources/, 실제 입력 증거와 재현 코드는 production/, 2.5D 씬은 motion-canvas/src/projects/praise-player/에 있습니다.

최종 납품은 output/praise-player/의 clean MP4, 한국어 박스 자막 MP4, KO SRT, EN SRT이며 output/index.html에서 확인합니다. 음성과 영상 파일은 Git에서 제외하고 rebuild.json으로 재현 정보를 보존합니다.

사람 전체 청취·재미 평가, Nintendo 게시 권리/개인 이용자 조건, 원래 Nimbus 파일, 잘린 회원 핸들, 외부 백업은 미완료 상태로 유지했습니다. 실제 기술 검수가 사람의 승인이나 공개 판단을 대신하지 않습니다.
