# 게임은 왜 플레이어를 칭찬할까? | 실제 게임으로 보는 성공 피드백 디자인

게임은 점수를 계산하는 것과 플레이어가 해낸 행동을 인정하는 것을 어떻게 구분할까요? 하이파이 러시의 실제 타격·퍼펙트·평가 장면과 닌텐도 스위치 스포츠·링 피트 어드벤처의 새로운 동작·결과 구간을 각 장 사이에 더했습니다. 기존 2.5D 설명과 방어·회피 비교 테스트의 내용, 시간과 내레이션은 모두 유지했습니다.

칭찬의 시점, 구체적인 행동 문구, 성과에 맞는 강도, 실패를 숨기지 않는 반응, 다음 행동을 가리지 않는 위치를 살펴봅니다. 입력 안내와 성공 평가, 한 행동의 인정과 경기 전체의 결과를 나누어 봅니다. 서로 다른 상용 게임 장면을 같은 조건의 실험으로 단정하지 않으며, 사람이 실제로 이해했는지는 플레이테스트로 확인합니다.
