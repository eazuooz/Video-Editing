We extend one AI-assisted character and workshop into a small playable room, showing the actual prompts, settings, tool outputs, pixel cleanup, measured walking cycle, and action transitions.

Play: https://yamyam-cartographers-room.eazuooz.chatgpt.site
Sit, read a map, take out a book, look through the window, or write with a quill. The room includes four weather states and a twenty-track CC0 lo-fi radio by HoliznaCC0.

Seven open-source tools, ComfyUI, and image generation were actually used. Sprite-Sheet-Diffusion setup was attempted, but official required weights were missing, so no inference output from it is used. No new character LoRA training is claimed.
