In a StarCraft II replay, you can move the view while watching a past match. That is because the game is actually running again.

The essential record is the players’ commands, rather than rendered frames. It records when they moved and which targets they attacked.

In our example, record a move at two seconds and an attack at four. During replay, feed in the same commands at the same moments.

With the same starting state and rules, movement and combat results are reproduced. This is deterministic simulation: the same conditions yield the same result.

But a patch that changes the rules could change the outcome. So the original map, game executable and data versions must match.

The random seed, the starting value for random calculations, must match too. Replay those commands under matching conditions, and the past match becomes a running game again.
