# 왜 남의 게임도 응원하게 될까?

## 독립적인 시청자 질문

조작하지 않고 다른 사람의 경기를 볼 때, 누구를 왜 응원하며 어떤 행동을 따라갈지 어떻게 알게 만들까?

원본 A_A4tgLIXO4는 관전자의 응원 대상에 관한 개념 연구에만 썼다. 이야기의 분기·진영 선택 주제가 아니다. 원문 대본·영상·음성을 복제하지 않는다. 기존 23개 프로젝트, 관련 전체 대본, 실제 Studio의 응원/관전/선택 검색을 대조하고 `preflight/picking-sides.json`의 distinct 및 생성 직전 검사 통과 후 시작했다.

## 편집 설계

6개 설명을 자르지 않고 각 설명과 맞는 실제 동작 관찰을 사이에 둔다. 대략 8~10분을 예상하지만 원본 길이를 상한으로 삼지 않는다. 최종 길이는 승인 목소리의 실제 발화와 의미 있는 동작 길이로 정한다. 인트로 2초·회원 10초를 제외한 실제 동작 E초, 설명 P초에 대해 E=1.5P를 프레임 단위로 맞춘다. 현재 시간은 목표이며 실측 완료가 아니다.

## 출처 구간 확정 절차

- UCH `4KBUHwBx5i4` 78.067초, Gang Beasts `tNgCy92QWZY` 58.191초를 원본 속도로 확보했다. 4초/3초 간격 전체 접촉표로 실제 동작을 확인했다. 정확한 컷 in/out·첫/중간/끝 프레임과 자막 겹침 검수는 아직 남았다.
- 예상 후보는 UCH 초반 지붕의 도약/공동 결승선, Gang Beasts 부표·컨테이너·승강기에서 잡고 매달리는 구간이다. 광고 카드·로그·점수표·편집 전환은 실제 시간에 넣지 않는다. 아직 확정되지 않은 구간 수치를 승인된 컷으로 기록하지 않는다.
- 자체 `Cloudpost Relay`의 실행 입력·시드·선택 대상·카메라 모드·시작/종료 프레임을 테이크마다 저장한다. 도약·충돌·목표 도착 같은 의미 있는 사건이 부족한 테이크는 폐기 표시하고 실제 비중을 채우는 용도로 늘리지 않는다.
- 대본은 녹화된 행동과 대조한 뒤 TTS를 시작한다. 기술 검증만으로 사람이 더 몰입하거나 즐겼다고 주장하지 않는다.

## 고정 제작 조건

승인 Qwen3-TTS 1.7B 목소리와 연속 Nimbus, 원본 고양이 2초, 전체 화면 게임, 흰 2.5D 설명, 10초 원본 회원 엔딩을 유지한다. 모든 내레이션 자막 중심은 (960,970); 화면을 재구성할 뿐 자막을 옮기지 않는다. 한글 고정 자막 MP4만 YouTube 기본 업로드에 쓰며 KO/EN SRT도 수동으로 올린다. 비공개 유지, 실제 CC-off 픽셀·설정·광고 검수, 한 편 완료 후 선택 커밋·일반 푸시까지 진행한다.

## 현재 상태

중복 사전 검토 후 독립 한영12장·72문단 초안과 자체 경주를 만들었다. 새8테이크 소스 렌더·전체 디코딩·24개 첫/중간/끝 화면 직접 검수를 마쳤다. 공식 원본도 2개 예고편에 더해 긴 개발/플레이 자료3개를 확보하고 접촉표 및 주요 구간을 직접 확인했다. `action-map.json`은 시간 범위와 주장 연결을 저장한 편집 후보이며 최종 타임라인이 아니다.

초안의 잘못된 경로·발판·겹침 주장과 구현을 대조해 고쳤다. 자체 전체 조망은 설명으로 분류하며 8테이크를 전부 사용하는 목표를 세우지 않는다. 실제 상용 게임 장면을 주제 설명 사이에 충분히 배치하고 여섯 기존 설명을 보존한다. 정확한 컷, 대사별 동작, 전체 화면 구성과 아래 가운데 자막 공간, 60:40 실측은 남아 있다. TTS·독립2.5D 장면·최종 렌더·수집·업로드는 아직 없다.
