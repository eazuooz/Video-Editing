# 최종 오디오 믹스 보고서

검수일: 2026-09-06

## 구성

| 레이어 | 적용 구간 | 기준 |
| --- | --- | --- |
| 한국어 내레이션 | 전체 | -16 LUFS 목표 |
| 원본 게임·기술 영상 소리 | 각 씬 시작 6.5초 | 장면별 -23 LUFS 목표 + 약 3dB 내레이션 사이드체인 덕킹 |
| `Nimbus — Eveningland` | 영상 처음부터 끝까지 연속 | -28 LUFS 목표 + 내레이션 덕킹, 원음이 겹칠 때 BGM만 추가 -3dB |
| 원음 예외 | 07번 | 선택한 Celeste 구간이 사실상 무음이므로 원음을 추가하지 않고 연속 BGM 유지 |

BGM과 게임 원음은 교대하지 않고 함께 재생한다. 씬 경계에서 곡을 끊거나 다시
시작하지 않는다. 게임 원음이 시작·종료될 때 0.45초에 걸쳐 BGM의 겹침 감쇠만
조절한다. 전체 시작·끝에는 0.45초 페이드를 적용하며, 약 280.6초 길이 곡은
끝과 다음 시작을 1초 크로스페이드로 겹쳐 반복한다.

03번 Street Fighter II에는 원본 오디오를 다시 결합했다. 19번은 Street Fighter II와
Alan Wake 2, 20번은 네 개 패널의 원본 소리를 각각 낮춘 뒤 섞었다. 따라서 영상에 쓰인
원본 소리를 임의로 무음 처리한 장면은 없다.

## 자동 재생성

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/mix-frame-rate-audio.ps1
```

이 스크립트는 원본 영상을 직접 덮어쓰기 전에 임시 MP4를 만들고 스트림·길이를 검증한다.
성공한 경우에만 `shared/output/motion-canvas/frame-rate-modern-rendering.mp4`를 교체한다.
동시에 MP4의 AAC 패킷을 재인코딩 없이 `assets/final-mix.m4a`로 추출하여
Motion Canvas의 프로젝트 오디오로 사용한다. 소스 내레이션 WAV는 유지한다.

배경 트랙만 별도로 검사하려면 `-ExportBackgroundReview` 옵션을 붙인다.
검수용 WAV는 `shared/output/motion-canvas/frame-rate-modern-rendering-qa/background-only.wav`에
생성된다. 이 검수 폴더는 Git 추적 대상이 아니다.
`bgm-only-before-narration-ducking.wav`도 함께 생성한다. 이것은 원음 겹침용 -3dB를
포함하되 내레이션 덕킹 전의 BGM만 담아, 게임 구간과 곡 반복의 음악 연속성을 검사한다.

## 미리보기 누락 수정

- 편집기의 `audio`가 내레이션 WAV만 가리키던 것을 전체 믹스로 교체했다.
- 여러 지연 트랙을 합치는 `amix`에 `normalize=0`을 명시했다. 기본 정규화가
  아직 소리가 나지 않는 트랙까지 세어 초반 배경음을 최대 약 32dB 줄이던 문제를 해결했다.
- 내레이션 설정은 유지하고 원음·BGM의 설정 음량이 실제 믹스에 반영되도록 수정했다.
- 개별 HTML Video 요소는 음소거해 마스터 믹스의 게임 원음이 이중 재생되지 않게 했다.
- 씬 경계를 Motion Canvas 타이밍 생성기와 동일한 30fps 격자에 맞췄다.

## 검수 결과

- 영상: 1920×1080, 60fps, 445.8초, H.264
- 오디오: AAC, 48kHz, 스테레오
- 전체 통합 음량: -16.9 LUFS
- 최대 트루피크: -1.7 dBTP
- 1초 이상 -50dB 이하의 완전 무음 구간: 없음
- 20개 씬의 BGM 단독(내레이션 덕킹 전) 표본 측정: 게임 구간 평균 -33.3~-28.1dBFS,
  설명 구간 평균 -31.5~-27.9dBFS. 각 씬 시작 +0.5초부터 5.5초,
  +7초부터 최대 8초를 측정했으며, 모든 표본에서 BGM이 확인됐다.
- 게임→설명 전환 20곳(+6.25초부터 0.5초)에서도 BGM이 유지된다.
  곡 반복 지점(279~281초) BGM 평균은 -30.9dBFS다.
- BGM의 -50dB 이하·0.3초 이상 구간은 의도한 마지막 페이드뿐이다.
  양 끝 0.45초를 제외한 내부에는 해당 무음 구간이 없다.
- MP4와 편집기 M4A의 AAC 패킷 SHA-256 일치:
  `ac8b93d303a48016c503bdaea8a934a9c2d3f09b814282c483e8ba6683d17aab`
- 영상 스트림 SHA-256은 믹스 전후 동일하다. 화면, 전체 길이, SRT는 변경하지 않았다.
- 브라우저 검사: 전체 믹스가 8초 이후 설명 구간까지 재생되고, 게임 Video 20개는
  중복 소리 방지용 음소거 상태임을 확인했다. 페이지 오류 없음, 렌더의 include audio 활성화.
- 최종 MP4 SHA-256: `d64b6c14b7089623a17bc81e5ad4b5b13439c1dce3440d07e28d401d0dd9fa4b`

## 게시 전 주의

`Nimbus`의 표기 정보는 한국어·영어 설명란에 넣었다. 배경음악과 별개로, 게임·기술
B-roll의 원본 음성이나 음악은 권리자가 Content ID로 감지할 수 있다. 게시 전에는
일부 공개 또는 비공개 업로드로 YouTube의 저작권 검사를 먼저 통과시키고, 문제가 잡힌
특정 구간만 효과음 중심 소스로 교체하거나 원음을 더 낮춘다.
