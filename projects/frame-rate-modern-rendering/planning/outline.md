# 게임의 프레임 레이트는 무엇일까? 30 FPS부터 DLSS까지 — 구성안

## 핵심 질문

FPS는 단순한 숫자가 아니라 게임 시간, 렌더링 예산, 디스플레이 출력과 입력 지연을
어떻게 연결하는 개념인가?

## 시청자가 얻어갈 것

프레임, 시뮬레이션 업데이트, 직접 렌더 프레임, 생성 프레임, 표시 프레임과 모니터
주사율을 서로 구분하고 게임 개발 시 목표 프레임 타임을 설계할 수 있다.

## 전체 구성

| 구간 | 장면 | 핵심 시각화 |
| --- | --- | --- |
| 기본 개념 | 01–04 | 움직임 정지, 프레임 카드, 30/60 FPS 동일 거리 비교 |
| 시간과 예산 | 05–09 | 밀리초 예산, 프레임 타임 그래프, deltaTime, NTSC/PAL |
| 콘솔과 GPU | 10–13 | Quality/Performance 저울, GPU 작업 큐, 4K 픽셀 격자 |
| AI 렌더링 | 14–18 | Super Resolution 파이프라인, R/G 프레임 타임라인, 지연 파이프라인 |
| 실무 연결 | 19–20 | 과거/현대 파이프라인 비교, 개발자 체크리스트 |

각 장면은 `실제 게임 예시 약 6.5초 → 채널 자체 모션그래픽 설명`의 한 쌍으로
구성한다. 실제 영상은 개념을 눈으로 확인시키는 역할만 하고, 정의와 결론은 자체
그래픽에서 전달한다.

## 디자인 원칙

- 1920×1080, 60fps, 어두운 남색 배경을 기준으로 한다.
- 직접 렌더 프레임은 파란색 `R`, 생성 프레임은 보라색 `G`로 통일한다.
- 긴 문장 대신 숫자, 짧은 용어, 그래프와 타임라인을 사용한다.
- 동일 시간 비교에서는 캐릭터의 출발점과 도착점을 항상 같게 둔다.
- 실제 게임 영상은 짧은 인용과 출처 표시에 한정하고, 고유 광고 레이아웃을 자체
  그래픽으로 복제하지 않는다.

## 정확성 기준

- FPS와 Hz, 렌더 FPS와 표시 FPS를 동일시하지 않는다.
- deltaTime은 가변 업데이트 예시로 쓰고 물리는 고정 타임 스텝을 쓸 수 있음을 함께 설명한다.
- PS5 모드는 일반적인 방향만 보여 주며 구체적인 목표 수치를 단정하지 않는다.
- DLSS Super Resolution과 Frame Generation을 별도 단계로 표현한다.
- DLSS 4 출시 시점의 최대 3개 생성 프레임과 2026년 DLSS 4.5의 확장을 구분한다.
