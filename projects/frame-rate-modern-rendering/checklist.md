# 제작 체크리스트

## 기획

- [x] 시청자가 얻어갈 한 문장을 정했다
- [x] 도입, 본론, 결론의 흐름을 만들었다
- [x] 각 씬을 실제 게임 예시와 자체 제작 그래픽의 페어로 구성했다
- [x] 기술 사실을 공식 자료로 확인했다

## 음성·자막

- [x] 내레이션 대본과 용어를 검토했다
- [x] TTS를 `Qwen3-TTS 1.7B balanced v2`로 교체했다
- [x] 장면 단위 연속 발화로 문장마다 끊기는 종결 어미를 개선했다
- [x] 기준 음성의 발화문을 함께 사용하는 고품질 복제 모드로 전환했다
- [x] 문장 끝 잘림·클리핑 자동 검사를 통과했다
- [x] 전체 음성 받아쓰기 검수 파일을 생성했다
- [x] 한국어 SRT 타이밍을 확인했다
- [x] 영어 번역 SRT를 만들었다

## 영상

- [x] Motion Canvas 20개 장면을 제작했다
- [x] 이 영상에는 별도 Manim 장면이 필요하지 않다고 결정했다
- [x] 20개 씬에 6.5초 실제 게임·공식 기술 B-roll을 배치했다
- [x] 20개 설명과 B-roll의 의미 대응을 전수 검토했다
- [x] 단순 반복 원본을 제거하고 격투·슈팅·PAL/NTSC 사례를 보강했다
- [x] 모든 B-roll의 시작·중간·끝 프레임과 1280×720·60fps·6.5초 규격을 확인했다
- [x] 교체한 B-roll로 1920×1080·60fps 전체 영상 검수본을 다시 렌더했다
- [x] 완성 MP4에서 20개 B-roll과 20개 모션그래픽의 대응 프레임을 재확인했다
- [x] 기술 문서와 영상 원본 URL·인용 시간을 기록했다
- [x] 음성·장면 길이 동기화를 검사했다
