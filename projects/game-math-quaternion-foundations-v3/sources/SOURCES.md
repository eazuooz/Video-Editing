# 쿼터니언 네 게임 비교

기존 라이더스 리퍼블릭 자료와 권리 기록은 이전 판을 보존합니다. 새 후보의 원본 URL, 선택/제외 구간, 정상속도 비교, 출처 조건은 candidate-comparison.json에 기록했습니다.

화면 선과 모든 수치는 설명용입니다. 게임 세계의 실제 각도 또는 독점 엔진 구현을 측정했다고 주장하지 않습니다.

비시지는 사용자가 필수 링크 두 개 추가를 명시적으로 승인했습니다. 한영 설명란 파일에 원본 영상과 공식 사이트 링크 두 개를 준비했습니다. 실제 저장·재열기 확인은 업로드 후 별도로 기록합니다. 다른 출처와 게임 IP의 사람 검수는 현재 상태대로 남깁니다.
