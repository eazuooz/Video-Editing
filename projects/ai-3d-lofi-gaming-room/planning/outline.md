# AI 도구로 LOFI 웹게임 따라 만들기

2026-11-17 사용자 정정: 개발 일지와 수정 순서를 따라가는 영상이 아니라 AI 도구에 넣을 입력·요청문·설정과 결과를 공유하는 튜토리얼이다. 같은 캐릭터와 방을 끝까지 사용한다.

기본 경로는 ChatGPT 이미지 생성 → Tripo H3.1 생성·Retopo·Rigging → Codex와 프로젝트 범위 Unity CLI/MCP → Unity URP/WebGL이다. Meshy·ComfyUI/Hunyuan3D·Blockbench·Material Maker·Mixamo·DeepMotion은 역할별 대안이며 실제 이 게임의 출력으로 꾸미지 않는다.

| 단계 | 주제 | 입력·설정·확인 |
|---|---|---|
| 1 | AI로 같은 방을 만드는 세 단계 | INPUT → MODEL → PLAY |
| 2 | 먼저 고를 핵심 도구 | 그림 / 모델 / 코드 / 실행 |
| 3 | 이미지 AI에 방의 기준 요청하기 | 따뜻한 목재 방 / 숲과 달 / 이동 통로 |
| 4 | 캐릭터 입력 이미지는 전신으로 | 전신 A-pose / 손·발 노출 / 단순 배경 |
| 5 | 소품도 한 개씩 분리해서 요청하기 | 소품 한 개 / 전체 윤곽 / 로고·받침대 제외 |
| 6 | Tripo에서 이미지로 모델 생성하기 | 참조 이미지 → 생성 → 앞·옆·뒤 검사 |
| 7 | 모델 생성 도구를 바꾸고 싶다면 | Meshy 또는 ComfyUI + Hunyuan3D |
| 8 | Retopo로 게임용 메시 정리하기 | 캐릭터 Quad 10K / 소품 Triangle 2K |
| 9 | 모델·텍스처·뼈대를 함께 넘기기 | FBX + PBR maps + animation |
| 10 | PBR 텍스처를 Unity에 연결하기 | Base Color / Normal / Roughness / Metallic |
| 11 | MCP로 AI와 Unity 연결하기 | 프로젝트 경로 지정 / 씬·실행·빌드 도구 |
| 12 | Codex에 방과 가구 만들기 요청하기 | 미터 단위 / 분리된 가구 / 몸에 맞는 치수 |
| 13 | 재질은 색과 표면을 나눠 요청하기 | 나뭇결 방향 / 무광 천 / 약한 요철 |
| 14 | Tripo 리깅과 기존 동작 연결하기 | Walk / Idle + 기존 Sit / Lie clips |
| 15 | Mixamo와 DeepMotion을 고르는 기준 | Mixamo: 기존 클립 / DeepMotion: 영상 → 모션 |
| 16 | 행동 전환 요청문을 구체적으로 쓰기 | Walk → Align → Enter → Loop → Exit |
| 17 | 걷기 클립과 실제 이동을 연결하기 | 클립 이동량 → 경로 이동 / 바닥 접촉 |
| 18 | 아이맥 앞에 차분하게 앉게 만들기 | 접근 / 정렬 / 차분한 앉기 / 키보드 접촉 |
| 19 | 빈백 독서는 책과 양손을 같이 맞추기 | 책의 법선 → 얼굴 / 손은 양쪽 바깥 / 팔꿈치 분리 |
| 20 | 머리카락에 작은 지연 더하기 | 뿌리 고정 / 끝의 지연 / 길이·충돌 제한 |
| 21 | 식물과 창밖 풍경 구성하기 | 잎 밑부분 고정 / 숲 레이어 / 낮·밤 연동 |
| 22 | 창문 영역에만 비 내리게 하기 | 배경 → 비·물방울 → 창틀 |
| 23 | 벽난로는 불꽃·빛·소리를 묶기 | 불꽃 + 잔불 + 주변 빛 + 별도 장작 음량 |
| 24 | 로파이 열 곡과 레코드 연결하기 | 곡 선택 / 자동 다음 곡 / 재생 상태 → 회전 |
| 25 | 삼색고양이에 필요한 요청 조건 | 흰 바탕 + 적은 삼색 무늬 / 무광 / 작은 호흡 |
| 26 | 화면 안 메모와 로컬 저장 | 한글 입력 / 단축키 분리 / 새로고침 복원 |
| 27 | 집중 타이머는 시각으로 계산하기 | 종료 시각 − 현재 시각 / 일시정지·복원 |
| 28 | Unity Web 빌드와 실제 브라우저 확인 | 동일 버전 모듈 / 씬 지정 / HTTP 실행 |
| 29 | 그대로 따라 할 입력과 결과 묶기 | 기준 이미지 / 출력 파일 / 기능별 요청문 |
| 30 | 완성 기준은 직접 조작되는 방 | 모델 → 행동 / 입력 → 반응 / 저장 → 복원 |
| 31 | 이미지·모델·게임으로 이어가기 | 이미지 → 모델·동작 → 플레이 |

원본 입력 그림과 실제 Tripo 작업 화면, 같은 방의 최신 실행 캡처를 사용한다. 요청문 카드는 자체 설명 화면으로 표시하며 도구 UI를 흉내 내지 않는다. 예시 프롬프트는 재현용 지시이고 과거 도구에 그대로 제출한 기록이라고 주장하지 않는다.

고양이는 반복된 얼룩·광택을 줄이고 연속된 꼬리로, 독서는 책 방향·손목 축·팔꿈치·전환을 함께 확인한다. 실제 프레임과 대본에 맞춘 위키 방법론 글을 같은 페이지에 갱신한다. 완성 로컬 전체 파일 검수 이후 업로드 경계는 유지한다.
