# 게임 시나리오 — 선택과 순서가 바뀌어도 말이 되게

2026-10-02 독립 제작. 참고 주제는 개념 연구에만 사용했다. 원문 전체 복사/번역과 참고 영상·음성 재사용은 없다. 생성 직전 전체 21개 기존 프로젝트의 활성 보강 대본까지 해시와 내용을 확인하고 실제 Studio의 시나리오/스토리/대사/이야기 검색을 대조했다. [현재 사전 검토](../../../production/batches/sakurai-planning-game-design/preflight/game-writing.json)는 distinct다. 기존 퀘스트의 목표/보상, 튜토리얼의 시작 속도, 입력 응답, 성공 칭찬과 범위를 구분한다.

## 구성과 길이

12개 독립 대본/씬은 실제 관찰 01 → 설명 02 → 실제 관찰 03 → 설명 04 순서로 여섯 쌍을 이룬다. 핵심 설명을 유지하면서 각 장의 조건을 실제로 실행한 예시와 새 해설을 연결한다. 참고 재생목록의 원래 길이를 상한으로 두지 않는다. 사용자가 확인한 것처럼 필요한 예시를 더한 우리 영상은 원본보다 길어질 수 있다.

고양이 인트로 2초와 원본 회원 엔딩 10초를 제외한 본편은 실제 게임/개발 동작 60%, 흰 2.5D 설명 40%다. 지금 적힌 시간은 계획이며 TTS 실측과 컷별 검수 전에는 최종 길이·비율을 주장하지 않는다. 도식·숫자 중심의 자체 테스트 녹화는 설명으로 계산한다. 이번 `항구의 봉인`은 마을을 이동하고 선택·소유·대화를 바꾸는 실제 게임 화면이므로 그 동작을 보여주는 구간만 actual로 분류한다. 상태표/그래프/로그를 크게 보여주는 정리는 explanation이다.

## 장별 주장 → 실제 동작 → 관찰 지점 → 설명 연결

| 대본 씬 | 주장과 실제 동작 | 출처/초기 인아웃 | 시청자가 볼 곳 | 다음 2.5D 설명과 연결 |
|---|---|---|---|---|
| 01 → 02 | 대화 선택과 순서가 달라져도 문장의 조건이 맞아야 한다. 자체 게임에서 문지기 먼저/게시판 먼저 방문 | DOS2 overview 46–47.8의 여러 답 선택, GM 462–475; 자체 문지기 먼저 실행 | 답 목록과 방문 전후 정보의 차이 | 장면번호 열과 현재 사실 열을 깊이 있는 두 판으로 비교 |
| 03 → 04 | 읽은 사실과 상대에게 전한 사실을 분리한다. 자체 게임에서 게시판 읽기 → 대화 → 정보 전달 → 재대화 | DOS2 overview 47.8–50.5의 Caryl/Ifan 대화; 자체 게시판 먼저 실행 | 게시판 읽기 뒤에도 아직 상대에게 전하지 않은 답이 남음 | 세계/플레이어/문지기 세 카드 사이 정보 전달 화살표 |
| 05 → 06 | 이야기 물건의 현재 소유자/접근 가능성을 확인한다. 반지 제작과 증표 맡기기/동료 쉬기/회수 | GM 1229–1253, 1257–1268; 자체 `absent-owner`/`recovery` | 실제 생성된 반지, 증표를 보여주는 답의 유무와 회수 후 복구 | 과거 획득 기록은 고정, 현재 소유자 토큰은 이동 |
| 07 → 08 | 다른 선택이 합류해도 결과를 잃지 않는다. 실제 사건 선택지 편집과 자체 먹이/우회 경로 실행 | GM 476–490, 513–526; 자체 `feed-route`/`detour-route` | 식량 0/1, 이동 1/3분, 항구 대사의 실제 행동 언급 | 갈라진 경로를 합류시키되 차이 토큰을 함께 운반 |
| 09 → 10 | 설명을 놓쳐도 필수 사실은 이야기 설정에 맞게 다시 얻는다. 설명 넘기기 → 문지기 → 게시판 → 다음 행동 | GM 429–447의 지도→사건카드 전환 후보; 자체 `skip-essential` 추가 촬영 | 아직 받은 적 없는 물건을 요구하고 출처를 알려 주는 대화 | 필수 통행 사실과 선택 배경을 두 깊이의 카드로 구분 |
| 11 → 12 | 다른 순서/소유/경로로 대사를 직접 실행한다. 정순서·설명 생략·동료 부재·경로 합류 | 자체 다섯 경로의 새 정상 속도 실행 | 누른 선택이 실제 대사와 상태로 이어지는 과정 | 실행 결과를 조건별 행으로 정리하고 작성자 질문으로 마무리 |

표의 공식 source 인아웃은 native 샘플을 본 초기 편집 후보다. 최종 선택은 현재 음성 길이를 기준으로 최초·중간·끝/실제 동작 전환을 다시 보고 확정한다. 같은 공식 구간을 두 장에서 자동 재사용하지 않는다. 짧은 대화/선택은 짧게 쓰고 서로 다른 자체 동작을 추가한다. 소스의 설명자 얼굴·로고/법적 표시를 임의 제거하지 않으며 원래 오디오는 제외한다. 원본 선택지 편집이 자동 조건 분기를 구현했다고 주장하지 않는다.

다이얼로그 자료 재확인에서 overview 121–134초는 이름 인식 대화가 아니라 전투/별도 인물 장면으로 확인해 03장의 후보에서 제외했다. Caryl이 Ifan의 이름을 부르는 실제 장면은 47.8–50.5초다. 짧은 원본을 해당 대사 전체만큼 늘리지 않으며, 짧은 관찰 직후 새 자체 실행으로 연결한다. 01장과 03장의 자체 방문 순서도 서로 다른 새 실행으로 촬영하고 같은 녹화 구간을 재사용하지 않는다.

## 원본 시연과 자체 검증의 경계

- DOS2 공식 영상은 인식이 표현되는 대화, 선택지 편집, 물건 생성 등 보이는 동작의 예시다. 보이지 않는 내부 조건 구현이나 다음 줄거리의 결과를 추정하지 않는다.
- `playtest/story-state.cjs`와 `playtest/index.html`은 우리 고유 이야기/그림/코드다. Larian 인물·대사·음성·그래픽을 생성하거나 모방하지 않았다. 화면에 자체 제작임을 표시한다.
- 최신 상태 모델 13개 시나리오, 도달 가능한 4,581개 사실/대화 상태와 2,930개 표시 선택의 유효성을 실행 검증했다. UI의 실제 여섯 경로/58입력 증거는 별도 파일로 수집했다. 이전 결과는 `-pre-reboot.json`에 보존한다. 사람의 재미·감정/이해 검토를 완료로 판단하지 않는다.
- 플레이어가 모르는 규칙을 공유하는 답과 부재한 동료의 물건을 보여주는 답을 실제로 막는다. 합류 후 결과 기록이 유지되는지 검사한다. 소유자 기록과 과거 획득을 섞지 않는다.

## 제작/검수와 재개

재부팅 뒤 실제 GPU 여유와 다른 합성 여부를 확인해 단일 runner를 재개했다. 기본 12장 합성을 마치고 현재 해시의 CPU ASR을 직접 대조하는 단계다. 이전 템플릿 0.1초 WAV와 설명 lookdev는 완성본이 아니다. 설명은 보존하며 [추가 관찰 계획](observation-insertions.json)의 새 실제 입력과 한영 해설을 네 위치에 더한다. 최종 길이·6:4 비중은 전체 검수 음성/컷 실측 뒤 확정한다.

같은 승인 Qwen3-TTS 1.7B/reference-text 목소리와 연속 Nimbus를 사용한다. 단일 TTS 실측 → 현재 WAV 전체 ASR 직접 대조 → 타이밍/컷/양언어 SRT/챕터/엔딩 동시 확정 → 실제 렌더 → 모든 큐/컷 시각 검수와 디코딩/음량/동일 오디오 → 4파일 수집 → 새 비공개 모든 설정 저장 → 선택 커밋/일반 푸시 순서다. 렌더·업로드·Git 완료는 실제 증거가 있을 때만 기록한다.
