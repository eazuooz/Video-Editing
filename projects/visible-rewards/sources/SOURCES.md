## 실제 사용 컷과 검수

정확한 초 단위 인점·길이·동작·원음 목표는 [gameplay-cuts.json](gameplay-cuts.json)이 기준이다.
총 실제 예시 156초(8 × 19.5초). 서로 겹치는 원본 구간은 사용하지 않았다.
클립을 반복하거나 정지·저속 재생해 길이를 채우지 않았다. 원본 자체 편집은 유지한다.
초기 확보한 Game Database Live의 tCAd9M1SIe8 영상은 내용 불일치로 최종 제외했다.

- 스타듀밸리: [ConcernedApe의 영상·스트리밍 수익화 허용](https://www.stardewvalley.net/stardew-monetization-policy-for-twitch-streamers-youtubers-etc/), [공식 FAQ](https://www.stardewvalley.net/faq/). 타 업로더의 녹화물 허가는 위 별도 근거로 확인.
- Vampire Survivors: 해당 녹화 업로더의 명시적 사용 허가/CC 라이선스에 따라 설명과 함께 편집. poncle의 게임 IP 소유권이 이전되는 것은 아니다. 광고용 자산 재배포·게임 파일 재배포·OST 단독 사용으로 확대하지 않는다. 플랫폼의 자동 Content ID 판정을 보장하지 않는다.
- YouTube CC: [플랫폼 안내](https://support.google.com/youtube/answer/2797468), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). 원본 링크·제목·업로더·편집 사실은 한영 설명란에 표기.
- 원본 메타데이터: `shared/output/visible-rewards/media-cache/<id>.info.json`. 로컬 캐시에 보존하며 전체 원본을 저장소 배포물로 올리지 않는다.
- 2번은 광산·수집·공간 제약의 상황 자료다. 서로 다른 녹화/시점의 인벤토리를 한 세이브의 연속 진행으로 주장하지 않는다.
- 1·3번의 1,700G/300G는 대본의 가정이며 실제 HUD를 바꾸지 않았다. 별도 흰 여백의 가정 표시와 자체 도식을 사용.
- 7번 확률 재료는 특정 게임 규칙이 아닌 가상 사례. 자료화면에서도 이를 명시.
- 녹화자의 얼굴 카메라와 원래 표식은 지우거나 다른 인물로 바꾸지 않았다. 외국어 해설은 우리 음성보다 작게 설정.
- 720p 가방 구매 원본은 비율을 보존해 1080p 출력에 확대. 가짜 고해상도 원본이라고 표현하지 않는다.
