## 이번 대본에 제안하는 연출

| 장면의 역할 | 표현 | 피할 것 |
|---|---|---|
| 질문 | ‘되겠는데요?’를 가볍게 올리고 잠깐 여유 | 매 문장 끝을 모두 올리기 |
| 기대 | ‘딱 삼백’처럼 핵심어 한 곳 강조 | 전체 문장 고음·고속 |
| 달성 | ‘드디어’에 작은 미소와 만족감 | 함성·광고식 과장 |
| 원리 | 상대적으로 차분하고 명료하게 | 강조 없는 숫자 나열 |
| 주의·결론 | 속도를 살짝 정리하고 말끝 온전히 닫기 | 마지막 ‘~다’를 조기 잘라내기 |

아래는 연출 의도이지 모델의 감정 파라미터가 아니다.
- 01: 회상은 편하게, ‘딱’에서 작은 기대, 질문은 가볍게 올린 뒤 설명으로 복귀.
- 02: 불편함은 공감하듯, ‘가방이 갖고 싶어집니다’는 작은 깨달음. 불평·조롱하지 않음.
- 03: 현재·목표를 또렷하게 구분하고 ‘삼백’만 강조. 산수 문제를 읽듯 단조롭게 나열하지 않음.
- 04: ‘드디어’에 미소 정도의 만족감, 다음 문장은 다시 담백하게. 환호·과한 고음 금지.
- 05: 수집→레벨업은 조금 경쾌하게, ‘무엇이 나올지’에는 호기심. 정보 설명의 발음은 유지.
- 06: ‘전부 붙이면’은 가벼운 반문, 핵심 두 유형은 속도를 낮춰 대조.
- 07: 첫 질문은 기대 후 의문, 확률 설명부터 진지하고 또렷하게. 과한 실망 연기 금지.
- 08: 세 질문마다 짧은 호흡, 결론은 차분한 확신. 마지막 어미까지 충분히 발화하고 자연감쇠 확보.

## 샘플 제작안

2026-09-15 사용자 ‘진행해줘’로 대본과 비교 문구 승인. 비교 샘플 생성 진행.
이전에 받은 링크 자체는 참고 자료이며, 원본 화자를 복제하는 승인이 아니다.

> 오늘은 여기까지만 하려고 했는데, 가방을 사기까지 딱 삼백 골드가 남았습니다. 아, 이것만 더 모으면 되겠는데요? 그리고 드디어, 가방을 샀습니다. 중요한 건 큰 보상 하나가 아닙니다. 내가 원하는 변화에 얼마나 가까워졌는지 보여주는 것이죠.

- A: 기존 Qwen3 1.7B Base / 사용자 기준 음성 / 동일 문구.
- B: Chatterbox Multilingual / 같은 사용자 기준 음성 / 동일 문구 / 표현 강도 중간부터 실험.
- 엔진이 달라지므로 B가 더 자연스럽거나 화자 유사도가 더 높다고 미리 단정하지 않는다.
- 같은 청취 음량으로 정규화하고 BGM 없이 비교. 원본 WAV·메타데이터 보존.
- 피치/속도 일괄 변경만으로 감정이 구현됐다고 설명하지 않는다.
- 성능 지시는 합성할 텍스트나 최종 자막에 섞지 않는다.
- 한 문장씩 과도하게 잘라 합성하지 않고 비교 문단을 연속 발화한다.

## 기술 확인

Qwen3 Base의 generate_voice_clone에는 직접적인 instruct 인수가 없다.
기존 화자를 유지한 채 감정 이름을 자유롭게 지정할 수 있다고 약속하지 않는다.
문장·문장부호·실제 기준 발화의 운율과 테이크 선택으로 개선을 검토한다.
CustomVoice의 지시 기능은 제공 화자를 대상으로 하므로 사용자 클론과 혼동하지 않는다.

- Qwen 공식: https://github.com/QwenLM/Qwen3-TTS
- API 구현: https://github.com/QwenLM/Qwen3-TTS/blob/main/qwen_tts/inference/qwen3_tts_model.py
- Chatterbox 공식: https://github.com/resemble-ai/chatterbox

로컬 voice-clone 환경의 Chatterbox는 mtl23ls_v2 모델을 참조하며 generate에
exaggeration / cfg_weight가 있다. 최신 V3 설치가 확인됐다는 뜻은 아니다.
2026-09-15 캐시 점검에서 ve.pt와 토크나이저 등은 존재하지만
t3_mtl23ls_v2.safetensors, s3gen.pt는 snapshot에 없었다.
이후 같은 날 누락 가중치를 다운로드하고 로컬 GPU 합성까지 검증했다.
사용 체크포인트: 5bb1f6ee58e50c3b8d408bc82a6d3740c2db6e18 / chatterbox-tts 0.1.7.
원본 기준 음성은 외부로 업로드하지 않았다. 상세 결과는 voice-comparison-review.md 참고.

## 합격 기준

1. 원래 사용자 화자처럼 들리는가 — 사용자 판정.
2. 질문·기대·만족이 작게 구분되면서 해설은 이해하기 쉬운가 — 사용자 판정.
3. 숫자·종결 어미·누락·반복을 ASR과 청취로 확인.
4. 모델·버전·시드·설정·발화문·원본 길이를 결과 옆에 기록.
5. 비교 샘플 선택 이후에만 본편 TTS, 실측 timing, KO/EN SRT, 믹스로 진행.
