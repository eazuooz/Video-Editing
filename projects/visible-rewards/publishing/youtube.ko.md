## 설명

게임을 끄려는데, 다음 가방까지 딱 조금이 남았다면?
스타듀밸리, 뱀파이어 서바이버스, 몬스터 헌터 와일즈의 장면을 통해 보상과 목표를 눈에 보이게 만드는 게임 디자인을 살펴봅니다.

보상이 크다고 항상 갖고 싶어지는 건 아닙니다. 그 보상으로 무엇이 달라지는지, 얼마나 가까워졌는지, 지금 어떤 행동을 하면 되는지를 알 수 있어야 하죠.

가방 확장과 인벤토리, 경험치 바와 레벨업 선택, 필요한 정보를 보여주는 타이밍, 확률 보상에서 기대를 정직하게 전달하는 방법까지 다룹니다.
실제 게임 장면을 관찰한 뒤, 직접 만든 2.5D 디오라마와 가상 UI 비교로 원리를 설명합니다.

게임 기획·보상 설계·UX를 고민하고 있다면 이 세 가지를 물어보세요.
왜 이 보상을 원해야 할까? 얼마나 남았는지 알 수 있을까? 얻은 뒤 달라진 점을 직접 느낄 수 있을까?
그리고 보상까지 가는 플레이 자체도 재미있어야 한다는 점을 잊지 말아야겠죠.

여러분이 “이것만 더 하고 끄자”라고 생각했던 게임은 무엇인가요?

한국어 내레이션 · 한국어/영어 자막 제공
내레이션은 채널 운영자가 승인한 자신의 목소리를 기반으로 합성했습니다.
1,700G/300G와 확률 재료는 설명용 가정입니다. 실제 게임 UI를 변경하거나 특정 게임의 드롭 규칙을 단정하지 않습니다.
UI 비교는 자체 제작 예시이며 실제 사용자 실험 결과가 아닙니다. 여러 녹화의 장면은 한 세이브의 연속 플레이를 의미하지 않습니다.
