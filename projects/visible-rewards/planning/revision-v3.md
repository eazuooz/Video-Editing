# 최종 v3 — 전체화면 / 하단 설명 제거

2026-09-17 사용자 요청: 하단 설명용 글 제거, 전체화면 구성, 최종 영상·SRT, Notion 게임 디자인 기초 문서, 커밋·푸시.

- 8개 설명 씬의 하단 문구와 전용 공간 제거. 핵심 제목·수치·2.5D 애니메이션은 유지.
- 자료화면은 1920×1080 전체 크기. 이전 주석 띠가 있던 01·03·07은 원본 구간에서 재편집해 불필요한 확대·잘림을 피함.
- 나머지 5개 클립은 v2와 바이트 동일. 01·03·07도 오디오는 기존 스트림 복사. 전체 최종 믹스는 v2 AAC를 재인코딩 없이 사용.
- 8×19.5초 게임 예시, 22,546프레임, 375.766667초 유지. 내레이션·음악·게임 음량 및 한영 SRT 94개씩 모두 유지.
- 가정 수치·출처·서로 다른 세이브의 예시라는 안내는 한영 설명란 및 Notion 글에 보존. 게임 HUD·원본 표식은 제거하지 않음.
- 최종 MP4는 `shared/output/motion-canvas/visible-rewards-final.mp4`. 같은 폴더에 `.ko.srt`, `.en.srt`를 배치. 자막은 영상에 구워 넣지 않음.
- 최종 영상 141,252,470 bytes는 80MiB 이하 gzip 2조각으로 저장. 해시 검증 복원으로 다른 PC에 무손실 전달.
- 승인 SRT의 CRLF 줄바꿈을 이 프로젝트에만 `.gitattributes`로 고정해 다른 OS에서 전달 SHA-256이 달라지지 않게 함.
- QA: 32지점 화면, 편집기 실제 오디오 시간 진행, 전체 FFmpeg 디코딩, AAC 일치, 승인 입력 해시, 타입 검사 및 전체 빌드 통과.
- 전체 사람 청취 승인은 별도 상태로 유지. 기술 검사 통과를 사람 청취 완료로 기록하지 않음.

재출력: `node scripts/prepare-visible-rewards-v2.cjs --v3` → Motion Canvas 폴더에서 `node scripts/render-visible-rewards.cjs --v3`. 현재 파일을 덮어쓰지 않으므로 새 수정은 새 버전으로 보존할 것.
