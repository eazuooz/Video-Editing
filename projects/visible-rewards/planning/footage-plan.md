# 실제 자료화면 작업표

2026-09-16 · 재사용 허용 소스 4개에서 실제 예시 8구간을 편집했습니다.
실제 사용 컷은 [gameplay-cuts.json](../sources/gameplay-cuts.json)이 기준입니다.
아래 표는 **초기 촬영·검색 희망 목록**을 보존한 것으로, 모든 세부 동작이 확보되었다는 뜻은 아닙니다.
기본 실제 예시 길이는 project.json.editing.exampleSeconds에서 읽습니다.

## 실제 편집 결과와 차이

- 01: 수집 → 피에르의 가방 확인. 1,700G 가정은 화면 밖 별도 텍스트. 작물 판매 컷은 사용하지 않음.
- 02: 광산과 수집·툴바 상황 자료 → 자체 만원 인벤토리 도식. 실제 "Inventory Full" 알림 순간을 확보한 것으로 주장하지 않음.
- 03: 실제 수집 HUD + 별도 가정 표시 → 자체 현재/목표 비교. 실제 화면의 500G를 1,700G로 수정하지 않음.
- 04: 가방 구매·24칸 획득 알림·인벤토리 → 이후 농장 수집. 같은 원본의 서로 다른 시점.
- 05: 같은 단독 플레이의 경험치 수집·레벨업 선택·공격 변화.
- 06: 전투 중 경험치 HUD → 상점 메뉴의 물품/가격. 01·04와 겹치지 않는 컷.
- 07: 다른 녹화의 이동·수집과 강화 화면. 특정 게임의 확률 재료를 설명하는 증거가 아님을 명시.
- 08: 확장 인벤토리 확인·광산 탐험. 구매 컷 재사용 없음.
- 확보 소스: SwenAL / Khittisun Chaemdikawiwat / G-Gou_Plays / No Copyright Runs.
- 외부 녹화의 얼굴 카메라·표식은 그대로 보존. 자료화면 출처는 한영 설명란에 기록.
