This game can switch to classic graphics with a button. The battle keeps going.

A game has two different jobs. One calculates positions and attack results. The other draws those results on screen.

Diablo II: Resurrected builds on the underlying game. A new layer renders it in 3D. It presents positions and actions using new models.

In our diagram, move the character one cell. Both appearances follow the same position. The presentation changes; the underlying state is shared.

That is why switching the view does not reset the characters or monsters. You see the same game state through another presentation.

This is separation of game logic and rendering. A new visual layer wraps familiar gameplay.
