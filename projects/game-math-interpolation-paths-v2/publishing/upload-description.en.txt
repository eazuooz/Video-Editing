Given two orientations, how do we create a natural motion between them? Keeping the same body and reference axes, we connect the short angular path, linear interpolation, quaternion interpolation and speed over time. We then use small numbers to compare intermediate orientations when the time function changes but both endpoints stay the same. This is the first of two lectures.
