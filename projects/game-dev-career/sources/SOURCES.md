## 실제 자료화면 v2 — 이전 편집 이력

현재 편집 기준: [원본·구간·허용 근거](../production/media-sources-v2.json).

- 게임 플레이: Archive 64 / NintendoBlackCrisis, [원본](https://www.youtube.com/watch?v=tOvTBrO7bPo), [녹화본 재사용 허용](https://www.nintblkc.com/archive-64). [Nintendo 지침](https://www.nintendo.co.jp/networkservice_guideline/en/index.html)은 별도 적용한다. 한국어 직무 교육 해설에 짧게 발췌하며, 게임 IP가 CC라는 뜻은 아니다. 닌텐도 후원·공식 교육을 암시하지 않는다.
- 기획·프로토타입·플레이 테스트: [GDQuest Hook](https://www.youtube.com/watch?v=mturL8WaHjY). 원본 설명에 영상 CC BY 4.0 명시, 2026-09-20 재확인.
- 실제 C++ 코딩: Hilze Vonck [Variables](https://www.youtube.com/watch?v=ESiCatrXWo4), [Vectors](https://www.youtube.com/watch?v=KqJEVA8TtiA). 원제작자 업로드의 `Creative Commons Attribution license (reuse allowed)` 메타데이터 확인. 코드 가독성을 위해 편집기 영역을 크롭하며 별도 권리 표시를 지우기 위한 크롭이 아니다.
- 작은 게임 완성·실행: [GDQuest Survivor tutorial](https://www.youtube.com/watch?v=GwCiGixlqiU). 영상·데모 에셋 CC BY 4.0 원본 설명 확인.
- 2D/3D: 아래 David Revoy와 Blender 허용 기록 유지. 실제 v2 사용 구간은 매니페스트와 한영 설명란을 따른다.

공통 변경: 구간 발췌, 1080p/30fps 자료화면 정규화, 한국어 설명·자막 합성, 원음 감쇠. 본편은 60fps. 재생 속도 변경·반복 없음. 저작자·링크·라이선스·변경 사실은 [한국어 설명란](../publishing/description.ko.txt)과 [영어 설명란](../publishing/description.en.txt)에 표기.

아래는 v1 조사·제작 이력이다. v1의 자체 실행 예제는 설명 그래픽/테스트로 남으며 v2의 예시 구간에서는 실제 외부 자료화면으로 대체한다.

## v1 본편 제작 조사 — 2026-09-20

아래 공식 직무 자료를 다시 확인하고 `script/review.ko.md`에 본편 초안을 작성했다.
구체적인 보물상자 규칙과 학습 과제는 채널의 설명용 창작 예시다.
영상 후보·라이선스 확인 범위·미확정 인점은 [본편 자료영상 계획](../planning/footage-plan.md)에 기록했다.
실제 채택 구간은 [편집 소스 매니페스트](../production/media-sources.json)에 기록했다.
2D는 David Revoy의 Krita 명암 덩어리 시범, 3D는 Blender 공식 Extrude 시범이다.
나머지는 자체 실행 가능한 상자 프로토타입의 입력 리플레이와 MSVC로 컴파일·검사한 C++ 실행 결과다.
상용 게임이나 외부 게임 엔진 편집기를 흉내 낸 화면이 아니다. 직접 실행: `http://localhost:9191/career-prototype.html`.
