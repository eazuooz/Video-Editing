# v3 — 역할군 소개·신규 자료화면 전면 교체

2026-09-20 사용자 피드백 반영본.

## 내용 방향

- 세부 C++ 문법이나 프로그래밍 절차를 설명하는 영상이 아니다.
- 게임 기획자, 프로그래머, 2D 아티스트, 3D 아티스트가 어떤 문제를 맡는지 넓게 소개한다.
- 같은 직군 안의 세부 분야, 역할 사이의 반복과 협업, 작은 입문 과제까지 연결한다.
- 9개 장면 대본·영문 번역·TTS·KO/EN SRT·타이밍을 함께 새로 만든다.

## 자료화면 원칙

- 저장소에서 이미 사용한 YouTube URL 94개를 제외했다.
- 9개 장면 모두 새 원본이며 정확한 출처·인아웃은 `media-sources-v3.json`에 기록했다.
- 원 업로더의 YouTube Creative Commons Attribution 메타데이터를 확인했다.
- 얼굴 위주 발표·스트리머 화면은 선택하지 않았다.
- 첫 01 후보의 로그인 화면, 첫 08 후보의 Bandicam 워터마크 화면은 시각 검수에서 탈락시켰다.
- 02는 손그림·엔진·코드·완성 결과만 보이는 구간으로 다시 잘랐다.
- 외부 프로젝트를 채널의 자체 제작물이나 실제 채용 현장이라고 주장하지 않는다.

## 유지한 승인 설정

- 내레이션: 기존 균형형 보이스 레퍼런스.
- 음악: Scott Buckley의 `Discovery`, CC BY 4.0, 처음부터 끝까지 연속 재생.
- 자료화면 원음: 한국어 내레이션 아래 작은 음량으로 유지.
- 자막: `boxed-white-forest-v1`, 중심 y=400, 무자막 마스터와 KO/EN SRT 별도 보존.
- 해상도/프레임: 1920×1080, 60fps 본편. 자료화면은 1080p/30fps로 정규화.

## 완료된 기술 검수

- 새 TTS 전체 ASR 정렬과 한영 SRT 94큐 대응 통과.
- 연속 BGM·원음·내레이션 믹스 측정 통과: -17.99 LUFS / -3.94 dBTP / LRA 3.90 LU.
- Motion Canvas 9개 장면과 전체 자막 시각 검수 통과.
- 무자막·자막 MP4 모두 24,597프레임·409.95초·1920×1080·60fps 확인.
- 두 MP4 전체 디코딩 및 최종 AAC 패킷 일치 확인.

## 남은 승인

- 사람의 최종 전체 청취·게시 승인. 완료 전 `publishReady=false`를 유지한다.
