# 실제 자료화면 수정본 v2

요청: 기존 설명 화면 유지 + 각 내용에 맞는 실제 게임·기획·코딩·드로잉·모델링·플레이 테스트 영상 삽입.

- v1 완성 MP4, 오디오, 기존 프리뷰 보존.
- 434.25초 / 26055프레임 / 9개 독립 씬 유지. TTS와 KO/EN SRT 102큐는 변경하지 않음.
- 자막 중심 y=400, 흰 박스·검정 테두리·초록 그림자 유지.
- Discovery 연속 BGM 유지. 외국어 해설은 -31 LUFS, 게임 원음은 -23 LUFS를 출발점으로 사용.
- 자료화면은 출처와 사용 구간을 `media-sources-v2.json`에 기록. 실제 다른 프로젝트의 자료이며 본편 보물상자 구현 과정 자체로 주장하지 않음.
- 2026-09-20 진행: Archive64 녹화 허용, GDQuest 각 영상 CC BY 4.0, Hilze Vonck 원본 C++ 강의 YouTube CC BY 확인. 각 원본 화면 검수·인아웃 확정 후 삽입.
- 미확인 재업로드 C++ 강의는 제외. Hilze Vonck 원제작자 업로드 사용.
- 최종 산출물 예정: `shared/output/motion-canvas/game-dev-career-v2.mp4`, `game-dev-career-v2-subtitled.mp4`.

기술 검수와 전체 청취 승인은 별도. 생성 중인 파일을 게시 완료본으로 부르지 않는다.
