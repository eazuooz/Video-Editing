## v2 — 내용별 실제 자료화면

2026-09-20 사용자 추가 요청으로 9개 예시 슬롯을 외부 실제 영상으로 교체 중이다.
정확한 소스·허용 근거·인아웃의 기준은 [media-sources-v2.json](../production/media-sources-v2.json).
434.25초의 TTS·KO/EN SRT 102큐는 그대로 유지한다. 예시는 보통19.5초, 06은13.2초.

| 씬 | 새 자료화면 | 설명과 연결 |
| --- | --- | --- |
| 01 | Archive64 야숨 탐색 | 플레이하는 경험에서 제작자의 관점으로 |
| 02 | 상자 열기·엔진 배치·Krita·Blender 짧은 연결 | 하나의 결과 뒤에 있는 서로 다른 직무 |
| 03 | GDQuest 실제 Hook 프로토타입 기획 문서 | 목표·핵심 메커니즘·조건을 글로 정리 |
| 04 | Hilze Vonck 실제 C++ 편집 | 자료형·변수와 실행 코드 |
| 05 | Hilze Vonck Visual Studio 벡터 작성 | 데이터를 저장하는 구조 |
| 06 | David Revoy Krita 명암 연구 | 큰 형태·명암을 먼저 관찰 |
| 07 | Blender 공식 돌출 튜토리얼 | 큰 입체·면 구조·다른 각도 |
| 08 | Hook 엔진 배치 편집과 실행 테스트 | 만들고 관찰하고 다시 고치기 |
| 09 | GDQuest 작은 2D 게임 실행 | 배운 기본기를 작은 제작에 적용 |

자료화면의 프로젝트와 우리 상자 예제는 서로 다르다. 타인의 강의를 본편 제작 현장으로 주장하지 않는다.
외국어 원음은 작게, Discovery는 전 구간 이어 사용. 화면의 출처 꼬리글 대신 게시 설명란에 표기.

## 이전 후보 조사 이력 (v1 전)

2026-09-20. 당시 상태: 후보 조사·시각 콘티.

씬당 예시 예산은 `project.json.editing.exampleSeconds`의 19.5초를 사용한다. 전체 495초 예산 안에 포함된 화면 구간이며 별도 시간을 더하지 않는다. 예시에서도 한국어 설명은 이어지고, 원음은 내레이션 아래로 낮춘다. Discovery는 처음부터 끝까지 유지한다. 최종 길이는 승인 대본의 실제 TTS에 맞춘다.

| 씬 | 실제 예시에서 보여줄 동작 | 자체 설명 | 현재 확보 상태 |
| --- | --- | --- | --- |
| 01 | 게임에서 상자 발견 → 열기 → 아이템 획득 | 같은 상자를 제작자 시선으로 전환 | 원본 선정 전; 임의 게임 화면 미삽입 |
| 02 | 엔진·아트 도구·실행 결과를 연결하는 제작 과정 | 같은 상자, 네 직무의 질문 | 각 원본의 다른 짧은 관련 컷을 확보할 예정 |
| 03 | 실제 규칙 문서 또는 에디터에서 조건·보상 수정 후 플레이 | 열쇠·가방·이미 열림의 조건 분기 | 자체 작성 규칙 문서와 실제 테스트 캡처가 가장 정확함; 녹화 전 |
| 04 | C++ 변수·분기 작성과 한 줄씩 실행 | 상자 상태와 코드 하이라이트 | 직접 실행할 샘플 제작 또는 허용된 튜토리얼 확인 필요 |
| 05 | 중단점·변수 검사·중복 보상 재현과 수정 | 저장·찾기·검증을 분리 | CppCon 후보는 주제 일치, 재사용 허용 미확인 |
| 06 | Krita에서 큰 명암·형태 또는 실루엣을 수정 | 상자 도형화 → 비례·원근 → 명암 | David Revoy 영상 CC BY 4.0 확인, 사용 구간 화면 검수 전 |
| 07 | Blender에서 큰 입체·면 구조·회전축 확인 | 동일 상자 회전·구조·경첩 표시 | Grant Abbitt 상자 튜토리얼 후보, 재사용 허용 미확인 |
| 08 | 플레이 테스트에서 문제 관찰 후 배치/대비 조정 | 관찰 → 변경 → 재검사 | 실제 변경 전후 녹화 전; 다른 사람 영상에 가상 문제를 단정하지 않음 |
| 09 | 작은 완성 결과를 실제 실행하는 장면 | 역할 선택 → 작은 제작 → 기본기로 복귀 | 자체 예시 완성 또는 사용 허용 게임 클립 확보 후 편집 |

- 탐색 지점: 19:35 명암 설명, 21:23 작은 구도 스케치, 39:09 드로잉, 56:46 명암 확인, 64:22 실루엣. 이는 작가의 챕터 정보이며 확정 인·아웃점이 아니다.

- 표기: “Tutorial: an Illustration from A to Z with Krita” — video and artwork by David Revoy, CC BY 4.0. Kiki character design by Tyson Tan (CC BY). Source: 위 링크. 발췌·한국어 내레이션·음량 조정 표시.

- 가장 정확한 대안은 우리 상자·인벤토리 코드를 실제로 실행하고 중단점·중복 입력을 직접 녹화하는 것. 코드를 흉내 낸 그래픽을 실제 디버거 화면이라고 표시하지 않는다.

## 삽입 전 필수 확인

영상의 공개 재생 가능 여부와 편집·재사용 허용은 별개다. 원본별 권리 확인 → 파일 확보 → 동작 확인 → 19.5초 관련 컷 편집 → 원음 확인을 마친 후에만 `sources/SOURCES.md`에 사용 인·아웃점과 파일 경로를 확정한다. 짧은 원본을 반복하거나 억지로 느리게 재생하지 않는다.
