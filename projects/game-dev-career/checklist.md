## 음악·믹스 승인

- [ ] 곡명·원본 링크·라이선스·출처 표기를 포함한 BGM 후보를 제시했다
- [ ] 사용자가 곡을 명시적으로 선택했다
- [ ] 선택 전에는 BGM을 최종 영상에 적용하지 않았다
- [ ] 승인된 BGM이 처음부터 끝까지 이어지고 게임 예시 구간에는 원음도 함께 나온다
- [ ] 씬 전환에서 BGM이 끊기거나 다시 시작되지 않으며 곡 반복은 크로스페이드로 연결된다
- [ ] 게임 원음이 겹칠 때만 BGM을 3dB 낮추고 무음 구간에서는 불필요하게 낮추지 않는다
- [ ] 내레이션 중 BGM과 게임 원음이 자동으로 낮아진다
- [ ] 내레이션 -16 / 게임 원음 -23 / BGM -28 LUFS 기본값을 적용하거나 예외를 기록했다
- [ ] 배경 음량 조정 시 승인된 내레이션·전체 길이·SRT 타이밍을 유지했다
- [ ] 지연 배경 트랙 합산에 `amix normalize=0`을 사용하고 합산 피크를 검사했다
- [ ] 모든 씬의 게임·설명 구간을 배경 단독 트랙으로 측정하고 청취했다
- [ ] 원음이 없거나 사실상 무음인 씬에만 승인곡을 대체 사용하고 목록을 기록했다
- [ ] MP4와 `paths.audioMix`를 함께 생성하고 편집기 `audio`를 전체 믹스로 연결했다
- [ ] 원본 클립 오디오는 보존하고 개별 Video 재생만 음소거해 중복 소리를 방지했다
