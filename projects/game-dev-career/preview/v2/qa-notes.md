# v2 프리뷰 및 자막 샘플 검증

- 본 프리뷰: 5389프레임 / 60fps = 89.817초. 독립 씬 6개, 1920×1080, AAC 음성·Discovery 포함.
- 박스형 자막 샘플: 919프레임 / 60fps = 15.317초. 첫 장면의 4개 발화에 고정 자막, 같은 믹스에 끝 0.45초 페이드아웃.
- TypeScript/Vite 빌드와 Python·Node 구문 검사 통과.
- 두 MP4 모두 FFmpeg 전체 디코딩 통과. 실제 해상도·프레임 수·오디오 포함 여부를 `render-report.json`으로 기록.
- 전체 12개 장면 표본과 자막 샘플 4개 문구를 캡처해 검토. 글자 잘림 없음. 자막은 핵심 상자 본체와 왼쪽 설명을 가리지 않음.
- 편집기에서 올바른 버전의 PCM WAV 로드, 음소거 해제, 재생 시간 증가 확인. 브라우저 오류 없음.
- 한영 SRT 20개 큐의 번호·타임코드 일치, 겹침·역전 없음, 마지막 자막이 영상 안에서 종료.
- 도입·결론의 새 음성을 받아쓰기로 검토. 도입의 ‘만드는 일을 맡는’ 표현이 두 차례 모호하게 인식되어 ‘직접 만드는 것은 조금 다릅니다’로 수정하고 재생성. 수정 후 도입과 결론 모두 정규화된 대본과 일치.
- 변경 없는 2~5번 음성을 재사용. 2차원·3차원 숫자 표기는 받아쓰기 정규화 차이.
- 최종 믹스 실측 -17.84 LUFS / -3.92 dBTP. 모든 장면의 음악 단독 트랙에서 신호 확인. 음악은 장면마다 재시작하지 않음.
- MP4와 대응하는 M4A의 AAC 패킷 해시 일치 확인. PCM 편집기용과 AAC 게시용은 동일 믹스에서 생성.
- 기존 v1의 MP4·음성·SRT 보존. v1 편집기 회귀 검사 통과.

GPU가 작업 중 사용할 수 없게 되어 도입의 최종 합성·검수는 CPU로 처리했다. NVIDIA 드라이버 변경, 시스템 재부팅 또는 사용자 프로세스 중단은 하지 않았다.

본편 완성·게시 승인이 아니라 프리뷰 검수 기록이다. 자동 받아쓰기와 음향 검사는 사람의 최종 청취 승인을 대신하지 않는다. 자막 스타일도 샘플 검토 대기이며 채널 전체 기본값은 변경하지 않았다.
