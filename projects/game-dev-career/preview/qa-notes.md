# 프리뷰 v1 검증 — 2026-09-19

## 범위

사용자가 요청한 짧은 설명·디자인 프리뷰. 도입, 기획, 프로그래밍, 2D 아트, 3D 아트, 마무리의 6개 독립 씬이다. 본편 제작·발행 승인을 뜻하지 않는다. 원본 절차적 모션그래픽으로 구성해 외부 게임 자료화면과 그 원음은 없다.

## 확인 결과

- TypeScript/Vite 빌드 성공.
- 실제 편집기 타임라인과 음성 기준 타임라인: 모두 4544프레임, 60fps.
- 6개 씬의 초반·후반 12개 화면 검토. 한글·입체·코드 강조·회전축 표시에 화면 밖 잘림이나 겹침 없음.
- 편집기 오디오 `preview-mix-v1.wav` 로드, 음소거 해제, 재생 시간 진행 확인. 브라우저 오류 없음.
- MP4: 1920×1080, 60fps, 75.733초, AAC 오디오, 5,724,277바이트. FFmpeg 전체 디코딩 통과.
- KO/EN SRT 17개 큐: 양언어 타임코드 일치, 순서·겹침·영상 길이 검사 통과.
- Whisper 받아쓰기와 발화 원문 비교: 문장 누락 없음. 이차원/삼차원의 숫자 표기 차이는 정상화 차이. 기존 3D 발화의 ‘회전축’ 인식이 모호해 마지막 문장을 ‘뚜껑이 어디를 중심으로 열리는지도 확인해야 하죠…’로 다시 합성했다.
- Discovery는 24초 지점부터 발췌, 전체 장면에 연속 재생. 내레이션 덕킹과 양끝 페이드 적용.
- 인코딩된 최종 믹스 실측: -17.82 LUFS, -4.00 dBTP. 믹스 보고서의 `encodedMix.input_i/input_tp`가 실제 입력 측정값이며 `output_*`는 측정 필터의 가상 정규화 결과다.

자동 받아쓰기와 음향 지표는 주관적인 발음·자연스러움 청취 승인을 대신하지 않는다. 본편 대본, 음성 톤, 최종 청취 승인은 사용자 검토 대기다.
