# 게임 애니메이션 프레임 세기

기획·게임 디자인 배치 9번 주제. 독립 한국어·영어 6장면 대본과 6개 흰색 2.5D 설명을 작성했다. 원본은 개념 연구용으로만 읽으며 원문 전체 복사·번역이나 원본 영상·음성을 사용하지 않는다.

새 사례는 Mega Man 11과 Monster Hunter Rise의 공식 플레이 동작이다. 정확한 상용 기술 수치를 추정하지 않고 자체 Frame Timing Lab의 실제 키보드 입력·충돌·판정·회복·시계 로그로 검증한다. 최근 게임 사용 이력과 Monster Hunter Wilds의 같은 프랜차이즈 사용도 sources/game-candidates.json에 보존한다.

입력을 받은 시점을 0으로 하고 12번의 시간 간격 뒤 판정이 시작한다. 자체 공격은 준비 [0,12), 판정 [12,15), 회복 [15,30), 60눈금/초에서 전체 0.5초다. 그림 수·화면 갱신·규칙 갱신·충돌 뒤 멈춤을 독립 비교한다. 다른 게임의 기술 데이터나 하드웨어 지연 측정으로 일반화하지 않는다.

승인된 기존 목소리/Qwen3-TTS 1.7B와 Nimbus를 그대로 사용한다. 2초 원본 고양이 인트로 → 전체 화면 게임·개발 테스트 위 boxed-white-forest-v1 → 흰색 2.5D 설명 → 원본 회원 프로필·이름·배지와 정확한 감사 제목을 보존한 10초 엔딩이다. 본편 60:40 목표는 실측 내레이션으로 계산한다.

최종 197.6초 영상과 50개 한영 자막을 실제 렌더·전체 디코딩했다. 여섯 장면과 전체 ASR에 누락·반복이 없고, 모든 56개 큐·컷 구간 및 모바일 화면을 검수해 output/counting-animation-frames/에 4개 파일을 수집했다. 본편 실제 예시는 111.367초(60.004%), 흰 2.5D 설명은 74.233초다. 실제 믹스는 -16.09 LUFS / -1.93 dBTP이며 두 MP4의 AAC가 일치한다.

02 장면의 두 이전 합성은 실제 반복 때문에 거부했다. 같은 승인 목소리로 해당 장면만 다듬고 재합성한 현재 해시를 검토했다. 원시 ASR 일치율 0.905263은 확인한 열 개 숫자 표기 차이뿐이며 정확한 해시와 대응 쌍에만 예외를 허용한다. 다른 장면의 음성은 그대로 보존했다. 전체 ASR의 그림 장소 모호성은 독립 꼬리 구간 ASR의 그림 장수로 확인했다. 사람 청취는 추정 완료하지 않는다. 이전 종료 세션은 재실행하지 않는다.

YouTube 실제 업로드 ID는 piZTx_239R8이다. 비공개·예약 없음, 새 썸네일, 한영 수동 자막, 영어 제목·설명, 00초 과외 카드, 마지막 10초 채널 재생목록·구독 요소를 모두 실제 Studio에서 확인했다. 수익 창출이 사용 상태이고 광고·저작권 자동 검사에서 문제가 없었다. 실제 완료 상태는 publishing/youtube-upload.json과 배치 queue.json을 우선한다. 중복 업로드하지 않는다.

자체 녹화 v1에서는 공통 입력이 관계없는 준비/멈춤 변수도 바꾸는 문제가 발견되어 보존한 채 제외했다. v2는 비교별 조작을 분리하고 모든 공격의 판정 시각과 고정 변수를 검증한다. 공격 구간 비교는 v3에서 B를 기본 12눈금 공격, A를 준비만 바꾸는 수정안으로 명확히 표시한다. 다른 네 비교는 검증된 v2를 사용한다. 짧은 자료 반복·인위적 느린 재생으로 분량을 늘리지 않는다.

검수 후 node scripts/collect-video-output.cjs counting-animation-frames로 최신 clean MP4·한국어 박스 자막 MP4·KO SRT·EN SRT만 output/counting-animation-frames/에 수집한다. 모든 저장된 YouTube 규칙을 적용하되 비공개만 저장하며 공개·예약은 사용자가 직접 한다. 사람 전체 청취·공개 권리·원래 Audio Library 파일·외부 백업은 실제 확인 전까지 pending이다.

완료하면 필요한 제작 코드·대본·자막·내부 출처·재빌드·실제 업로드 증거만 선택해 체크 후 커밋·일반 푸시한다. MP4·음성·BGM·게임 소리·압축 미디어·다운로드 info.json은 Git에 넣지 않고 다른 사용자 작업을 보존한다.
