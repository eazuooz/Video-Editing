It restricts raw component distribution, standalone cutscenes, unauthorized event reposts and third-party material. We use short publisher-owned gameplay portions with original explanations; original source sound/music is omitted. This is a policy-based use record, not blanket rights clearance. Human public-rights review and actual new-video Studio checks remain pending. No paid-exclusive access is planned.
