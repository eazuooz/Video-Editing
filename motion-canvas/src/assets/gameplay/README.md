# 게임 영상 자리 (gameplay B-roll)

이 폴더에 영상 파일을 넣으면 `narrated` 프로젝트가 **자동으로** 잡아서 재생합니다.
코드 수정 없이 파일만 떨어뜨리면 됩니다.

## 파일 이름

`src/broll.ts`의 `clip` 값과 파일 이름(확장자 제외)이 같아야 합니다.

| 파일 이름            | 들어갈 내용                                              |
| -------------------- | -------------------------------------------------------- |
| `intro-montage`      | 서로 다른 게임 2~3개의 점프를 빠르게 이어붙인 몽타주      |
| `axes-horizontal`    | 같은 점프에서 가로 속도만 다른 두 플레이를 나란히         |
| `mario`              | 느린 상승 / 빠른 하강이 드러나는 마리오 점프              |
| `metroid`            | 둥실둥실한 체공, 공중에서 높이 조절해 쏘는 장면           |
| `ghosts`             | 점프 직후 착지 지점이 정해진 마계촌 장면 (실패/성공)      |
| `sf2`                | 장기에프 스크류 파일드라이버 (슬로 모션 권장)             |
| `smash-squat`        | 점프 스쿼트 준비 프레임, 위 스매시 입력과 대비            |
| `smash-ultimate`     | 초반에 확 뜨고 곧 감속하는 얼티밋 점프                    |
| `jump-king`          | 차지 게이지가 차오르다 발사되는 순간, 공중 수정 불가       |
| `celeste`            | 오래 눌러 최대 높이까지 가는 점프와 일찍 뗀 짧은 점프      |
| `megaman-x`          | 걷기 점프와 대시 점프의 이동 거리 차이                    |
| `outro-prototype`    | 파라미터를 바꿔가며 점프 감각이 달라지는 프로토타입 화면  |

확장자는 `.mp4`, `.webm`, `.mov` 중 아무거나 됩니다. 브라우저에서 렌더하므로
`.mp4`(H.264)가 가장 안전합니다.

## 길이

각 슬롯의 정해진 길이만큼만 화면에 나옵니다 (`npm run check:narration`으로
전체 타임코드 확인). 영상이 더 길면 잘리고, 짧으면 반복(loop) 재생됩니다.
정확한 시작 시각과 길이는 아래에서 확인하세요:

- `shared/output/narration/qwen3-balanced/broll-cues.md`

## 파일을 안 넣으면

해당 구간에 "게임 영상 자리" 안내판이 대신 표시됩니다. 안내판과 실제 영상의
위치·크기가 같아서, 나중에 파일을 넣어도 레이아웃이 흔들리지 않습니다.
