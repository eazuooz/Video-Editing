# Frame-rate gameplay examples

이 폴더의 `scene01.mp4`부터 `scene20.mp4`까지는 각 Motion Canvas 장면에서
약 6초 동안 표시되는 실제 게임 예시입니다. 현재 파일은 화면·타이밍 확인용으로
원본 오디오 스트림을 함께 보존한 1280×720, H.264, 60fps 클립입니다. 07번은
선택한 원본 구간 자체가 사실상 무음이며, 나머지 19개 장면은 최종 믹스에서
내레이션보다 작게 원본 소리를 사용합니다. `scripts/build-frame-rate-broll.ps1`로
동일한 구성의 클립을 다시 만들 수 있습니다.

장면은 다음 순서를 반복합니다.

1. 실제 게임 또는 공식 기술 데모의 짧은 예시
2. 같은 개념을 설명하는 채널 자체 모션그래픽

원본 URL, 인용 구간, 이용 근거는
`projects/frame-rate-modern-rendering/sources/SOURCES.md`에서 관리합니다.
