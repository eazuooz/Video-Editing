# 자료 출처

외부 영상, 이미지, 음악, 효과음을 추가할 때 아래 표에 기록합니다. 출처를 확인하지 못한 자료는 최종 영상에 사용하지 않습니다.

| 파일명 | 원본 링크 | 권리자/채널 | 라이선스·허용 근거 | 사용 구간 | 확인일 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

## 메모

- 원본 제목과 업로더 이름을 함께 남깁니다.
- 허용 조건을 확인한 페이지나 라이선스 링크를 기록합니다.
- 편집·비평 목적이라도 필요한 분량만 사용하고 출처를 표시합니다.
