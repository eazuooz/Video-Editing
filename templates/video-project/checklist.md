# 제작 체크리스트

## 기획

- [ ] 시청자가 얻어갈 한 문장을 정했다
- [ ] 도입, 본론, 결론의 흐름을 만들었다
- [ ] 필요한 게임 영상·이미지 목록을 만들었다
- [ ] 외부 자료의 출처와 사용 조건을 확인했다

## 음성·자막

- [ ] 내레이션 대본을 소리 내어 검토했다
- [ ] 짧은 비교 샘플로 TTS 톤과 속도를 승인받았다
- [ ] `Qwen3-TTS 1.7B`와 정확한 기준 발화문을 사용했다
- [ ] 같은 장면의 문장을 장면 단위 연속 발화로 생성했다
- [ ] 문장 끝 잘림·고유명사·숫자 발음을 확인했다
- [ ] 전체 받아쓰기에서 누락과 반복이 없는지 검토했다
- [ ] 한국어 SRT 타이밍을 확인했다
- [ ] 필요한 번역 SRT를 만들었다

## 영상

- [ ] Motion Canvas 장면을 제작했다
- [ ] 필요한 Manim 장면을 제작했다
- [ ] 대본 장면과 Motion Canvas 씬을 각각 분리했다
- [ ] 각 장면의 실제 예시 영상과 자체 설명 화면이 페어로 배치됐다
- [ ] 게임 원음의 효과음·환경음이 작은 음량으로 보존됐다
- [ ] 출처 표기를 갱신했다
- [ ] 음성·장면 길이 동기화를 검사했다

## 음악·믹스 승인

- [ ] 곡명·원본 링크·라이선스·출처 표기를 포함한 BGM 후보를 제시했다
- [ ] 사용자가 곡을 명시적으로 선택했다
- [ ] 선택 전에는 BGM을 최종 영상에 적용하지 않았다
- [ ] 자체 설명 구간에는 승인된 BGM을, 게임 예시 구간에는 작은 원음을 사용했다
- [ ] 내레이션 중 BGM과 게임 원음이 자동으로 낮아진다
- [ ] 선택한 음악의 출처 표기를 설명란과 `sources/SOURCES.md`에 넣었다

## 게시

- [ ] 1920×1080 최종 영상을 확인했다
- [ ] 처음부터 끝까지 음량·클리핑·오탈자를 확인했다
- [ ] 최종 영상에 AAC 오디오 스트림이 있고 음성과 길이가 맞는다
- [ ] 제목·설명·챕터·썸네일을 확정했다
- [ ] YouTube에 언어별 SRT를 등록했다
- [ ] 사람의 최종 청취 승인 뒤 프로젝트 상태를 `complete`로 변경했다
