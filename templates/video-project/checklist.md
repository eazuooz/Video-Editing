# 제작 체크리스트

## 기획

- [ ] 시청자가 얻어갈 한 문장을 정했다
- [ ] 도입, 본론, 결론의 흐름을 만들었다
- [ ] 필요한 게임 영상·이미지 목록을 만들었다
- [ ] 외부 자료의 출처와 사용 조건을 확인했다

## 음성·자막

- [ ] 내레이션 대본을 소리 내어 검토했다
- [ ] TTS 톤과 속도를 확정했다
- [ ] 문장 끝 잘림과 발음을 확인했다
- [ ] 한국어 SRT 타이밍을 확인했다
- [ ] 필요한 번역 SRT를 만들었다

## 영상

- [ ] Motion Canvas 장면을 제작했다
- [ ] 필요한 Manim 장면을 제작했다
- [ ] B-roll이 설명과 맞는 위치에 들어갔다
- [ ] 출처 표기를 갱신했다
- [ ] 음성·장면 길이 동기화를 검사했다

## 게시

- [ ] 1920×1080 최종 영상을 확인했다
- [ ] 처음부터 끝까지 음량과 오탈자를 확인했다
- [ ] 제목·설명·챕터·썸네일을 확정했다
- [ ] YouTube에 언어별 SRT를 등록했다
- [ ] 프로젝트 상태를 `complete`로 변경했다
