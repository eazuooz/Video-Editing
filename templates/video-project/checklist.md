# 한 편 제작 단계표

기준은 `docs/VIDEO_WORKFLOW.md`. 여기에 별도 증거를 복제하지 않고 `planning/production-plan.json`과 `production/review-ledger.json`을 연결한다. 체크 표시는 실제 근거가 있을 때만 바꾼다.

## 전체 제작 전

- [ ] 사용자가 선택한 한 편과 허용 범위를 확인했다. 자동 다음 편은 꺼져 있다.
- [ ] 해당 Sakurai 원본의 전체 대사·관련 화면을 확인하고 질문/주장/순서/예시/결론을 우리 대본에 대응시켰다. 해당 원본이 없으면 실제 수업자료를 기록했다.
- [ ] 원본 주장/순서를 보존한 세부 PPT 보강, 원본 게임의 동등한 최신 버전 판단, 현재 중복검토/실제자료 권리·재생·비교·충분한 고유 분량을 확보했다.
- [ ] KOEN 전체 대본, 개론·선행설명·인과 흐름·원문 보존·수학/발음 검토를 마쳤다.
- [ ] 모든 씬의 상세대상/2.5D/대사별 동작/추적표식/실제자막·UI 공간을 설계했다.
- [ ] 비중·팔레트·오디오·인트로/회원·썸네일·게시 범위와 대표 움직임 샘플을 준비했다.
- [ ] 강의이면 낮은 로파이의 실제 사용 조건·게임 효과음/환경음 확보·30–60초 설명/게임 비교 샘플을 위 패키지에 포함했다. 선택한 곡·음량을 실제 믹서 필드에 반영했다.
- [ ] 패키지를 사용자에게 보여 주고 실제 승인과 해당 버전/범위를 기록했다.

## 승인 범위의 제작

- [ ] 실제 자원을 확인하고 필요한 GPU 인계/복원만 수행했다. 기존 승인PCM을 재사용했다.
- [ ] 현재 PCM 전체 ASR을 한 번 대조하고 모호한 부분만 독립문맥으로 해결했다.
- [ ] 실측 단일타임라인의 씬/믹스/KOEN/챕터/엔딩·본편비중을 확정했다.
- [ ] 실제 믹스 전체 ASR·음량·원음/BGM계약을 확인했다. 동일 검사를 반복하지 않았다.
- [ ] 최종자막 preflight 뒤 clean/captioned 쌍을 제작했다. prepared를 완료라 하지 않았다.

## 한 번의 최종 통합 검수·사용자 확인

- [ ] 원본 주장/순서와 게임 대응·세부 PPT 보강·버전 차이·연속흐름·상세대상/2.5D/표식 움직임과 모든큐/컷 픽셀을 확인했다.
- [ ] 두출력 전체decode/PTS/길이/fps/비중/동일AAC/LUFS/TP와4파일 수집을 확인했다.
- [ ] 기존 정확한 검수는 재사용하고 변경구간/접합만 다시 검수했다.
- [ ] 사람 청취/발음/권리/백업 미완료를 정확히 남겼다.
- [ ] 완성본/썸네일/게시안을 사용자에게 제시했다. 이미 승인된 해당편 범위는 중복 질문하지 않았다.

## 승인된 게시·전달 후 종료

- [ ] 승인된 captioned 단일비공개 ID에서 수동KOEN/영어정보/썸네일/카드/엔딩/광고 등을 저장·재열람했다.
- [ ] 업로드CCoff게임/설명 자막과 실제처리상태를 확인하고 제한/댓글은 후속으로 남겼다.
- [ ] 승인된 예약/교체만 처리했다. 기존 예약/원본을 먼저 삭제하지 않았다.
- [ ] 명시경로/임시index/media gate/선택Git/실제remote일치를 확인했다.
- [ ] 이 한 편에서 멈췄다. 다음 제작은 사용자 선택을 기다린다.
