# 제작 체크리스트

## 기획

- [ ] 시청자가 얻어갈 한 문장을 정했다
- [ ] 도입, 본론, 결론의 흐름을 만들었다
- [ ] 필요한 게임 영상·이미지 목록을 만들었다
- [ ] 외부 자료의 출처와 사용 조건을 확인했다

## 음성·자막

- [ ] 내레이션 대본을 소리 내어 검토했다
- [ ] 짧은 비교 샘플로 TTS 톤과 속도를 승인받았다
- [ ] `Qwen3-TTS 1.7B`와 정확한 기준 발화문을 사용했다
- [ ] 같은 장면의 문장을 장면 단위 연속 발화로 생성했다
- [ ] 문장 끝 잘림·고유명사·숫자 발음을 확인했다
- [ ] 전체 받아쓰기에서 누락과 반복이 없는지 검토했다
- [ ] 한국어 SRT 타이밍을 확인했다
- [ ] 필요한 번역 SRT를 만들었다
- [ ] `docs/CAPTION_STYLE.md`의 흰 박스·검정 테두리·초록 하드 그림자 자막을 적용하거나 프로젝트 예외를 기록했다
- [ ] 모든 자막이 최대 두 줄이고 박스·그림자 잘림 및 게임 UI·하단 요약과의 겹침이 없다

## 영상

- [ ] 상황 자료도 게임개발·코딩·디버깅·플레이 테스트 화면이며 일반 사무실·현금 스톡으로 채우지 않았다
- [ ] 각 챕터의 실제 동작을 확인하고 반복 원본을 최소화했으며, 자료화면과 사실 증거를 구분했다
- [ ] `docs/VIDEO_VISUAL_STYLE.md`의 흰색·좌측 정렬·하단 요약 디자인을 적용했다
- [ ] 인트로·회원 엔딩을 제외한 본편의 실제 영상:설명 비율을 60:40으로 실측했으며 반올림 오차는 최대 한 프레임이다
- [ ] 씬마다 같은 비율을 강제하지 않고 최종 실측 시간·비율을 project.json.editing과 rebuild.json에 기록했다
- [ ] 설명은 정적인 글 위주 PPT보다 2.5D 비교·화살표·강조 애니메이션으로 보여 주었다
- [ ] 19.5초는 기획 참고값으로만 사용했고 짧은 원본을 반복·슬로다운해 비율을 채우지 않았다
- [ ] 예시 길이 변경을 음성·KO/EN SRT·씬 시작·원음 믹스 모두에 반영했다
- [ ] 밈은 허용된 원본만 사용하거나 독자적인 도식으로 재해석했다
- [ ] Motion Canvas 장면을 제작했다
- [ ] 필요한 Manim 장면을 제작했다
- [ ] 대본 장면과 Motion Canvas 씬을 각각 분리했다
- [ ] 각 장면의 실제 예시 영상과 자체 설명 화면이 페어로 배치됐다
- [ ] 실제 예시는 기존 게임의 플레이 자료로 확보했으며 에이전트가 만든 게임·데모·시뮬레이터로 대체하지 않았다
- [ ] 실제 자료의 동작·출처 인아웃·사용 조건을 검토한 뒤 해설과 TTS를 작성했다 (`docs/VIDEO_GAME_FOOTAGE_POLICY.md`)
- [ ] 게임 원음의 효과음·환경음이 작은 음량으로 보존됐다
- [ ] 출처 표기를 갱신했다
- [ ] 음성·장면 길이 동기화를 검사했다

## 음악·믹스 승인

- [ ] 곡명·원본 링크·라이선스·출처 표기를 포함한 BGM 후보를 제시했다
- [ ] 사용자가 곡을 명시적으로 선택했다
- [ ] 선택 전에는 BGM을 최종 영상에 적용하지 않았다
- [ ] 승인된 BGM이 처음부터 끝까지 이어지고 게임 예시 구간에는 원음도 함께 나온다
- [ ] 씬 전환에서 BGM이 끊기거나 다시 시작되지 않으며 곡 반복은 크로스페이드로 연결된다
- [ ] 게임 원음이 겹칠 때만 BGM을 3dB 낮추고 무음 구간에서는 불필요하게 낮추지 않는다
- [ ] 내레이션 중 BGM과 게임 원음이 자동으로 낮아진다
- [ ] 내레이션 -16 / 게임 원음 -23 / BGM -28 LUFS 기본값을 적용하거나 예외를 기록했다
- [ ] 배경 음량 조정 시 승인된 내레이션·전체 길이·SRT 타이밍을 유지했다
- [ ] 지연 배경 트랙 합산에 `amix normalize=0`을 사용하고 합산 피크를 검사했다
- [ ] 모든 씬의 게임·설명 구간을 배경 단독 트랙으로 측정하고 청취했다
- [ ] 원음이 없거나 사실상 무음인 씬에만 승인곡을 대체 사용하고 목록을 기록했다
- [ ] MP4와 `paths.audioMix`를 함께 생성하고 편집기 `audio`를 전체 믹스로 연결했다
- [ ] 원본 클립 오디오는 보존하고 개별 Video 재생만 음소거해 중복 소리를 방지했다
- [ ] `audio/mix-report.md`에 설정·측정값·검수 결과를 기록했다
- [ ] 선택한 음악의 출처·권리 기록을 `sources/SOURCES.md`에 보존했다. 공개 설명란의 출처 표기는 사용자 게시 규칙을 따른다.

## 게시

- [ ] 1920×1080 최종 영상을 확인했다
- [ ] 무자막 마스터·한국어 박스 자막판·KO/EN SRT를 별도 보관하고 두 영상의 길이·오디오가 같다
- [ ] 처음부터 끝까지 음량·클리핑·오탈자를 확인했다
- [ ] 최종 영상에 AAC 오디오 스트림이 있고 음성과 길이가 맞는다
- [ ] 편집기 음소거를 해제해 실제 재생을 확인하고 Render의 `include audio`를 켰다
- [ ] 편집기와 MP4의 믹스 내용·길이가 같으며 한국어·영어 SRT가 영상 길이를 넘지 않는다
- [ ] 제목·설명·챕터·썸네일을 확정했다
- [ ] YouTube에 언어별 SRT를 등록했다
- [ ] 사람의 최종 청취 승인 뒤 프로젝트 상태를 `complete`로 변경했다
- [ ] 모든 고정 내레이션 자막이 하단 중앙 `(960,970)`에 있으며 핵심 코드·게임 동작과 겹치지 않는다. 위·옆으로 옮기지 않는다.
- [ ] 과외의 정확한 링크가 설명란과 영상 마지막에 있고, 실제 YouTube 최종 화면 외부 링크 저장 상태 또는 플랫폼 제한이 기록됐다.
- [ ] `publishing/pinned-comment.ko.txt`를 준비했다. 실제 댓글 등록·고정의 증거를 기록하거나 비공개 영상의 `pending-video-publication` 상태를 유지했다. 댓글을 위해 공개 상태를 바꾸지 않았다.
