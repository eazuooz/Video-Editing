# {{TITLE_KO}} — 제작 전 한 편 설계

현재 절차: `docs/VIDEO_WORKFLOW.md`. 사용자 선택/실행 범위는 `planning/production-plan.json`, 실제 검사 결과는 `production/review-ledger.json`에만 기록한다. 같은 내용을 여러 검수보고서에 복사하지 않는다. 전체 TTS 전에 아래를 실제 내용으로 채워 내부 확인하고 선택한 한 편을 비공개 업로드까지 중간 승인 없이 완료한다. 사용자 검수는 완성 후다.

## 선택한 한 편

- 중심 질문 / 시청자가 할 수 있게 되는 일:
- 포함 / 제외 / 완결된 회차 경계 / 예상 길이:
- 기존 영상과 내용 차이·현재 중복검토 근거:
- 실제:설명 비중 / 팔레트 / 오디오 / 기타 사용자 승인 예외:
- 이번에 허용받을 범위(제작, 로컬납품, 비공개업로드, 예약/교체 구별):

## Sakurai 원본 → 우리 대본 대응

- 해당 원본 제목/URL/전체 대사·관련 화면 확인 근거:
- 원본이 없는 수학·기술 주제이면 그 사실과 실제 수업/1차 자료:

| 원본 구간·중심 질문/핵심 주장 | 유지할 순서·게임/예시 역할 | 우리 씬·KO/EN 대사 | 해당 위치의 세부 PPT·다음 원본 대목 연결 |
|---|---|---|---|
| 개론부터 결론까지 핵심 흐름을 대응 | | | |

원본 주장·순서·사례·결론을 뼈대로 유지하고 새 짜임새로 재구성하지 않는다. 사용자 제공 원문이면 그 텍스트를 바탕으로 보강하고, 제공되지 않은 전체 대본은 복제/번역하지 않고 독립 문장으로 설명한다. 개인 일화는 Sakurai에게 귀속한다.

## 원본 게임과 동등한 최신 버전

- 원본 게임 목록과 실제 등장 근거 / 우리 중심 사례:
- 오래된 원본 버전→최신 동일 시리즈 후보 / 현재 출시·가용성 근거 / 같아야 할 기능·행동·결과:
- 실제 후보 화면/권리/차이 / 최신판 채택 또는 원본 유지 이유 / 소스 부족 시 대안:

| 게임·원본URL·버전·정확인아웃 | 권리·최근사용 | 전→행동→결과 | 필요한 규칙/UI | 다른게임과 공통원리/차이 | 후보 선택/제외 이유 |
|---|---|---|---|---|---|
| 직접 재생한 자료로 작성 | | | | | |

최소4게임과 추가1게임 기본값은 사용하지 않는다. 추가 게임 기본0이며 최신판에서 원리가 달라지면 원본을 유지한다. 원본 없는 수업은 개념에 필요한 최소 사례를 선택한다. 기술 데모는 별도 분류하며 관련 고유 소스의 충분한 길이를 확보한 뒤 최종 해설을 확정한다.

- 결론과 다음 질문:
