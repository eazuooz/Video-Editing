# M21–M33 방향·개론·정리 수정

사용자 요청 범위는 기존 13편의 시각 보강과 로컬 검수본 렌더다. 실제 이미지의 시점과 몸의 앞쪽을 확인하고, 이동·속도·힘을 구분한다. 모든 편의 기존 개론·마무리 음성에 학습 관계와 순서, 핵심 정리 화면을 맞춘다. 음성·재생 속도·길이·한영 자막은 보존한다.

`plan.json`은 이전 완성본과 실제 발화 cue를 고정한다. `assets.py`는 이미 확보한 FHD 녹화의 측면·높은 시점 프레임을 추출하고 편집 출처를 기록한다. `patch_base.py`는 이전 해설 렌더러를 별도 버전으로 재사용한다. `render.py`는 변경된 GOP 구간만 새로 그리고 다른 구간은 복사한다. 외부 GPU 작업은 건드리지 않고 제한된 CPU 인코더를 사용한다.

수정점은 직립한 마리오의 좌우 시선, 측면 카트, 원운동 접선에 맞춘 차량 앞쪽, 진동 중 고정된 차체와 독립적인 힘·속도 표시다. 실제 왼쪽 마리오 프레임은 대안 후보로 보관하며, 최종 주 운동 표현은 기존 오른쪽 프로필의 좌우 반전을 사용한다. 정면 사진을 옆모습으로 가장하지 않는다.

현재 유한 작업은 `render.py`의 M21–M33 순차 처리이며 중복 실행하지 않는다. 첫 작업 중 발견한 M25의 수직 속도와 M26의 포물선 속도 표기, M25·M28·M33 개론/정리의 누락 글리프는 `repairs.py`로 첫 작업 종료 후 보정한다. 수직 속도의 음수를 후진으로 설명하지 않는다. 한글 서체에 없는 ⇄·ₛ·−·⁰는 기호 서체로 표시하고 기준선을 맞춘다. 이 보정은 현재 작업의 새 미검수 중간본을 입력으로 한다. 새 보정본의 QA 후 같은 임시 파일명에 원자적으로 반영하며, 이전 승인 마스터는 별도로 보존한다.

`audit.py`는 전체 장면별 선택과 독립적인 위치 변화 대비 투영 접선을 확인하고, 실제 인코딩 영상의 개론·정리 및 변경 장면 전·중·후 프레임을 모은다. 실제 이미지 검사 결과는 `visual-review.json`에만 기록한다. 전체 스트림 디코드·정확한 60fps 표시 시각·AAC 패킷과 시각·자막·수정하지 않은 VCL·로컬 링크 검사 후 `finalize.py`로 닫는다. 사용자 전체 시청과 내부 표본 검수는 구분하며 `humanReviewed`는 계속 false다.

완료 상태: 13편의 FHD60 clean/captioned MP4 및 KO/EN SRT 52개를 로컬 사용자 검수 대기로 등록했다. 이전 승인 마스터 52개의 SHA-256은 그대로이며, 전체 스트림 디코드·60fps 표시 시각·AAC 패킷/시각·자막·복사 구간 VCL·로컬 링크 검사를 마쳤다. 575개 장면 선택을 분류했고 실제 출력의 개론·정리와 변경 장면의 시간별 표본, 최종 보정 구간을 검사했다. 사용자 전체 시청은 아직 하지 않았으며 자동 업로드나 후속 배치를 시작하지 않는다.
