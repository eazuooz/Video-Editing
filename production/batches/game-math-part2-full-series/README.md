# 게임수학 PART2 전체 강의 제작

사용자가 승인한 극좌표계 두 편의 제작 방식으로 남은 8~13장을 제작한다. 배경음악과 게임 원음 없이 승인된 내레이터만 사용하며, 본문 실측 화면 비율은 기존 게임의 실제 플레이 40% / 원래 제작한 설명 60%다. 저장소 일반 기본값 60:40은 이 사용자 요청으로 재정의하지 않는다.

23편을 주제별로 계획했다. 각 편은 쉬운 게임 관찰 → 원리 → 손으로 계산하는 예제 → 코드·실수·범위 → 실습으로 이어진다. 모든 핵심 절을 coverage-audit에 연결하되 원문 전체를 그대로 낭독하지 않는다. 실제 음성 길이를 확인하며 긴 편은 추가 분할할 수 있다. 기존 극좌표계 완성본과 이전 샘플은 보존한다.

매 편 제작 전 전체 프로젝트·현재 Studio 영상·겹치는 대본을 대조한다. 새 게임 후보와 최근 사용 이력을 검토하고 실제 장면과 촬영자 사용 허락을 확인한 다음 해당 관찰 대본을 작성한다. 공개 게임 IP 검토 및 사람의 전체 청취는 별도 대기로 정확하게 기록한다.

고양이 2초 도입 뒤에 독립 한영 도입 설명을 넣고, 원본 회원 프로필·이름·배지로 10초 감사를 마무리한다. 모든 내레이션 자막은 화면 아래 가운데에 고정한다. clean/한국어 자막 MP4와 한영 SRT를 output으로 모으고, 영상별 검토한 제작 기록만 격리 Git index로 커밋·푸시한다. 미디어와 재생성 가능한 래스터 이미지는 로컬에 보존한다. 업로드는 비공개만 허용된다.

진행 상태의 근거는 queue.json에 기록한다. 계획·실행 시작을 완료로 표시하지 않는다.

2026-10-06 기준 8장 3D 회전의 비공개 검수본 네 편을 완성했다. 모든 편의 실제 업로드 화면에서 플레이어 CC를 끈 채 한국어 영구 자막을 직접 확인했으며, 수동 KO/EN 자막·영어 제목과 설명·썸네일·PART2 재생목록·00:00 과외 카드·마지막 10초의 구독/재생목록/과외 링크를 저장하고 다시 열어 검수했다. 저작권 및 광고 적합성 자동 검사에서 발견된 문제가 없었다. 원본 회원 사진·이름·배지가 엔딩 요소에 가리지 않는 것도 직접 확인했다.

각 편의 현재 clean/한국어 자막 MP4와 KO/EN SRT는 저장소 루트 `output/<slug>/`에 모았으며 `output/index.html`에서 찾을 수 있다. 전체 청취, 공개용 게임 IP 검토, 잘린 회원 핸들 확인은 사람 검토 대기이며 `publishReady=false`를 유지한다. 비공개 영상의 과외 고정 댓글은 준비만 되어 있고 아직 게시·고정하지 않았다.

2026-10-07 기하 ①의 22개 장면과 244개 한영 자막, 실제 게임 40% / 설명 60% 본문, 배경음악 없는 내레이션을 완성했다. 실제 비공개 업로드에서 영구 자막을 직접 확인했고, 수동 한영 자막·영어 제목과 설명·썸네일·PART2 재생목록·00:00 과외 카드·마지막 10초의 세 엔딩 요소를 저장하고 다시 검수했다. 세 엔딩의 실제 60fps 시간은 `17:31:40`–`17:41:40`이며 원본 회원 사진·이름·배지를 가리지 않는다. 현재 Studio의 자동 검사 완료 후 알림 없음, 저작권 보호 콘텐츠 미발견, 광고 사용 및 미드롤 저장 상태를 각각 실제 화면으로 확인했다. 근거는 프로젝트의 `publishing/youtube-upload.json`에 연결되어 있다.

2026-10-06에는 “논문 실험 먼저 진행해야 해서 이것까지만 완료되면 일단 정지해줘~”에 따라 기하 ① 납품 후 남은 18편을 정지하고 대본·음성·lookdev를 보존했다. 이 정지 이력과 기존 `GPU_TTS_HOLD.json`의 해제 이력은 삭제하지 않는다.

2026-10-08 사용자가 **“작업 진행 계속 해주고”**와 GPU TTS 전후 학습의 안전한 중단·재개를 지시했다. `queue.json.executionControl.mode=active`로 재개했다. 현재 연구 학습을 끝낸 뒤 최종 저장과 완료 표식을 확인하고 큐의 `STOP`으로 새 GPU 작업을 막는다. TTS 종료 후 자신이 만든 요청만 해제하고 원래 명령·작업 디렉터리로 큐를 다시 실행해 완료 표식 다음부터 진행한다. GPU를 보유한 학습 프로세스를 강제 종료하거나 일시정지하지 않는다. 실제 인계·재개는 `gpu-handoff.py`와 프로젝트의 `production/gpu-scheduling.json`에 기록하며, 자원 대기 중인 큐를 실제 GPU 실행으로 표시하지 않는다. 강의별 무BGM·실제 게임 40%/설명 60% 예외와 비공개 납품·선택적 Git 전달을 유지한다.

같은 날 기하 ② 평면과 무게중심 좌표를 비공개로 저장했다. 22개 장면·237개 한영 자막·62250프레임을 검수했으며 한국어 및 영어 수동 자막의 실제 게시 상태, 별도 영어 제목·설명, 썸네일, PART2 재생목록, 00:00 과외 카드와 마지막 10초 세 엔딩 요소를 저장 후 다시 열어 확인했다. 플레이어 CC를 끄고 영구 자막과 원본 회원 표시를 직접 확인했으며 저작권·광고 자동 검사에 발견된 문제가 없었다. 제작 기록 커밋 `9dec7c5838b5311d0afae9925e5a6521f871cd91`과 실제 플랫폼 증거 커밋 `5e2f3e8a1bc12910e5ce2fd44004ca2657e509b4`를 각각 정상 푸시하고 원격 SHA를 대조했다.

현재 기하 ③ 삼각형의 중심과 다각형 분할은 16:23.5833·59015프레임·204개 자막의 로컬 렌더와 직접 수학/픽셀 검수를 완료했다. 본문은 실제 게임 23318프레임·설명 34977프레임으로 정확한 40:60이다. 비공개 업로드는 아직 준비 단계이며 완료로 기록하지 않는다. 이 편의 세 차례 GPU TTS 인계 후 원래 연구 큐를 재개했고 실제 완료 항목이 206에서 212로 늘어나는 것을 확인했다. 기하 ③ 비공개 납품과 선택적 Git 전달 후 다음 순서는 렌더링 ① 빛에서 화면까지다.
