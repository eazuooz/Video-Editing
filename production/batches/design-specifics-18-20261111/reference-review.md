# 게임 설계 디테일 원문 검수

[공식 재생목록](https://www.youtube.com/playlist?list=PLgKCjZ2WsVLQUWyKv2-ee6ds7uxtFiZeO) 순서로 DS01부터 DS18까지 관리한다. DS는 기존 게임디자인 작업표의 D와 별개다. 연구 파일은 격리 폴더에 둔다. 전 구간의 화면 자막을 읽고, OCR 오독 가능성이 있는 용어와 중요한 시연은 해당 화면과 대조한다. 독립 게임 녹화의 화면과 권리를 검증한 뒤 대사와 인·아웃을 확정한다.

## DS01 중요한 순간의 정지 | 게임은 왜 결정타에서 잠깐 멈출까?

| 원문 위치 | 유지할 학습 단계 | 자체 해설과 화면 설계 |
| --- | --- | --- |
| 0:03–0:28 | 손으로 구현하고 조정하는 설계의 세부 중 하나인 정지 연출 | 결정타의 접촉과 결과가 한눈에 보이는 독립 녹화에서 바로 시작한다. 시리즈 소개와 제작자 소개는 생략한다. |
| 0:32–1:02 | 일반 타격 직후의 짧은 정지와 접촉 피드백 | 같은 입력·타격·카메라에서 정지만 켜고 끈 모형으로 비교한다. 게임 시간과 효과 시간을 구분한다. |
| 1:03–1:43 | 피니시 줌과 보스 처치 정지, 플레이어 패배에도 적용 | 마지막 타격, 결과를 기다리는 짧은 순간, 결과 공개를 타임라인에 붙인다. `Boss Stop`은 설명에 쓰는 이름이며 엔진 API나 통일된 표준명이 아니다. |
| 1:44–3:07 | 화면 정보가 많은 슈팅에서도 피격 원인을 읽게 한다. 정지를 쓰는 고전의 역할 | 일반 진행과 피격 순간을 구분해 탄·기체·접점 순서로 시선을 유도한다. Fantasy Zone과 Defender는 동일한 게임의 독립 FHD 구간이 확인될 때만 확정한다. 교체 시 피격 위치가 정지 구간에 계속 보이는 동등 사례가 필요하다. |
| 3:07–4:00 | 무연출 → 정지 → 흔들림 → 슬로모션을 추가해 차이를 관찰 | 자체 슈팅 한 장면에서 조건만 하나씩 변경한다. 접촉, 충격 방향, 다시 읽는 시간이 각각 어느 효과에서 오는지 별도 트랙으로 보여 준다. |
| 4:00–4:10 | 승리와 실패를 알아차리게 중요한 순간에 시선을 붙든다 | 도입의 결정타 장면으로 돌아와 효과를 넣을 판단 기준을 답한다. |

관련 기존 A10은 맞았을 때의 자세·경직·밀려나는 방향에 집중한다. DS01은 화면의 정지 구간으로 승패와 피격의 원인을 읽게 하는 편이다. DS04의 세부 흔들림이나 판정 구현은 DS01의 결론 이후 별도 회차에서 풀어낸다.

## DS02 버튼의 무게 | 같은 버튼인데 왜 어떤 캐릭터는 더 무겁게 느껴질까?

| 원문 위치 | 유지할 학습 단계 | 자체 해설과 화면 설계 |
| --- | --- | --- |
| 0:03–0:45 | 같은 스위치의 물리적 저항과 화면 반응으로 느끼는 무게를 구분 | 소닉이 출발해 배경이 빨리 흐르기 시작하는 독립 녹화로 도입한다. 같은 입력을 통제하는 비교는 바로 뒤 자체 시연에 배치한다. 적응형 트리거는 구분에 필요한 한 문장으로 다룬다. |
| 0:47–1:12 | 같은 입력이 속도·관성·점프·지연·프레임의 차이로 달라 보임 | 한 장면에서 속도/가속/감속을 차례로 바꾼다. 지연은 입력 후 첫 변화까지, 관성은 변화 뒤의 운동으로 분리한다. 상용 게임에 입력 지연값을 덧씌우지 않는다. |
| 1:15–1:39 | 손 입력이 게임에 들어가고 화면과 소리가 플레이어에게 돌아오는 루프 | 버튼 → 처리 → 화면·소리 → 다음 입력의 흐름을 한 화면에 점진적으로 그린다. |
| 1:41–1:57 | 캐릭터별 이동 속도와 빈틈, 모션 차이가 역할과 대전을 바꿈 | 둘이 같은 거리에서 기술을 내고 다시 움직일 수 있게 되는 시점을 비교한다. 빠름과 무게가 각각 어떤 선택을 유도하는지 보여 준다. |
| 1:58–2:15 | 아날로그 스틱의 입력이 감지되는 최솟값도 기기별 보정 항목 | 스틱 중심 근처 입력을 자체 모형에 넣어 데드존 경계를 넘을 때 반응이 시작되는 것을 보여 준다. 방향 감도와 최저 감지값을 구분한다. |

기존 원버튼 영상은 입력 하나에 여러 선택을 매핑하는 편이다. DS02는 고정 입력에 돌아오는 반응과 체감의 편이다.

## DS03 점프 물리 | 같은 점프인데 왜 마리오와 사무스는 다르게 느껴질까?

| 원문 위치 | 유지할 학습 단계 | 자체 해설과 화면 설계 |
| --- | --- | --- |
| 0:04–0:30 | 점프에서 속도와 가속도를 구분 | 바닥을 밀고 떠난 뒤에도 중력이 아래쪽으로 작용한다. 인가되는 값은 고정 낙하 속도가 아니라 아래 방향 가속도다. |
| 0:31–1:17 | 초기 상승, 감소, 꼭짓점, 낙하 | Manim에서 Y 속도 화살표를 발 위치에 붙이고 위→0→아래로 바뀌는 모습을 보여 준다. 같은 높이·일정한 중력·공기 저항 없음 조건에서 이륙과 착지 속력 크기가 같은 이유를 설명한다. 프레임별 상수 나열은 생략하고 부호와 관계는 유지한다. |
| 1:18–1:40 | X 이동과 Y 운동을 분리, 관성과 제한은 별도 설계 | 같은 세로 곡선에서 공중 조향만 바꿔 도달점이 달라지는 그림. 실제 게임에서 내부 계수를 역산했다고 표시하지 않는다. |
| 1:42–2:42 | 마리오의 홀드 높이와 상승/낙하 차이, 사무스의 체공 사격, 마계촌의 고정 방향 | 관찰 가능한 현상을 원본 순서대로 비교한다. 작품 버전과 공중 입력 규칙을 독립 화면에서 확인한다. |
| 2:45–3:09 | 장기에프 잡기의 경로와 속도 배분 | 초기판과 터보를 정확히 식별할 수 있는 FHD 자료가 필요하다. 같은 경로를 서로 다른 시간에 통과하는 자체 도식으로 원리를 따로 보여 준다. |
| 3:09–3:39 | 점프 스쿼트와 위 스매시 입력 우선순위 | 위 입력과 공격 입력의 판정 창을 자체 타임라인에 표시한다. 준비 자세 길이의 시리즈별 차이와 같은 설정으로 통일한 버전을 구분한다. |
| 3:41–4:42 | 강한 초기 상승, 빠른 감속, 이후 기본 중력과 늦은 회피의 이점 | 점프 높이만으로 초기 반응을 판단하기 어려운 이유와 추가 상태의 테스트 부담을 설명한다. |

기존 `projects/jump-physics`의 6분 13초 완성편은 같은 학습 순서를 포함한다. 자체 설명과 승인된 PCM은 적용 범위를 대조해 재사용한다. 기존 조합본의 게임 클립은 720p로 정규화됐으며 감속과 도입 몽타주가 있어, 이 배치 검수본의 원본 규격과 도입 근거로 채택할 수 없다. 기존 프로젝트와 게시본은 별도 기록으로 보존한다.

| 원문 위치 | 유지할 학습 단계 | 자체 해설과 화면 설계 |
| --- | --- | --- |
| 0:03–0:57 | 적중 시 두 동작을 잠깐 붙잡는 효과, Final Fight의 인지, Smash의 흔들림 | DS01에서 익힌 타격 멈춤을 짧게 상기하고 이 편의 질문을 구현의 차이로 좁힌다. |
| 0:58–1:20 | 받는 쪽의 흔들림을 더 크게 | 접점은 공유하고 모델 표시 진폭만 비교한다. |
| 1:21–1:38 | 표시 모델과 판정 범위를 분리 | 충돌에 쓰는 `Hurtbox`는 고정하고 표시 모델만 이동시킨다. 상용 게임 내부 판정으로 오인하지 않도록 자체 구현 표시를 넣는다. |
| 1:38–2:09 | 지상은 가로, 공중은 세로도 허용 | 발 접촉과 바닥 관통이 보이는 동일 카메라 A/B. |
| 2:10–2:26 | 정지 끝으로 갈수록 흔들림 감쇠 | 시간이 흐르면서 시각 진폭이 작아지는 연결 그래프. |
| 2:26–3:13 | 위력과 기술별 배율로 길이를 조절 | 마르스 검끝/안쪽, 류/카즈야의 차이 역할을 유지한다. 정확한 원본이 없는 비교는 독립적으로 구현한 배율의 예시로 구분한다. |
| 3:13–3:42 | 피격 포즈까지 여러 프레임 보간 | 스냅과 보간을 같은 시작/도달 포즈로 비교. |
| 3:43–4:30 | 공격자는 일부 기술에서 느리게 움직여 절단감을 남김 | 공격·피격·판정·카메라 트랙을 분리한다. 기술별 선택과 번개/다인전 조건은 옵션의 역할만 전달한다. |
| 4:40–5:19 | 멀리서는 더 크게 흔들어 화면에서 유사하게 읽힘 | 월드 이동과 화면상 이동을 구분하고 두 거리에서 시인성 비교. 각각의 작은 변화가 함께 충격을 만든다는 결론. |

기존 A03의 핵심은 공격 동작 단계와 조건부 정지이며, A10은 피격 자세다. DS04는 8가지 조정이 겹쳐도 판정과 움직임을 유지하는 구현에 집중한다.

기존 D15는 멀미와 카메라 운동의 충돌을 줄이는 편이다. DS05의 중심은 캐릭터의 이동을 화면 안에서 얼마나 보이게 할지다.
