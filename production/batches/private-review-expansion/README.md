2026-10-01 사용자 요청: `지금까지 비공개로 올려진 영상이 다그러네 피피티 내용을 줄이지는 말고 여기에 중간삽입으로 대본을 늘려서 진행해줘`.

실제 Studio의 최근 제작 비공개 5편을 확인했다. 프레임 세기 → 분석·재조립 → 퀘스트 → 칭찬 → 입력 응답 순서로 수정한다. 기존 24편의 새 주제 제작보다 우선한다. 2025년 무료 에셋 영상은 이번 제작과 무관하다. 원버튼 DeSXTV41GXs는 최초 목록 확인 때 예약 상태였고, 이후 실제 Studio 대시보드에서 사용자 공개 완료 상태를 확인했다. 사용자가 관리하는 공개·예약을 임의로 변경하지 않는다.

기존 업로드본의 모든 설명·PPT·도식형 자체 테스트와 승인 내레이션을 유지하고, 설명 사이에 개념과 맞는 실제 게임·개발 동작과 새 한영 해설을 추가해 전체 길이를 늘린다. 자체 테스트가 숫자·도표 중심이면 실제 영상으로 계산하지 않는다. 인트로 2초와 회원 엔딩 10초를 제외한 본편은 실제 영상 60% / 설명 40%, 반올림 최대 1프레임이다. PPT를 줄이거나 덮어써 비율을 맞추지 않는다.

각 프로젝트의 `production/private-expansion-baseline/preservation.json`이 업로드 당시 타임라인·대본·자막·미디어 해시와 보존본을 기록한다. 미디어는 로컬 전용이며 Git에 넣지 않는다. counting-animation-frames의 기준은 업로드된 final-v1이다. PPT를 일부 대체한 로컬 final-v2도 보존하되, 이번 final-v3에서는 업로드본 설명 전체를 복구해 유지한다.

새 후보와 최근 사용 구간을 다시 검토하고, 각 추가 대사의 실제 동작·시청자 관찰점·원래 설명 연결·출처 인아웃을 기록한다. 짧은 자료를 반복하거나 저속으로 늘리지 않는다. 승인 목소리/Qwen3-TTS 1.7B와 연속 Nimbus, 고양이 인트로, 원본 회원 프로필·이름·배지 및 정확한 제목을 유지한다. 추가 음성 실측 뒤 믹스·모든 씬 시작·KO/EN SRT·챕터·엔딩 위치를 함께 갱신한다.

단일 합성·렌더만 실행하고 실제 PID/세션/로그를 queue.json에 남긴다. 다른 프로젝트의 GPU 학습을 중단하지 않는다. 전체 ASR·모든 자막/컷 화면·전체 디코딩·음량·true peak·두 MP4 오디오 일치를 검수한 뒤 4개 파일을 수집한다. 사람 청취·게시 권리·원래 Nimbus 파일·잘린 회원 핸들·외부 백업은 실제 완료 전까지 pending이다.

YouTube는 영상 파일 자체를 교체할 수 없으므로, 완성 수정본은 의도적인 새 비공개 검토 업로드로 원래 ID와 새 ID를 연결한다. 기존 업로드와 영수증은 삭제하지 않는다. docs/YOUTUBE_PUBLISHING.md의 썸네일·한영 수동 SRT·영어 제목/설명·00초 과외 카드·마지막 10초 재생목록/구독·광고/저작권 검사를 새 시간에 맞춰 적용하고 저장 상태를 실제 Studio에서 검증한다. 공개·예약은 사용자가 진행한다.

완성 한 편마다 재빌드 manifest와 media/rebuild 검사를 통과하고 승인된 제작 파일만 커밋·일반 푸시한다. 마지막에는 수정 배치의 실제 완료를 기록하고 기존 24편의 다음 비중복 주제 사전 검토로 돌아간다.
