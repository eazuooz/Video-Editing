격자 배경 제작 방식 비교

일반 게임에서 캐릭터만 분리하는 짧은 실제 시험과, 처음부터 격자 훈련장에서 촬영된 게임 영상의 비교입니다. 최종 영상이 아닌 제작 방식 검토용입니다.

1. 배경 분리·해설 합성 — CPU 시험

본편 채택 불가

왼쪽은 실제 게임 원본, 오른쪽은 자동 분리 결과입니다. 움직임과 타격 이펙트에서 배경·바닥·UI가 따라붙습니다. 실제 애니메이션 에디터 출력이 아닙니다.

Street Fighter 6 실제 게임 12–16초 / FHD 원본 / CPU GrabCut + optical flow / 무음 시각 시험

2. 실제 격자 훈련장 — 대안 후보

동작을 확인하기 좋은 원본 배경

SEGA 공식 New VIRTUA FIGHTER Project 개발 영상입니다. 머리카락·옷·팔·발과 가림이 유지됩니다. 게임의 실제 훈련장 화면이며, 애니메이션 편집 툴 화면으로 소개하지 않습니다.

공식 공개 게임 영상 24–28초 / 1920×1080 · 60fps / 원래 재생 속도 / 무음 시각 시험

3. 직접 만드는 설명 장면

임포트된 PHILIPP 휴머노이드 캐릭터의 걷기·달리기·소품 애니메이션을 Unity에서 실행하고 격자 무대를 직접 만들 수 있습니다. 편집 과정이나 원리를 자세히 보여 줄 때 적합합니다. 실제 상용 게임 예시와는 분리해 설명 영상으로 집계합니다.

이 후보는 파일·리그 참조·라이선스까지 확인했습니다. Unity에서의 새 실행·렌더 검수는 아직 하지 않았습니다.

제작·출처·권리·검수 기록

기술 검수는 움직이는 MP4의 연속 프레임 검사와 전체 디코딩 검사입니다. 실제 사람의 최종 시청 승인을 의미하지 않습니다.
