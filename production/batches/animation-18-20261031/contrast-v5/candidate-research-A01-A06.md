## A01 애니메이션 제작 지시

기존: New VIRTUA FIGHTER Project, Super Smash Bros. Ultimate, Untitled Goose Game.

**보존할 흐름:** 모호한 요청과 실제 결과의 차이 → 동작 목록·길이·반복/단발·판정 구분 → 사진/자세/무게중심으로 구체화 → 둘이 맞물리는 동작과 무기 경로 → 캐릭터성·비인간형의 다른 조건 → 실제 속도·리그 범위 확인과 피드백.

### Sifu — 여성 주인공

- 장르: 3D 액션 / 근접 격투 어드벤처
- 동작: 상단 회피 → 반격; 별도의 잡기/테이크다운 한 동작
- 설명 역할: 발 위치·상체 높이·상대와의 접점을 언어로 지정하는 역할
- 관찰할 전후: 양쪽 발과 상대 팔이 보이는 대치 → 몸을 낮추거나 뒤로 빼서 피한 뒤 반격 → 회피 방향·거리·몸 높이가 다음 행동에 이어짐
- 공식/개발자 근거: [Sloclap: How Sifu's kung fu combat works](https://blog.playstation.com/?p=356872) — 회피·구조·빠른/강한 공격의 구분. 선택할 테이크다운의 정확한 접점은 실제 녹화로 확인할 항목.
- 독립 녹화 후보: [SIFU (GIRL) Gameplay Walkthrough Part 1, 4K60 no commentary](https://www.youtube.com/watch?v=8VMAIosrhUM) — 초기 스쿼트 전투에서 상대 상단 공격 회피 후 반격; 정확 타임코드는 미선정
- 확인/제한: 영상 제목의 4K60 표시는 내려받은 파일의 검증이 아니다.
- 확인/제한: 정확한 회피 성공/잡기 접촉을 확인한 한 연속 동작만 사용. 다른 두 동작을 이어 하나처럼 만들지 않는다.

### Untitled Goose Game — 거위

- 장르: 퍼즐 / 샌드박스
- 동작: 부리로 물건 집기 → 목을 들어 운반 → 내려놓기
- 설명 역할: 사람 손 기준의 지시를 비인간형에 그대로 적용할 수 없다는 기존 예시 유지
- 관찰할 전후: 물건 앞에서 부리와 목이 가까워짐 → 부리 접점을 유지한 채 목·몸·다리가 함께 이동 → 부리를 놓으며 물건과 몸의 움직임이 분리됨
- 공식/개발자 근거: [House House official game site](https://goose.game/) — 개발사·배급사·게임 정체성. 스위치 출시만으로 Nintendo 소유작이 되지 않음.
- 독립 녹화 후보: [Untitled Goose Game PC 4K60 no commentary longplay](https://www.youtube.com/watch?v=yrI6ihmiEGM) — 초반 정원의 물건 집기/운반; [기존 House House 별도 게임 녹화(완성 강의 아님)](https://www.youtube.com/watch?v=wQknBJo4aBQ) — 11.5–19.5 부리 집기·운반; 164.5–170.9 채소 반복 운반
- 확인/제한: 신규 독립 플레이 기록 우선. 기존 자료를 유지하면 프리알파 판본임을 내부 기록하고 상용판 동작과 혼동하지 않는다.
- 확인/제한: 게임 소품을 손에 든 물건이라고 부르지 않고 부리 접점으로 설명한다.

### Pikmin 4 — 구조대원 + 오치

- 장르: 실시간 전략 / 탐색 퍼즐 · Nintendo 예시
- 동작: 오치에 올라타기 → 함께 이동 → 돌진 직전/돌진 후 자세
- 설명 역할: 서로 다른 몸이 맞물리는 상호작용, 탑승 위치와 몸 크기에 맞는 제작 지시
- 관찰할 전후: 구조대원과 오치가 떨어져 있음 → 탑승하며 구조대원의 몸이 오치 등 위에 놓임 → 같이 이동하거나 돌진하면서 탑승 접점이 유지됨
- 공식/개발자 근거: [Nintendo 개발자 인터뷰 Part 2](https://www.nintendo.com/en-ca/whatsnew/ask-the-developer-vol-10-pikmin-4-part-2/) — 111행 전후: 플레이어와 피크민이 오치를 타는 설계. 내부 애니메이션 구현 방식은 공개 근거 없음.; [Nintendo Pikmin 4 product](https://www.nintendo.com/en-ca/store/products/pikmin-4-switch/) — Nintendo 발매 작품 및 오치의 역할.
- 독립 녹화 후보: [Pikmin 4 full game no commentary](https://www.youtube.com/watch?v=LMPRYGIEA6Q) — 오치 성장 후 첫 탑승·돌진 튜토리얼; 정확 타임코드 미선정
- 확인/제한: 3D 사람끼리의 잡기를 대체하는 것이 아니라 상호 접점의 다른 사례. 사람끼리 접촉은 Sifu로 남긴다.
- 확인/제한: 돌진의 실제 충돌 프레임/내부 attachment 시스템은 관찰만으로 단정하지 않는다.

**단계 동시 화면 / 비교 개선**

- 첫 화면은 제작 요청 → 필요한 조건(시작/대상/접점/방향/끝) 관계도.
- 실제 UE 샘플에서 걷기/숙이기/회전/소품 집기를 각각 선택한다. 기존 한 주먹 동작의 재활용 금지.
- 탑승 또는 소품 장면은 접근·접촉·운반·분리 2×2 실제 단계 자세와 큰 연속 재생 화면을 결합한다.
- 정상 속도 3회 후 분석. 분석에서는 발 접지와 실제 소품 접점에만 가이드, 내부 리그 추정선 없음.

**대본 영향:** Sifu·Pikmin으로 바뀌는 고유명사/눈에 보이는 행동만 이후 승인 범위에서 치환. 제작 목록·판정/모션 구분·피드백 내용은 유지.

**Nintendo 예시:** 1/3 — Pikmin 4만 Nintendo. Goose의 스위치 출시는 카운트 사유가 아님.

## A02 동작의 과장

기존: THE KING OF FIGHTERS XIII — Kula Diamond, TEKKEN 8 — Lili.

**보존할 흐름:** 실제 화면 크기에서 읽히는 과장 → 작은 캐릭터와 전신 변화 → 어깨의 회전과 이동/리그 제한 → 한 프레임의 뒤틀림보다 연속 인상 → 오버슈트와 정착.

### THE KING OF FIGHTERS XIII — 쿨라 다이아몬드

- 장르: 2D 격투
- 동작: 낮아진 어깨에서 솟는 팔·착지 몸통; 공중 회전 후 낮게 미끄러지는 착지
- 설명 역할: 세로로 긴 실루엣과 가로로 긴 실루엣을 같은 연속 동작에서 읽기
- 관찰할 전후: 랄프 앞에서 몸을 낮춤 → 팔·어깨를 펴며 상승 → 착지에서 몸통이 접히고 낮은 이동으로 이어짐
- 공식/개발자 근거: [SNK official KOF character portal](https://www.snk-corp.co.jp/us/games/kof-portal/characters/) — Kula Diamond의 출연작에 KOF XIII 포함. 실제 포즈는 기존 독립 녹화 증거.
- 독립 녹화 후보: [Ercdouken KOF XIII arcade capture](https://www.youtube.com/watch?v=hw46zmUsOtE) — 상승: 정상169.9–171.55, 분석170.3–171.5; 회전: 정상319.33–321.16, 분석319.55–320.9
- 확인/제한: 기술명/입력이 보이지 않아 Crow Bite나 Ray Spin으로 임의 확정하지 않는다. 관찰한 동작 묘사를 사용한다.
- 확인/제한: XIII의 스프라이트를 XV의 3D 리그 구조 증거로 쓰지 않는다.

### TEKKEN 8 — 리리

- 장르: 3D 격투
- 동작: 가로 발차기 뒤 상체를 낮추고 다리를 위로 세우는 연속 동작
- 설명 역할: 몸통·골반·다리 축의 큰 변화; 한 프레임 교정보다 실제 재생 인상
- 관찰할 전후: 첫 발차기에서 가로 방향 확장 → 몸통을 낮추며 다리의 축 변경 → 위로 길어진 모양 뒤 착지/회복
- 공식/개발자 근거: [Bandai Namco official Lili character](https://tk8.tekken-official.jp/character/?chara=lili) — 캐릭터 정체성과 격투 스타일. 정확 기술명은 현재 영상 입력 대조 전 미확정.
- 독립 녹화 후보: [aarmani Lili CNT practice](https://www.youtube.com/watch?v=f0J2t8Vt9Vc) — 정상19.75–22.7; 분석20.43–22.47; 21.90–22.05는 보이는 몸통·허벅지만 표시; [KeizoHasumi retail Lili ranked capture](https://www.youtube.com/watch?v=a_k1Fgrlyms) — 223.8–235.9 등 기존 검수 범위
- 확인/제한: CNT 화면의 수치·피해량·프레임을 현재 밸런스 값으로 인용하지 않는다.
- 확인/제한: 화면 밖 발끝을 추정한 박스/궤적 금지.

### Splatoon 3 — 잉클링 / 다이너모 롤러

- 장르: 3인칭 팀 슈터 · Nintendo 예시
- 동작: 무거운 롤러 들어 올리기 → 가로/세로 휘두르기 → 몸을 정리하는 동작
- 설명 역할: 격투 이외 작은 플레이 캐릭터도 몸 전체와 무기 실루엣으로 행동을 전달함
- 관찰할 전후: 롤러가 낮게 놓임 → 무기·팔·상체가 함께 크게 올라가고 전방으로 휘둘러짐 → 잉크가 퍼지고 몸이 다음 행동 자세로 정리됨
- 공식/개발자 근거: [Nintendo official roller explanation](https://splatoon.nintendo.com/base/en/fashion/weapons/?weapon=4) — 가로/세로 휘두르기의 다른 범위와 다이너모의 무거운 휘두름.; [Splatoon 3 official weapons](https://splatoon.nintendo.com/en/weapons/) — 게임과 무기 계열.
- 독립 녹화 후보: [Zebra Gamer: Dynamo Roller, Splatoon 3 Part 61](https://www.youtube.com/watch?v=crJ46-pn4hU) — 다이너모 롤러 플레이 구간; 타임코드 미선정
- 확인/제한: 기록자 해설이 있어 무해설 대체본 또는 허가/오디오 분리 검토 필요.
- 확인/제한: 게임이 어깨를 1.8배 이동시킨다는 주장 금지. 1×/1.8×는 우리 UE 시연의 제어값만.
- 확인/제한: 오버슈트가 확인되지 않으면 이 클립을 오버슈트 증거로 쓰지 않는다.

**단계 동시 화면 / 비교 개선**

- 기존 UE 1× / 1.8×는 캐릭터 자체 크기와 카메라·동작 시간·발 기준을 동일하게 고정한다.
- 어깨 고정 vs 어깨 이동에서는 바뀐 어깨의 실제 UE 좌표/실루엣만 표시. 단순 동작 범위 비교와 어깨 리그 비교를 구분한다.
- 정상3회 후 시작·최대 확장·반전·복귀 4단계 실제 포즈를 동시에 보이고, 고스트와 어깨 이동선으로 차이 강조.
