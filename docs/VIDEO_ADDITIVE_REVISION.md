# 기존 영상의 보강 — 유지와 최소 변경

현재 절차는 [통합 제작 규칙](VIDEO_WORKFLOW.md)이다. 이 문서를 별도 필수 전체검수 루프로 사용하지 않는다. 누적 완료영상/옛 상태 기록은 [원문 보관본](history/video-policy-before-20261013-consolidation/docs/VIDEO_ADDITIVE_REVISION.md)에 있으며 현재 완료/공개 상태는 해당 프로젝트의 최신 receipt/Studio가 우선한다.

1. 기존 영상 검토에서 현재 ID/상태·대본·미디어·검수 근거를 읽고 충족 부분과 실제 문제를 나눈다. 같은 해시/관련 설정의 검수는 재사용한다. 단순 새 규칙 기록으로 미디어를 재제작하지 않는다.
2. 사용자에게 해당 편의 문제 위치·유지 범위·수정안·영향을 보여 주고 제작 범위를 확인한다. 새 운영에서는 다음 편/다음 큐로 자동 이동하지 않는다.
3. 좋은 설명·주장·원문 순서·수식·승인PCM·설명 길이를 보존하고 필요한 선행 설명/실제 관찰/비교를 해당 대목 사이에 넣는다. 기존→유지/추가/수정 대응을 기존 계획에 기록한다.
4. 해당 Sakurai 원본의 전체 대사·화면에서 주장/순서/예시/결론을 유지하고, 해당 위치에 세부 설명 PPT를 보강한다. 원본 게임의 오래된 버전만 개념이 동등한 최신 버전으로 검토하며 기본 추가 게임은 없다. 실제 자료를 확보·재생한 뒤 보이는 전→행동→후에 맞춰 독립 KO/EN 대사를 확정한다. 인과 연결/상세2.5D/고정자막도 포함한다. 본편60:40이면 추가 actual 최초계획은 `max(0,1.5*retainedExplanationSeconds-retainedActualSeconds)`이며 새 설명·새음성 실측 후 다시 계산한다. 강의40:60 예외에 이 공식을 복사하지 않는다.
5. 변경 PCM/씬만 생성하고 타이밍이 바뀌면 믹스·씬시작·KOEN·챕터·엔딩을 함께 갱신한다. 시각 수정은 TTS 재생성 사유가 아니다. 원본 역사파일/납품/승인을 보존한다.
6. 변경구간과 접합부의 실제 움직임·자막·믹스를 검수하고 새출력의 전체decode/PTS/길이/음량/동일AAC를 확인한다. 전체를 다시 만드는 대신 통합 규칙의 영향 범위 표를 따른다. 준비/샘플/후보는 최종승인이 아니다.
7. 현재4파일 수집·사용자 확인·승인 범위의 단일비공개/설정/Git을 처리한다. 검수한 교체본 없이 기존 업로드를 먼저 삭제/예약 이동하지 않는다. 완료 후 사용자가 다음 편을 선택할 때까지 멈춘다.

과거 완료본의 게임 구성/팔레트/자체 예시/옛 예약간격 등은 당시 근거이지 신규 제작 규칙이 아니다. 사용자가 사례나 구성을 명시적으로 바꾸면 새 지시가 우선하며 기존 버전/PCM/자료는 보존하고 현재 미사용으로 기록한다. 해당 편의 필요한 수정만 수행한다.
