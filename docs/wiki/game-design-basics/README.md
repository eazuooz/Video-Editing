Notion 게임 디자인 기초: https://www.notion.so/3de0b1ffa61e80f4b411f7f227d52b43

AI 글은 사용자가 `게임 업계 이야기, 프로그래밍 이야기` 아래로 이동했으므로 그 위치와 변경한 제목을 유지했습니다. 네 글 맨 위에 사용자 채널의 해당 YouTube 게시본을 네이티브 동영상 블록으로 삽입했습니다. 앞으로의 영상 기반 위키 문서도 상단 임베드 + 독립적으로 읽을 수 있는 본문을 기본으로 합니다.

사용자 요청에 따라 튜토리얼, 점프, 프레임, AI 시대 개발자 공부를 각각 독립적인 서사형 문서로 작성했습니다. 본문만으로 이해할 수 있도록 영상의 전후 동작을 서술하고 실제 영상 캡처 20장을 첨부했습니다. 원본 영상과 자막은 수정하지 않았습니다.
