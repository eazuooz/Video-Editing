# 설명 샘플·썸네일 규격

승인·전체 검수·변경분 재사용은 [통합 제작 규칙](VIDEO_WORKFLOW.md)을 따른다. 설명용 상세 대상·투영·색은 [화면 규격](VIDEO_VISUAL_STYLE.md)이 기준이다.

## 제작 전 시각 샘플

새 시각 체계에서 대표 설명 동작과 가장 까다로운 자막/UI 구간을 짧게 제작한다. 실제 최종 서체·48px/두 줄 고정 자막·정확 crop·프레임 시점을 적용한다. 원근 면·두께·앞뒤 가림, 상세 인물/사물과 내레이션에 맞는 비교 동작을 움직이는 픽셀로 확인한다. 그림자 붙인 평면 카드, 자막 없는 raw 화면, 정지 이미지 한 장은 충족하지 않는다. 동일 승인 샘플을 모든 보고서용으로 재생성하지 않는다.
