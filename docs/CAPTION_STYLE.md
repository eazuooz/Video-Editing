# 채널 기본 자막 — 흰 박스와 짙은 초록 그림자

스타일 ID: `boxed-white-forest-v1`

2026-09-19 사용자가 참고 이미지 기반 샘플을 “응 이렇게 만들어줘 ㄱㄱ”로 승인하고,
이어 “그리고 이 자막스타일 기억해줘~”라고 요청했다. **앞으로 만드는 영상의 내레이션
자막 기본값**으로 사용한다. 프로젝트별 다른 요청이 있으면 그 요청을 우선하고
`project.json.editing.captionStyle`에 예외를 기록한다. 기존 완성작은 자동 변경하지 않는다.

## 디자인 수치

1920×1080 기준이며 다른 출력 크기에서는 비례 조정한다.

| 항목 | 기본값 |
| --- | --- |
| 박스 | 불투명 흰색 `#ffffff`, 모서리 반경 0 |
| 글자 | 검정 `#080b09` |
| 테두리 | `#161b18`, 3px |
| 그림자 | 짙은 초록 `#073c32`, 오른쪽 14px·아래 14px, 블러 0 |
| 서체 | Noto Sans KR, 500, 48px; Malgun Gothic / sans-serif 폴백 |
| 줄 높이 | 62px |
| 배치 | 하단 중앙, Motion Canvas 중심 좌표 `(0, 430)`; 화면 좌상단 기준 중심 `(960, 970)` |
| 글줄 최대 폭 | 1570px; 실제 글자 폭을 측정해 박스 폭 자동 조정 |
| 내부 여백 | 좌우 각각 22px, 위아래 각각 11px |
| 최대 줄 수 | 2줄 |

참고 이미지의 정확한 원본 서체가 확인된 것은 아니다. 승인 샘플에서 사용한 유사 서체와
수치를 유지한다. 참고 이미지의 그래프·통계·종이 질감까지 채널 공통 디자인으로 채택한 것은 아니다.

## 편집과 검수

- 자막은 후편집 가능한 텍스트로 유지한다. 이미지에 글자를 합쳐 저장하지 않는다.
- 실제 내레이션의 timing JSON / SRT를 기준으로 표시하며, 스타일 변경만으로 발화·영상 길이·음량을 바꾸지 않는다.
- 긴 문장은 의미 단위로 줄바꿈한다. 두 줄을 넘으면 문구를 읽기 좋게 나누고 실제 발화에 맞춰 KO/EN 큐를 함께 조정한다. 무조건 축소하거나 문장을 자르지 않는다.
- 모든 큐에서 박스·테두리·그림자까지 화면 안에 들어가는지 확인한다. 한 줄·두 줄 모두 핵심 게임 UI, 인물, 도식과 겹치지 않게 한다.
- 기존 하단 요약 띠와 자막을 같은 자리에 겹쳐 놓지 않는다. 자체 설명 화면의 요약은 위로 옮기거나 중복 내용을 생략하고, 자료화면은 핵심 동작이 가리지 않게 배치한다.
- 자막 없는 구간에는 빈 박스를 남기지 않는다. 추가 튀기기·노래방식 강조 등은 기본값이 아니다.
- 실제 출력 캡처와 모바일 크기로 가독성을 확인한다. 서체 로딩 실패나 세 줄 이상 표시를 검수 없이 승인하지 않는다.

## 기본 납품 구성

1. 전체 오디오 믹스가 포함된 무자막 마스터: `paths.videoClean`
2. 위 스타일을 적용한 한국어 자막판: `paths.videoBurnedCaptions`
3. 별도 한국어·영어 SRT: `paths.captionsKo`, `paths.captionsEn`

두 영상은 같은 장면·길이·오디오 믹스를 사용한다. 영어 고정 자막판은 요청 시 추가한다.
YouTube SRT는 이 박스·서체 디자인을 전달하지 않는다. 디자인 고정이 목적이면 자막판,
자막 언어 선택이 우선이면 무자막판과 SRT를 사용한다. 고정 자막과 플레이어 자막의
이중 표시 여부도 확인한다. 스타일 승인과 대본·목소리·음악·최종 게시 승인은 별개다.
