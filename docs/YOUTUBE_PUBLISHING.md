## 자동화 기록과 완료 확인

프로젝트의 `publishing/youtube-upload.json`에 제목·설명·언어별 자막 파일·썸네일·카드 URL/시점·최종 화면 요소/시점·실제 영상 ID·공개 상태와 검증 결과를 기록한다. 수동 자막 두 개와 영어 메타데이터의 실제 게시 상태, 00:00 링크 카드, 마지막 10초 요소를 Studio에서 확인하고 증거 화면을 보관한다. 설정 JSON이 존재하는 것과 실제 업로드 완료를 구분한다.

기본 공개 상태는 비공개 검토본이다. 비공개 업로드는 공개 게시 승인·권리 검수 완료를 뜻하지 않는다. 사용자 지정 썸네일과 업로드 설정만 변경하는 경우 원본 MP4·SRT·오디오·타이밍은 재생성하지 않는다. 매시간 제작 자동화는 완성본의 비공개 업로드까지 수행한다. 공개 예약은 사용자 직접 작업이며 자동 수행하지 않는다.
