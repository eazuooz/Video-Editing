## 관리 기준과 근거

- 기준 파일: [영상별 상태](../shared/publishing/video-worklist.json). 표를 갱신할 때 `python scripts/render-video-worklist.py`를 실행한다. 각 편의 상세 계획·검수 원장은 해당 프로젝트의 기존 파일을 사용한다.
- [실제 Studio 상태 확인](../shared/publishing/video-worklist-studio-observation.json): 최신 100개 행에서 현재 공개/비공개/예약을 확인했다. 오래된 예약표의 날짜를 현재 예약으로 승계하지 않았다. 목록에서 보이지 않은 과거 ID는 삭제로 단정하지 않는다.
- [게임디자인 순서](../production/batches/sakurai-planning-game-design/playlist-inventory.json), [기존 게임수학 순서](../shared/publishing/daily-alternating-schedule.json), [렌더링 시리즈 계획](../production/research/game-lighting-history/series-plan.json)을 연결했다. 과거 길이 제한·자동 작업 지시는 적용하지 않는다.
- 기존 비공개 영상에는 대사 연결, 쉬운 선행 설명, 정식 용어, 독립 게임 자료, 화면 표식, 자연스러운 TTS·국소 음량, 1080p60·모바일 가독성을 선택 시 검수한다. 최신 규칙 때문에 미선택 완성본을 자동 재제작하지 않는다.
- M21 이후는 기존 승인 상한 밖 후속 후보다. 이번 목록 작성으로 착수하지 않는다.
- 별도 완료 영상 「AI 시대 게임개발과 실력」은 현재 Studio에서 2026-10-16 예약 상태를 확인했다. 기존 설정을 유지한다.
