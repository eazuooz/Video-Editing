# 실제 자료 선정 규격

단계·사용자 확인은 [통합 제작 규칙](VIDEO_WORKFLOW.md)을 따른다. 이 문서의 항목은 대본 작성 전 소스 선정에 적용한다.

1. **사쿠라이 영상은 참고 자료이며 편집 재료가 아니다.** 그의 강의·해설 영상과 그가 설명하는 Nintendo Direct/행사 실연에서 게임 컷·화면·PPT·자막·내레이션·오디오를 추출해 완성본에 넣지 않는다. 음소거·크롭·우리 자막 추가만으로 별도 게임 원본이 되지 않는다. 해당 자료는 `research-reference-only`로 기록하고 제작 컷 목록에서 제외한다.
2. 참고에서 파악한 게임과 사례 역할을 바탕으로 **별도로 실제 게임 플레이·메뉴 조작 영상을 검색하고 확보**한다. 독립 플레이 녹화나 사용 조건을 확인한 공식 게임 원본 등에서 필요한 동작을 직접 찾는다. 위 참고 해설/발표 영상은 여기에 해당하지 않는다. 채택 후보는 `independent-gameplay`로 구분하고 원본URL/업로더·권리자/버전/사용 조건/오디오 권리/정확 인아웃/최근 사용을 기록한다. 공식·무해설·온라인 공개라는 이유만으로 재사용 허가를 가정하지 않는다. 설명은 우리 내레이션과 직접 만든 상세 PPT로 제작한다.
3. 후보 구간을 실제 재생해 전 상태→행동→결과와 시점·가림·UI가 처음 보는 사람에게 얼마나 명확한지 비교한다. 선택/제외 이유, 필요한 게임 규칙과 해설을 `sources/game-candidates.json` 또는 기존 출처표에 남긴다. 유명세·새로움·긴 분량·검색 제목은 채택 근거를 대신하지 않는다.
4. 실제로 관찰한 행동에 맞춰 대본과 표식을 쓴다. ReadyUp 경로를 적 전투로, 미리보기/선택을 구매·효과로, 미완성 건물을 완료 결과로 말하지 않는다. 다른 사건을 하나의 전후처럼 연결하지 않는다. 화면만으로 엔진 내부·비용·개발 의도·최적 전략을 증명하지 않는다.
5. Sakurai 원본 게임과 사례 역할을 유지한다. 오래된 게임만 같은 기능/행동/결과가 확인되는 동일 시리즈 최신 버전/작품으로 교체한다. 현재 출시·가용성·기능·권리를 실제 확인하고 원본→후보→관찰 차이→채택/유지 이유를 기록한다. 최신판에서 설명이 달라지면 원본을 유지한다. 최소4게임과 추가1게임 기본값은 폐기하며 추가 게임은 기본0이다. 원본 없는 수업은 개념에 필요한 최소 사례를 쓴다. 상세는 [게임 간 설명 기준](VIDEO_EXAMPLE_TRANSFER_REVIEW.md).
6. 본편 주요 설명 사이에 개념이 맞는 실제 구간을 배정하고 충분한 고유 분량을 확보한다. 부족하면 관련 자료/해설을 더 찾는다. 자체 게임·이야기 데모·경주·시뮬레이터, 루프·인위적 저속·무관한 대기·장식 몽타주로 채우지 않는다.
7. **실제 영상 원본은1080p FHD 이상을 사용한다** (`fhd-source-minimum-v1`,2026-10-16). 검색 제목이나 완성본 해상도만 믿지 않고 다운로드 포맷·ffprobe 디코딩 크기를 기존 출처표에 기록한다.480p/720p 파일을 확대하거나 AI 업스케일해 기준을 충족했다고 기록하지 않는다. 레트로 게임의 내부 렌더 해상도와 녹화 해상도는 구분하고 원래 화면비를 유지한1080p 녹화를 사용한다. 적합한 자료가 없으면 다른 독립 녹화를 찾고, 해결되지 않으면 부족한 소스를 보고한다. 최종 마스터는1920×1080/60fps다. 새 자료 선정에 적용하며 미선택 완성본을 자동 재제작하지 않는다. 이번 `game-reward-planning` 수정은 사용자가 대본/TTS만 지정했으므로 기존 저해상도 DX 녹화는 명시된 범위 예외로 유지한다.
8. 전체 화면과 원본 UI/비율을 보존한다. 레트로 비율은 중요 내용을 자르거나 늘리지 않고 동일 원본의 배경 확장 등으로 처리한다. 고정 자막과 충돌하면 소스/크롭/큐를 설계 단계에서 고친다. 내레이션과 맞는 대상 추적 표식을 [화면 규격](VIDEO_VISUAL_STYLE.md)에 따라 만든다.

실제 동작 중심의 보조 선/자막은 actual, 정지 분석·도식·숫자 비교가 중심인 구간은 explanation이다. 파일 확장자나 실행 가능 여부로 분류하지 않고 같은 시간을 두 번 세지 않는다. 기본 본편60:40, 승인된 강의40:60 등 개별 예외를 유지한다.

명시 요청된 엔진 기술 데모·실제 코드/편집기/디버거/프로파일러 시연은 해당 주제에서 허용되며 별도 자료 유형으로 기록한다. 자체 게임을 실제게임으로 대체하는 허가는 아니다. 일반 사무실/현금/전화 스톡은 별도 요청 없이 사용하지 않는다. 원음 사용/제거는 프로젝트 오디오 계약과 권리를 따르고 파일 원본은 보존한다.

원본·info·전체 연구 자막·추출 프레임·연락판은 로컬이다. 중복/최근 사용 검토는 기존 검증과 입력 변경분을 재사용하며 매 턴 같은 소스를 재생/추출하지 않는다. 이전 Cloudpost 등 자체 예시 이력은 역사일 뿐 현재 제작 허용 근거가 아니다.
