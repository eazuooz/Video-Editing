## 배치와 기존 자료

- 한 영상은 한 학습 페이지로 만들고, 게임디자인·게임애니메이션·게임 개발 기술 쇼츠의 시리즈 목차에서 순서대로 연결한다. 글 안의 소제목은 그 영상의 학습 단계를 따른다. 같은 영상의 재업로드·개선본은 같은 페이지를 갱신하며 중복 페이지를 만들지 않는다.

## 글의 깊이와 흐름

2026-11-17 후속 사용자 검수 `development-methodology-column-v2`: 위키 글은 독립적인 개발 방법론 칼럼이다. 영상 대사를 그대로 옮기거나 영상 순서에 맞출 필요가 없다. 독자가 글만 읽고 원리와 적용을 이해하도록 하나의 구체적인 사례를 배경·필요 개념 → 자료/판단의 중간 과정 → 구현/설계 → 보이는 결과 → 실패·한계 → 직접 검증까지 충분히 풀어 쓴다. 원래 영상의 유용한 사례와 정확한 사실은 보존하되, 읽기 위해 설명 순서와 예시를 확장·재구성할 수 있다. 기술 칼럼은 자료구조·처리 순서·필요한 의사코드/수식까지, 디자인 칼럼은 대안의 선택 이유·플레이어 행동·프로토타입과 검증 방법까지 설명한다. 이미지도 요약 글자나 장식으로 채우지 않고 전후 변화·작동 과정·구체적인 대상의 차이를 보여 준다. 완성 영상 프레임을 유용하게 유지하면서, 부족한 부분은 직접 만든 도식과 사용 조건이 확인된 공식/개발자/외부 이미지를 보충하고 저자·출처·라이선스·변경 여부를 표시한다. 저장된 문서 길이와 이미지 개수만으로 품질 완료를 판정하지 않는다. 이 지시는 위키에 한정되며 영상 원문 충실성·제작 순서를 자동 변경하지 않는다.


- 영상 요약이나 자막 나열로 끝내지 않는다. 처음 보는 독자가 영상 없이도 이해하도록 상황과 질문 → 필요한 용어의 쉬운 뜻 → 원리 → 영상의 구체적 게임 예시 → 입력·행동·결과 → 구현·설계 시 주의점 → 적용 연습과 정리로 연결한다. 내용을 억지로 이 틀의 고정 절 수에 맞추지 않는다.
- 유용한 설명·학습 순서·중간 단계·전문적 깊이는 보존한다. 처음에는 일반인·고등학생도 이해하는 설명으로 시작하고, 공식 용어와 필요한 수학·코드·한계까지 차근차근 올라간다. 앞 절의 결과가 뒤 절의 질문이나 도구로 이어지게 쓴다.
- 숫자·수식·코드를 쓰면 무엇을 구하는지와 기호·단위를 먼저 정의한다. 관찰한 게임 화면과 설명용 가정·모형, 확인된 실제 구현과 해석을 구별한다. 게임의 의도·내부 구현·실측값을 근거 없이 단정하지 않는다.

## 그림은 영상 화면을 우선 사용

- 해당 내용을 가장 잘 보여 주는 **우리 완성 영상의 실제 프레임을 우선** 선택한다. 동작 전후가 필요하면 서로 다른 실제 시점의 화면을 함께 쓴다. 썸네일·무관한 게임·정지 화면을 반복해 분량을 채우지 않는다.
- 각 그림에는 게임·대상·관찰할 변화·본문에서 설명하는 의미를 구체적으로 적는다. 설명에 필요한 표식은 속성에 맞는 선·화살표·회전 기즈모 등으로 표시하되, 편집상 안내와 실제 게임 데이터를 구별한다. 좌우·앞뒤 방향과 기호를 화면과 일치시킨다.
- 제작 마스터 경로·SHA256, 프레임 시각, 이미지 SHA256, 출처·사용 조건·수정 여부와 Notion 첨부 ID를 기록한다. 문서 재게시 권리가 영상 사용 권리와 동일하다고 자동 가정하지 않는다. 검토가 필요한 자료는 이유를 남기고 검증된 자체 설명 프레임 등으로 대체한다.
- 영상 프레임만으로 부족할 때만 공식 자료·권리 확인 이미지나 직접 제작한 설명 그림을 사용한다. 출처와 설명을 함께 적고, 일회성 외부 이미지 주소·로컬 파일 경로를 Notion 이미지로 남기지 않는다. Notion 자체 첨부나 안정적인 허용된 주소를 사용한다.

- 페이지를 읽어 문맥·기호·수식·표·게임 예시·그림 설명이 맞는지 확인하고, 실제 저장된 페이지/첨부/부모 경로/중복 여부를 검증한다. 링크나 작성 예정 상태만으로 완료 처리하지 않는다. 자료·권리·접근이 막히면 해당 항목의 장애를 기록하고 다른 허용된 항목을 진행한다.
- 위키 페이지 URL, 글 원고, 영상과 이미지 대응, 실제 검증 결과를 기존 작업표에 연결한다. 선택 커밋·푸시에는 글·설계·근거만 포함하고 MP4/WAV·캡처 이미지는 기존 미디어 저장 규칙을 따른다. 새 승인 루프나 자동화 생성 권한은 추가하지 않는다.
