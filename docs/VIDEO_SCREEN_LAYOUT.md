이번 원버튼 수정은 커비 외에 서로 다른 게임 두 개를 추가한다.

## 순서와 화면 역할

1. **채널 인트로**: 기존 세 고양이 로고와 `얌얌코딩 / 게임 기획·디자인` 카드.
   흰 배경, 검정 각진 테두리와 노란 강조. 기존 인트로가 있으면 재사용한다.
   렌더가 없으면 `shared/assets/branding/yamyamcoding-cats-original.png` 원본 로고로 카드를 다시 만든다.
   참고 캡처의 브라우저 상단 테두리·알림 배지는 영상 요소로 복제하지 않는다.
2. **전체 내용 안내 도입부**: 고양이 로고2초 다음에 핵심 질문, 시청 후 얻는 점, 실제 사례와 설명 순서를 우리 내레이션으로 짧게 안내한다. 약20~30초를 기준으로 내용에 맞춰 조정한다. 검토한 실제 게임 동작 또는 흰2.5D 개요 도식을 사용하고 첫 사례로 자연스럽게 연결한다. 모든 내레이션 자막은 아래 가운데 고정이다. 이 구간은 본편60:40에 포함한다. 자세한 대본·검수 기준은 [제작 워크플로](VIDEO_WORKFLOW.md)의2026-10-04 도입부 규칙을 따른다.
3. **실제 게임 영상**: 1920×1080 화면을 게임 영상으로 채운다. PPT 제목·흰 액자 안에 작게 넣지 않는다.
   자막은 영상 위에 `boxed-white-forest-v1`로 겹쳐 표시한다. 출처도 작은 오버레이로 표기한다.
   원본 색상·재생속도·게임 UI를 보존한다. 16:9 영상은 전체 화면으로 표시한다.
   레트로 화면은 중요 UI를 자르거나 억지로 늘리지 않고, 같은 원본 영상의 배경 확장으로 전체 화면을 채울 수 있다.
4. **자체 설명**: 모든 설명 장면을 흰색 연구 발표형 2.5D로 제작한다.
   버튼·게임 공간·물체·시점에 원근, 면의 두께, 겹침, 투영 그림자와 움직임을 준다.
   내레이션에 맞춰 비교·화살표·단계별 강조로 판단과 결과를 보여준다. 텍스트만 나열한 정적 PPT는 사용하지 않는다.
5. **회원 감사 엔딩**: 결론 뒤 10초. 왼쪽 감사 문구·부제, 오른쪽 원본 회원 행 이미지,
   오른쪽 아래 작은 채널 로고를 표시한다. 프로필·표시 이름·회원 배지를 함께 보존한다.
   텍스트 명단이나 생성 이미지로 대체하지 않는다. 잘린 핸들을 추정하지 않는다.
   별도 문구 변경 요청이 없는 한 기존 확정 제목 `멤버쉽가입 감사드립니다.`를 유지한다.

2026-10-01 재확인: 인트로와 엔딩을 제외한 본편은 **실제 영상 60% / PPT·자체 설명 40%**다. 이전 62:38 선택 범위는 대체하며 프레임 반올림은 최대 1프레임만 허용한다. 흰 도식·시간 눈금·숫자 비교 중심의 자체 테스트는 녹화 MP4라도 PPT로 계산한다. 각 주요 설명에 맞는 실제 게임·개발 동작을 본론 중간에 나누어 넣고, 내레이션으로 볼 지점과 PPT의 원리를 연결한다. 좋은 2.5D 설명을 유지하면서 실제 동작 관찰 → 원리 비교 → 적용 결과가 이어지게 만든다. 컷별 분류·개념 연결과 실측 시간은 [제작 워크플로](VIDEO_WORKFLOW.md)에 따라 기록·검수한다.
인트로 추가·예시 대본 변경 시 음성·씬 시작·KO/EN SRT·전체 믹스를 함께 갱신한다.
무자막 마스터, 한국어 자막판, 별도 KO/EN SRT를 `output/<slug>/`에 모으고 게시 전 잔여 검수를 유지한다.
이 기준만으로 게시된 과거 영상을 자동 변경하지 않는다.
