# 게임 간 개념 설명 — 제작 전 설계표

[통합 제작 규칙](VIDEO_WORKFLOW.md)의 제작 전 패키지 안에서 작성한다. 별도의 반복 검수 단계로 운영하지 않는다.

Sakurai 기반 영상은 원본 게임과 사례 역할을 유지한다. 오래된 게임은 동일한 내용을 실제로 보여 줄 수 있는 동일 시리즈의 최신 버전/작품만 찾아 교체한다. 최신 사용자 지시로 최소4게임과 추가1게임 기본값을 모두 대체했다. 추가 게임은 기본으로 넣지 않는다. 원본 없는 수학·기술 강의는 실제 수업자료와 개념에 필요한 최소 사례를 쓴다.

원본 게임→최신 버전 후보→같아야 할 기능/전→행동→결과→차이→채택 또는 원본 유지 이유를 기록한다. 실제 출시/가용성과 소스 권리·UI·기능을 확인하며 최신이라는 이유만으로 설명을 바꾸지 않는다. 기능이 사라졌거나 원리가 달라졌으면 원본을 유지한다. 구체적 소스/권리 문제와 대안은 한 패키지에 적고 여러 게임으로 자동 확장하지 않는다.

| 원본 게임→버전 후보/정확 소스 구간 | 필요한 규칙/UI | 같은 전→행동→결과 | 관찰 차이/채택·유지 이유 | 원본 구간→대본·씬 | 움직이는 표식/자막 공간 |
|---|---|---|---|---|---|
| 실제 확인한 자료 | 사용 전에 설명 | 관찰 사실 | 최소 한 번 직접 비교 | 전환 이유 포함 | 대상·카메라 추적 |

기존 `planning/game-example-coverage.json`이 있으면 참조하고 같은 내용을 복제하지 않는다. 후보 재생, 채택, 해설 존재, 현재 최종 움직임/자막/믹스 검수는 구별한다. 최종 검수는 위 설계가 실제 영상에 구현됐는지 한 번 확인한다. 게임 목록만으로 승인하지 않는다.

대본의 뼈대는 항상 해당 Sakurai 원본이다. 전체 대사·관련 화면에서 중심 질문·핵심 주장·설명 순서·사례 역할·결론을 유지하고, 그 대목에 필요한 세부 설명 PPT/선행 지식/작은 계산·동작만 추가한다. 원본 구간→유지 내용→추가 설명→다음 원본 구간을 연결하며 새 짜임새로 재설계하지 않는다. 사용자 제공 원문은 그 텍스트를 바탕으로 보강할 수 있다. 제공되지 않은 전체 원문의 복제/번역 대신 개념을 독립 문장으로 설명한다. 개인 일화는 Sakurai에게 귀속한다. **원본 영상의 화면·게임 컷·PPT·자막·음성을 편집본에 사용하지 않는다.** 같은 게임의 별도 실제 플레이/메뉴 조작 녹화를 검색·확보하고 우리 설명과 PPT를 제작한다. 그가 해설하는 공식 발표·행사 실연도 연구 전용이며, 자세한 소스 구분은 [실제 자료 선정 규격](VIDEO_GAME_FOOTAGE_POLICY.md)을 따른다. 대응 원본 없는 수학/기술 강의는 실제 수업자료를 사용한다.

기존 업로드는 현재 상태와 내용을 읽어 충족 부분을 보존하고 부족한 지점만 보고한다. 사용자와 한 편씩 수정 범위를 정한 뒤 진행한다. 점수편의 보존 Balatro:Tetris 내부 상대60:40과 해당 영상 전체 actual60:explanation40, 강의40:60 등 승인된 비중을 혼동하지 않는다. 강의 오디오는 [현재 오디오 규격](NARRATION_AUDIO_STANDARD.md)의 낮은 로파이/게임 효과음·환경음 기본값을 선택한 편에 적용한다.
