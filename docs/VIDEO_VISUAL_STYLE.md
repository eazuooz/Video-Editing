# 채널 영상 디자인 기준

## 실제 게임 화면 위에 수학 표시와 비교를 그리기 — 2026-10-10 승인

[실제 게임 자료 방침](VIDEO_GAME_FOOTAGE_POLICY.md)에 따라 이해가 잘되는 원본 구간을 직접 재생·비교한 뒤, 전체 화면 게임 영상 위에 우리가 다루는 수학을 직접 그려 설명한다. 원본 게임의 색감과 동작을 유지하고, 검정 설명 배경 팔레트는 별도 설명 씬에 적용한다.

- **내용에 맞는 도형:** 회전에는 기준축·회전 중심·현재/목표 방향 벡터·각도 호, 이동에는 경로·변위·속도 방향, 공간 관계에는 원·삼각형·평면·거리선 등을 필요한 만큼 선택한다. 빨간선으로 핵심 대상이나 관계를 짚고, 다른 역할은 청록·노랑·초록 등 구별되는 색으로 표시한다. 색의 역할은 장면 계획에 기록하고 같은 영상의 연관 장면에서 유지한다. 라벨·화살촉·실선/점선도 함께 써 색만으로 구별하게 하지 않는다.
- **내레이션과 단계 동기화:** 원본 동작을 먼저 알아볼 수 있게 보여 주고, 대사가 가리키는 축/대상 → 비교 선·도형 → 계산/각도 → 결과 순서로 표시를 드러낸다. 시청자가 실제 행동과 수학의 관계를 따라갈 수 있도록 유지하며 한꺼번에 여러 선·수식을 쏟아내지 않는다.
- **실제 대상에 고정:** 선의 시작점·회전 중심·벡터 방향·궤적은 물체와 카메라 이동에 맞춰 갱신한다. 화면의 고정 좌표에 붙은 화살표가 움직이는 캐릭터와 떨어지지 않게 한다. 3D 축/평면을 그릴 때는 카메라 투영과 가림을 고려하고, 단순 화면 표시라면 그 표시의 의미와 한계를 설명한다. 장면 전환 뒤에는 이전 기준의 표시를 남기지 않는다.
- **가독성과 수학 정확성:** 영상의 밝기·배경 변화에도 선이 읽히도록 굵기와 필요한 대비 윤곽을 조절하고, 도형 채움은 관찰할 행동이 보이도록 투명하게 둔다. 핵심 물체·게임 UI와 고정 하단 자막 `(960,970)` / MC `(0,430)`을 가리지 않는다. 화면상의 투영 각도/길이를 실제 월드 수치로 오인하게 하지 않으며, 확인하지 않은 게임 값은 설명용 값과 구분한다.
- **움직이는 최종 렌더 검수:** 원본과 표시를 비교하고 실제 재생 및 시작/중간/끝, 물체·카메라 이동과 컷 경계를 확인한다. 표시가 대상에 맞는지, 내레이션 순간에 나타나는지, 빨간선과 다른 색의 역할이 일관되고 읽히는지, 원래 행동과 자막이 보이는지 기록한다. 코드에 도형이 있거나 정지 프레임 한 장이 맞는 것만으로 검수 완료를 표시하지 않는다.

원본 파일과 Motion Canvas/Manim의 편집 가능한 선·도형·라벨·타이밍을 분리해 보존한다. 화면이 실제 동작 중심인지 도식 분석 중심인지에 따라 비중을 분류하며, 이 오버레이 요청이 별도 2.5D 설명 장면의 입체·가림·비교 기준을 대체하지 않는다.

2026-10-10 최신 적용 범위: 초반 개론·유기적 흐름·이해하기 쉬운 실제 게임 후보 비교와 화면 위 수학 표시는 앞으로의 제작뿐 아니라 아직 게시되지 않은 예약/비공개 영상의 검수·수정에도 적용한다. 수학 표시를 넣을 때 빨간 핵심선과 역할별 색·라벨을 실제 대상/카메라에 맞춰 움직이고, 중요한 동작·UI·고정 자막을 보존한다. 관련 수학이 없는 디자인 사례에는 개념에 맞는 윤곽·높이·상태 표시를 사용한다. 공개 완료본과 원본 이력은 보존하며 `docs/VIDEO_WORKFLOW.md`의 최신 공개 전 수정 절차를 따른다.

**적용 경계:** 이 요청 전에 제작에 들어간 프로젝트는 현재 색감·소스·승인 음성·렌더를 보존한다. 현재 `similar-game-design`도 흰 스타일로 마무리하며 다음 미착수 Sakurai 항목 `presenting-game-scores`부터 새 기본값을 적용한다. 요청 시점의 기존 프로젝트 목록과 첨부 원본 경로·SHA는 `shared/publishing/explanation-style-policy.json`에 보존한다. 기존 프로젝트를 템플릿 변경으로 일괄 갱신하지 않는다.

이 요청은 설명 부분의 색감 변경이다. 실제 게임 화면의 원래 색감, 원본 고양이 인트로·회원 10초 엔딩, 고정 하단 `boxed-white-forest-v1` 자막과 자연스러운 노랑/흰 삽화 썸네일은 기존 기준을 따른다. 설명 화면의 흰 글씨와 내레이션 박스 자막은 서로 다른 역할이다.

입체 설명 요구는 유지한다. 앞·옆·윗면, 높이·원근·앞뒤 가림과 문단에 맞는 이동·비교가 실제 렌더에서 보여야 한다. 검정에 묻히는 면은 밝기 차와 얇은 윤곽선으로 구별한다. 제목·수식·축·범례·보조 문구 및 한 줄/두 줄 고정 자막의 대비와 여백을 모든 씬에서 직접 확인한다. 흰 배경 검사를 새 프로젝트의 성공 조건으로 재사용하지 않으며 검정 배경 자체를 빈 화면 오류로 판정하지 않는다.

아래 흰 연구 발표 기준은 이미 착수한 작업과 과거 제작의 기록이다. 신규 설명 색감은 위 규칙이 우선한다.
