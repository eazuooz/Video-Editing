# 채널 영상 디자인 기준 — Research Paper / White

2026-09-07 사용자 지정. 현재 AI 시대 컴공 영상과 앞으로 만드는 영상의 기본값.
기준은 사용자 제공 `Exploring Low-Rank Retargeting of RenderFormer.pdf`(28쪽, 16:9).
PDF 자체는 수정하지 않는다. 연구 내용·그림·저자명을 채널 자산으로 복사하지 않는다.

## 관찰한 디자인

- 1쪽: 흰 바탕, 좌측 정렬 제목, 넓은 여백, 검정 제목과 회색 부제.
- 2~6쪽: 작은 장 번호 → 큰 제목 → 짧은 설명 → 중앙 도식 → 하단 핵심 결론.
- 7·13·16·26~27쪽: 연한 회색의 각진 행/박스, 얇은 테두리, 명확한 글자 위계.
- 14·17~20·24쪽: 파랑 막대/선, 실제 이미지 비교, 축과 범례. 색은 의미를 구분할 때만 사용.
- 글꼴 추출: Segoe UI Regular/Bold/Italic, 수식은 Cambria Math. 한글은 맑은 고딕 폴백.

## 1920×1080 배치와 타이포그래피

- 안전 여백 좌우 96px. 장 번호 y=-477, 왼쪽 정렬 제목 y=-405, 부제 y=-325.
- 제목 48~56px, 핵심 도식 32~40px, 보조 설명 26~30px, 출처 20~24px.
- 영어 Segoe UI, 한글 Malgun Gothic, 코드 Consolas. 제목 600~700, 일반 본문 400~500.
- 핵심 도식은 가운데 넓게. 하단 y=405에 폭1728·높이90px의 연회색 요약 띠.
- 큰 둥근 카드, 네온 민트/보라, 어두운 대시보드 배경, 그라데이션, 장식용 빛 번짐은 기본값에서 제외.
- 그림은 새로 제작한다. 시각적 근거가 필요하면 실제 자료 영상과 자체 개념도를 구분한다.
- 외부 영상에는 색상 테마를 씌워 변색하지 않는다. 원본 비율과 크레딧을 보존하고 화면 밖의 흰 여백에 출처를 적는다.
- 자막은 별도 KO/EN SRT가 기본. 긴 문장으로 도식을 덮지 않는다.

## 움직임과 가벼운 밈

일반 전환은 0.2~0.4초 페이드·단계별 등장. 밈은 선택적: 장당 약2초,
가상 인물·직접 그린 도형과 짧은 반응 문구로 재해석한다. 발표 자료의 색과 정렬은 유지한다.
남의 밈 영상/캐릭터/음성을 참고 링크만으로 재사용 허용이라 판단하지 않는다.
취준생·신입을 무능력자로 희화화하지 않고 과한 기대와 익숙한 난처함을 웃음의 대상으로 삼는다.
