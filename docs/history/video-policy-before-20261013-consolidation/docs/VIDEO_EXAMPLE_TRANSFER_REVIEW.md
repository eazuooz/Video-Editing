# 게임 간 개념 전달 검수

2026-10-11 사용자 요청: 한 게임에 한정해서만 설명이 이해되는 문제를 고치고 설명용 게임을 최소 4종 이상 사용한다. 미게시(예약 포함)를 우선 검수하고 기존 업로드도 확인하여 필요한 것만 수정한다.

## 독립 영상별 기준

1. 실제 본편에 서로 다른 기존 게임을 최소 4종 사용한다. 후보·거절·보류 자료, 썸네일, 이름 언급, 정지 이미지나 장식 몽타주는 실제 설명 사례 수에 넣지 않는다. 같은 게임의 모드·버전·재출시·다른 녹화는 수를 늘리지 않는다. 가능한 한 서로 다른 작동 방식이나 상황을 비교하되 무관한 장르를 억지로 삽입하지 않는다.
2. 대표 사례에서 개념을 충분히 설명한 다음 다른 게임에서 무엇이 같고 무엇이 달라지는지 보여 준다. 모든 게임에 같은 시간을 배분할 필요는 없지만, 각 게임에 필요한 규칙/UI와 대상 → 행동 → 결과 → 공통 원리를 이해할 수 있는 정상 속도의 구간·완결 해설이 있어야 한다. 시간을 정해 패딩하거나 유용한 설명을 줄이지 않는다.
3. 게임이 바뀔 때 앞의 결과, 새로 확인할 질문, 달라진 규칙이나 가정을 안내한다. 적어도 한 번은 두 게임의 같은 개념을 직접 비교하고, 결론에서 특정 게임의 특수 규칙과 다른 게임에도 적용할 원리를 구분한다. 수학은 단위·좌표·축·곱셈 순서와 표식 색의 역할을 일관되게 유지한다.
4. 실제 정상 속도 후보를 직접 보고 비교한다. 작은 대상·복잡한 UI·가림 때문에 이해가 어려우면 더 명료한 장면/게임을 선택하거나 프레이밍과 전제 해설을 보완한다. 설명에 맞는 빨간 핵심선·역할별 도형/라벨은 원본 동작과 카메라를 따라가며 UI와 고정 자막을 가리지 않아야 한다. 확인하지 않은 월드 수치나 게임 엔진 내부를 관찰 사실처럼 말하지 않는다.
5. 참고 마사히로 원본의 질문 → 관찰 → 이유 → 결과 흐름과 비교한다. 같은 게임을 써도 되지만 권리와 이해도를 확인하고 더 적절한 게임으로 대체할 수 있다. 참고 강의의 영상·음성·전체 번역은 복제하지 않는다.

## 기록과 승인

`planning/game-example-coverage.json`에 실제 게임마다 `gameId`, `gameTitle`, 핵심 주장, 사전 설명, 원본URL·사용 조건, 정확 native 인아웃, 관찰한 전/행동/후, 연결되는 대본·씬·자막 위치, 비교 게임, 공통 원리와 차이를 기록한다. `footageAdopted`, `narratedExample`, `normalSpeedPlaybackReviewed`, `finalMovingPixelsReviewed`, `captionAndUiClearanceReviewed`, `mixedAudioReviewed`를 별도로 기록한다. 후보 재생과 최종 연속 렌더 승인은 구별한다.

게임명 수를 세는 정적 점검은 자료 조사이며 전체 개념 전달 검수가 아니다. 후보/출처 기록에 네 게임이 있더라도 실제 채택·본편 해설·비교·움직이는 표식·현재 혼합 음성 검수가 없으면 승인하지 않는다. 자료가 부족한 항목은 미완료로 기록한다.

## 기존 영상 처리

- 현재 Studio에서 공개/예약/비공개와 실제 ID를 먼저 확인하고 삭제된 역사 원본을 수정 대상으로 다시 잡지 않는다.
- 충족한 부분은 재사용한다. 네 게임 기준이나 개념 전달이 부족한 부분만 추가·수정하고, 기존 승인된 설명·음성·회원 신원·고양이 인트로·팔레트를 보존한다.
- 새 버전은 기술 QA/현재 전체 혼합 ASR/최종 움직임·자막·모든 컷/4파일 수집/비공개 게시 설정/Git 전달 후 기존 예약일과 실제 현재 일정을 대조한다. 미완성본을 예약하지 않는다. 기존 공개본은 교체본 없이 삭제하지 않는다.
- 프로젝트별 actual/explanation 비율, no-BGM 등 승인된 예외를 보존한다. 점수편의 최신 최소 네 게임 지시는 이전 전체 Balatro60:Tetris40 두 게임 배정에 우선하며, 보존할 두 게임끼리의 상대 배정은 60:40으로 유지한다.

앞선 사용자 토큰 부족 중단 지시는 재제작 시점 답변으로 구별한다. 규칙 기록·읽기 검수는 수행할 수 있지만 중단 중 TTS/렌더와 자동화를 임의 재개하지 않는다.
