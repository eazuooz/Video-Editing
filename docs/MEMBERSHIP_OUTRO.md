# 원본 회원 엔딩 규격

[통합 제작 규칙](VIDEO_WORKFLOW.md)에 따라 제작 전 전체 화면/플랫폼 요소를 함께 설계한다.

- 결론 뒤 정확10초, 영상당 한 번. 제목은 사용자 원문 **`멤버쉽가입 감사드립니다.`**. 임의 맞춤법 교정 금지. 부제 `채널을 함께 만들어 주셔서 고맙습니다.`.
- 왼쪽 감사 제목/안내, 오른쪽 사용자 원본 회원 행, 원래 채널 로고. 각 회원의 프로필·표시 이름/핸들·배지를 함께 보존한다. 생성 사진/추정 배지/텍스트만 명단으로 대체하지 않는다.
- 기준 명단 `motion-canvas/src/shared/membership/members.json`, 씬 `motion-canvas/src/shared/membership/membership-outro.tsx`. 현재 승인 원본/명단 해시를 재사용하고 명단이 바뀌었거나 원본이 없을 때만 확인을 요청한다. 잘린 핸들은 추정하지 않고 미확인으로 기록한다.
- 과거3열/y=-405 배치를 새로 강제하지 않는다. 승인된 원본 행 배치와 신원 가독성을 우선하고 링크·관련 재생목록·자기 채널 구독3요소를 가리지 않을 공간을 처음부터 마련한다.
- 내레이션 없음/내레이션 SRT 없음. 선택한 강의의 승인 로파이를 포함해 승인 BGM은 끝까지 낮게 연속, 맨 끝0.45초 fade. 과거 무BGM 납품은 보존하고, 새로 선택한 강의는 [현재 오디오 규격](NARRATION_AUDIO_STANDARD.md)을 적용한다. 해당 편에 새로 명시한 무BGM 예외는 엔딩에도 적용한다. 타임라인·믹스·총길이·엔딩 시점을 함께 갱신한다.
- 설명색 변경으로 회원 원본을 recolor하지 않는다. 실제 마지막 프레임까지 신원/제목/로고와 플랫폼 요소의 겹침을 확인한다. 동일 엔딩 입력·출력은 검수 근거를 재사용한다. 명단 변경만으로 기존 공개 영상을 재렌더하지 않는다.

원본 배치 참조: [회원 화면](references/video-layout-20260930/04-membership.png). 원본이 없으면 정확한 파일/첨부를 요청하며 임의 생성으로 해결하지 않는다.
