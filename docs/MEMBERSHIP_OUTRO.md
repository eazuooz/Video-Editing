# 영상 마지막 멤버십 감사 화면

2026-09-25 사용자 요청: “영상마지막에 항상 10초정도 멤버쉽 가입 감사드립니다. 영상 붙여서 추가해주고
이거 영상제작규칙으로 만들어줘”. **앞으로 만드는 모든 새 영상의 마지막에 붙인다.**
이미 게시한 영상은 이 규칙만으로 다시 렌더하지 않는다.

2026-09-30 화면 구성 추가 확정: 새 렌더는 [VIDEO_SCREEN_LAYOUT.md](VIDEO_SCREEN_LAYOUT.md)의 사용자 첨부 배치를 따릅니다. 왼쪽 감사 제목·부제, 오른쪽 원본 회원 행, 오른쪽 아래 작은 채널 원본 로고를 표시합니다. 이 배치가 아래의 종전 제목 좌표·3열 기본값보다 우선합니다. 회원의 프로필·이름·배지를 보존하고 기존 제목과 10초 길이를 유지합니다.

## 구성

| 항목 | 기본값 |
| --- | --- |
| 위치 | 본편 마지막 씬 뒤, 영상의 맨 끝 |
| 길이 | 10초 (`MEMBERSHIP_OUTRO_SECONDS`) |
| 제목 | `멤버쉽가입 감사드립니다.` — 사용자 요청 문구 그대로 (y=-405, 56px, 700) |
| 부제 | `채널을 함께 만들어 주셔서 고맙습니다.` |
| 명단 | 사용자 제공 목록의 프로필 이미지 + 표시 이름/핸들 + 멤버십 배지를 한 세트로 그대로 사용. 이름만 있는 카드로 대체하지 않는다 |
| 긴 명단 | 6줄을 넘으면 카드 영역이 천천히 위로 올라간다 |
| 소리 | 내레이션 없음. 연속 BGM만 이어지고 영상 맨 끝 0.45초 페이드아웃. BGM을 쓰지 않기로 한 영상은 음악을 새로 넣지 않는다 |
| 자막 | SRT 큐 없음. 한국어 박스 자막판에도 이 구간에는 자막 박스를 표시하지 않는다 |

제목 문구는 사용자가 지정한 `멤버쉽가입 감사드립니다.`를 그대로 쓰며 임의로 맞춤법을 바꾸지 않는다.

## 파일

- 명단: `motion-canvas/src/shared/membership/members.json` — 이 파일 한 곳만 갱신한다.
- 공통 화면: `motion-canvas/src/shared/membership/membership-outro.tsx`
- 새 프로젝트 템플릿: `templates/motion-canvas-project/scenes/membership-outro.tsx`가 자동으로 마지막 씬에 등록된다.
- 단독 검토 렌더: 개발 서버 실행 후 `node motion-canvas/scripts/render-membership-outro.cjs`

## 명단 관리

- 2026-09-25 추가 요청: 사용자가 준 YouTube Studio 멤버 목록의 **프로필 사진·표시 이름·멤버십 배지를 그대로 함께 사용**한다. 종전의 핸들만 표시하는 규칙을 대체한다.
- 원본 목록의 행을 Motion Canvas 클리핑으로 배치하면 이름과 사진, 배지의 대응을 보존할 수 있다. 가능하면 3열로 넓게 배치하고 작은 배지도 식별되게 한다. 원본 비율을 유지한다.
- 사진을 AI로 재생성하거나 배지 색·모양을 추측해 그리지 않는다. 다른 계정의 사진을 검색해서 대신 사용하지 않는다. 표시된 이름을 추측으로 확장하거나 실제 신원을 추가하지 않는다.
- 원본 이미지 파일을 확보하지 못했다면 재첨부나 로컬 파일 경로를 요청한다. 채팅에서 보이는 이미지를 실제 파일로 확보한 것으로 간주하지 않는다. 이미지·배지 없는 구버전을 수정 완료라고 안내하지 않는다.
- 캡처에서 잘린 핸들은 `verified: false`로 표시하고, 게시용 렌더 전에 전체 핸들을 확인한다.
- 새 영상을 렌더하기 직전 명단의 `updatedAt`과 목록을 사용자에게 확인한다.
- 명단이 바뀌었다는 이유로 게시한 영상을 다시 렌더하지 않는다.

## 타이밍·오디오·검수

- 이 구간은 내레이션 타이밍 밖에 있다. 전체 길이 = 본편 실측 길이 + 10초. `project.json.video.durationSeconds`와 `editing.outro`에 함께 기록한다.
- 믹스에서는 BGM을 이 10초까지 연장하고 최종 페이드는 영상 맨 끝에만 적용한다. 원음·내레이션은 넣지 않는다.
- KO/EN SRT의 마지막 큐는 본편 내레이션에서 끝난다. 아웃트로에는 큐를 만들지 않는다.
- 음성·디자인만 확인하는 부분 프리뷰에는 붙이지 않아도 된다. 최종 본편에는 반드시 한 번만 붙인다.
- 모든 핸들이 카드 안에 들어가는지, 잘린 핸들이 없는지, 마지막 프레임까지 BGM이 이어지는지 확인한다.
