가방을 조금 더 넓히려고 한 번 더 돈을 모으고, 처음 켠 게임에서도 자연스럽게 버튼을 누르고, 잘 만든 컷신도 반복되면 넘기고 싶어집니다.

실제 게임으로 배우는 게임기획 수업

게임 화면으로 현상을 보고, 그림과 구조로 원리를 이해한 뒤, 내 아이디어에 적용할 질문을 남깁니다.

01. 튜토리얼 설계: 플레이하며 배우게 만들기

슈퍼 마리오 오디세이의 장면을 보며 플레이어가 무엇을 보고 행동하는지 살펴봅니다. 첫 화면과 행동의 결과가 어떻게 다음 시도를 이끄는지 관찰합니다.

실제 수업 화면 · 「설명보다 먼저 플레이하게 하기」

02. 보상 설계: 갖고 싶은 이유 만들기

왜 가방 확장이 다음 목표가 될까요? 하고 싶은 행동과 현재의 불편함을 연결하면 보상의 의미가 보입니다. 보상을 얻은 뒤 무엇이 달라지는지 그림으로 풀어봅니다.

실제 수업 화면 · 「눈에 보이는 보상이 만드는 동기」

03. 게임 기획서: 아이디어를 구조로 정리하기

규칙이 많아질수록 어디를 고쳐야 할지 찾기 어려워집니다. 탐험·전투·아이템을 묶고 필요한 가지를 펼치며, 다른 사람도 이해할 수 있는 기획 구조로 정리합니다.

실제 수업 화면 · 「계층형 아웃라인으로 기획서 정리하기」
화면의 기획서는 설명용 예시입니다.

6가지 관점으로 배우는 게임 디자인

  1. 게임 디자인을 보는 눈
    제작자의 역할과 먼저 플레이하게 하는 설계
  2. 첫 장면과 배움
    도입부 · 튜토리얼 · 초보자에게 친절한 게임
  3. 손에 익는 조작과 편안한 화면
    원버튼 · 점프 · 입력 피드백 · 프레임 · 시야각 · 카메라
  4. 계속하고 싶게 만드는 보상과 선택
    보이는 목표 · 수집 · 칭찬 · 커스터마이징 · 관전
  5. 플레이어를 존중하는 게임
    게임 AI · 컷신과 스킵 · 시간 · 색 정보 전달
  6. 아이디어를 전달하고 발전시키기
    기획 설명 · 계층형 아웃라인 · 선택받을 차별점

한 수업마다, 내 게임에 질문 하나

관찰하기 — 좋아하는 게임에서 비슷한 장면을 찾습니다.
설명하기 — 플레이어의 목표·행동·결과를 한 문장씩 적습니다.
적용하기 — 내 게임이라면 무엇을 바꿀지, 그 이유를 남깁니다.

작은 질문이 쌓이면 조작과 보상, 안내 문구를 고칠 때 사용할 자신만의 설계 기준이 됩니다.

이런 분과 함께하고 싶습니다

  • 게임 개발 입문자·인디 개발자 — 구현할 아이디어는 있지만 재미를 어떻게 다듬을지 막막한 분
  • 예비 게임 기획자 — 조작, 보상, 튜토리얼을 분석하고 기획 의도를 전달하고 싶은 분
  • 게임을 좋아하는 분 — 좋아하는 게임이 재미있는 이유를 더 깊이 이해하고 싶은 분
