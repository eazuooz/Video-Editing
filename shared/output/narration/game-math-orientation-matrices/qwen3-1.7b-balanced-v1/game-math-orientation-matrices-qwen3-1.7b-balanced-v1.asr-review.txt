[22]  첫 문제입니다. 앞에 Z축 90도 행렬에 로컬 벡터 1, 0, 0을 넣으면 무엇이 나올까요? 첫 열을 고르면 됩니다. 답은 월드 0, 1, 0입니다. 두 번째 문제입니다. 월드 점은 4, 5, 0이고 물체의 원점은 3, 3, 0입니다. 물체 자세는 같은 90도 회전입니다. 먼저 위치를 빼면 월드 변이 1, 2, 0입니다. 이제 전치 행렬을 곱하면 로컬 좌표 2, 마이너스 1, 0이 됩니다. 다시 원래 행렬을 곱하고 물체 위치를 더해서 월드 4, 5, 0으로 돌아오는지도 확인해보세요.

[23]  처음과 같은 게임이지만 이제 볼 항목이 조금 늘었습니다. 몸의 위치, 몸이 향하는 앞쪽, 팔이 기울어진 방향을 따로 구분해보세요. 카메라가 보여주는 화면 기준과 물체 기준도 함께 생각해보세요. 회전 행렬은 이 자세를 세 축의 방향으로 기록하고 공간 사이의 벡터를 바꿔줍니다. 보이는 움직임을 실제 좌표 값으로 측정한 것은 아니지만 무엇을 기록할지는 분명해졌습니다. 다음 편에서는 사람이 입력하기 쉬운 오일러 값과 회전 순서를 배웁니다.
